# 监管园区接口落地设计

## 1. 模块目标

建立**园区/政府监管平台数据交换**能力，按配置化映射上报双重预防、特殊作业、重大危险源、报警等数据，支持任务调度、回执追踪、失败重试和对账。

## 2. 功能范围

| 子模块 | 二期范围 |
| --- | --- |
| 平台配置 | 监管平台地址、认证、租户级启用 |
| 映射配置 | 字段映射、编码转换、区域/装置对照 |
| 上报任务 | 定时/实时任务、批量/单条 |
| 数据抽取 | 从业务服务聚合待上报数据 |
| 传输适配 | HTTP/HTTPS、签名、加密（按平台要求） |
| 回执处理 | 成功/失败回执、错误码解析 |
| 重试对账 | 失败重试、补报、对账报表 |
| 审计 | 上报报文摘要、操作人、结果 |

## 3. 上报数据域（二期）

| 数据域 | 典型内容 |
| --- | --- |
| 双重预防 | 风险单元、管控措施、隐患台账、整改状态 |
| 特殊作业 | 作业票申请、审批、许可、关闭状态 |
| 重大危险源 | 档案、监测指标、在线率 |
| 报警 | 报警事件、处置结果（按监管要求 subset） |
| 人员定位 | 区域人数、告警（若监管要求） |
| 视频 AI | 关键 AI 事件（若监管要求） |

具体字段以项目所在地监管平台和化工园区接口规范为准，通过映射配置适配，禁止硬编码单一地区口径。

## 4. 关键流程

### 4.1 定时上报

```text
调度器触发上报任务
 -> 按数据域抽取增量数据
 -> 应用映射和编码转换
 -> 组装报文并签名
 -> 调用监管平台接口
 -> 解析回执
 -> 成功标记/失败入重试队列
 -> 写审计和对账记录
```

### 4.2 失败重试

```text
上报失败
 -> 记录错误码和报文摘要
 -> 按退避策略重试
 -> 超过阈值告警运维
 -> 支持人工补报
 -> 对账报表展示成功率
```

## 5. 数据设计

| 表 | 说明 |
| --- | --- |
| `reg_platform_config` | 监管平台配置 |
| `reg_field_mapping` | 字段映射 |
| `reg_code_mapping` | 编码对照（区域、作业类型等） |
| `reg_report_task` | 上报任务实例 |
| `reg_report_payload` | 报文摘要（不存敏感明文全量） |
| `reg_report_receipt` | 回执记录 |
| `reg_retry_queue` | 重试队列 |
| `reg_reconciliation` | 对账汇总 |

## 6. 关键字段

### 6.1 上报任务 `reg_report_task`

| 字段 | 说明 |
| --- | --- |
| task_no | 任务编号 |
| platform_code | 监管平台 |
| data_domain | 数据域 |
| trigger_type | SCHEDULE、REALTIME、MANUAL |
| data_window_start | 数据窗口起 |
| data_window_end | 数据窗口止 |
| record_count | 记录数 |
| status | 待执行、执行中、成功、失败、部分成功 |
| executed_at | 执行时间 |

### 6.2 回执 `reg_report_receipt`

| 字段 | 说明 |
| --- | --- |
| task_id | 关联任务 |
| success | 是否成功 |
| platform_code | 平台返回码 |
| platform_message | 平台返回信息 |
| receipt_time | 回执时间 |

## 7. 集成架构

```text
业务服务（双重预防/作业票/危险源/报警/定位/视频）
 -> psm-integration-service（抽取与组装）
 -> 映射/签名/加密适配层
 -> 监管/园区平台
 -> 回执/重试/对账
```

`psm-integration-service` 一期已存在骨架，二期完善调度、映射和适配器插件机制。

## 8. 接口设计

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/reg/platforms` | GET/POST | 平台配置 |
| `/reg/mappings` | GET/POST | 字段/编码映射 |
| `/reg/tasks` | GET | 上报任务列表 |
| `/reg/tasks/trigger` | POST | 手动触发上报 |
| `/reg/tasks/{id}/retry` | POST | 失败重试 |
| `/reg/receipts` | GET | 回执查询 |
| `/reg/reconciliation` | GET | 对账报表 |
| `/reg/preview` | POST | 上报报文预览（脱敏） |

## 9. 安全与合规

- 监管平台密钥、证书走 Jasypt 或环境变量，禁止入库明文。
- 报文日志只保留摘要、哈希和 record_count，不默认全量 INFO 打印。
- 上报数据需租户隔离，跨租户任务禁止混报。
- 支持网络白名单和专线部署。

## 10. 验收标准

- 可配置至少一个监管/园区平台上报通道。
- 双重预防、特殊作业、重大危险源数据可按映射生成报文。
- 上报任务可定时执行、手动触发、失败重试。
- 回执和对账报表可查询成功率与失败原因。
- 密钥和报文敏感字段不出现在普通日志。
- 上报和补报操作可审计。
