# 视频智能与过程监护落地设计

## 1. 模块目标

接入视频平台和 AI 分析事件，实现**烟火、违章、闯入等智能识别事件的标准化汇聚**，并支撑**特殊作业过程视频监护**与报警中心、作业票联动。

## 2. 功能范围

| 子模块 | 二期范围 |
| --- | --- |
| 视频资源 | 摄像头台账、区域绑定、直播/回放地址 |
| AI 事件接入 | 烟火、未戴 PPE、离岗、闯入、聚集等 |
| 事件标准化 | 映射区域、危险源、等级、去重 |
| 过程监护 | 作业票绑定摄像头、监护截图/片段留痕 |
| 报警联动 | AI 事件转报警、关联视频画面 |
| 处置辅助 | 报警详情跳转实时视频和回放 |
| 统计分析 | 按类型、区域、摄像头统计 AI 事件 |

## 3. 关键流程

### 3.1 AI 事件接入

```text
视频平台/AI 算法推送事件
 -> 适配层解析和验签
 -> 映射摄像头、区域、危险源
 -> 规则分级和去重
 -> 写入视频事件表
 -> 推送报警中心（按等级）
 -> 值班确认和处置
```

### 3.2 作业过程监护

```text
高风险作业票进入作业中
 -> 绑定区域默认摄像头或手动选择
 -> 记录监护开始
 -> 定时/异常触发截图或片段归档
 -> 作业结束停止监护
 -> 附件关联作业票审计
```

## 4. 事件类型（首期）

| 类型 | 说明 |
| --- | --- |
| FIRE_SMOKE | 烟火识别 |
| NO_PPE | 未佩戴 PPE |
| INTRUSION | 人员闯入 |
| LEAVE_POST | 离岗 |
| CROWD_GATHER | 人员聚集 |
| HOT_WORK_VIOLATION | 动火违章（如未设监护） |
| RESTRICTED_ENTER | 禁入区域出现人员 |

## 5. 数据设计

| 表 | 说明 |
| --- | --- |
| `video_camera` | 摄像头台账 |
| `video_ai_event` | AI 事件主表 |
| `video_ai_event_media` | 事件截图/短视频 |
| `video_watch_session` | 作业过程监护会话 |
| `video_watch_capture` | 监护截图/片段 |
| `video_platform_config` | 视频平台接入配置 |

## 6. 关键字段

### 6.1 AI 事件 `video_ai_event`

| 字段 | 说明 |
| --- | --- |
| event_no | 事件编号 |
| source_platform | 来源平台 |
| camera_id | 摄像头 |
| event_type | 事件类型 |
| event_time | 发生时间 |
| area_id | 区域 |
| major_hazard_id | 危险源（可选） |
| alarm_id | 关联报警 |
| work_permit_id | 关联作业票（可选） |
| severity | 严重程度 |
| status | 新事件、已转报警、已忽略 |

### 6.2 监护会话 `video_watch_session`

| 字段 | 说明 |
| --- | --- |
| work_permit_id | 作业票 |
| camera_ids | 监护摄像头列表 |
| started_at | 开始时间 |
| ended_at | 结束时间 |
| operator_id | 监护人/值班员 |
| status | 进行中、已结束 |

## 7. 联动规则

| 场景 | 规则 |
| --- | --- |
| 报警中心 | 达到阈值等级的 AI 事件自动转报警 |
| 作业票 | 动火/受限空间作业中区域出现烟火/闯入触发强制复核 |
| 重大危险源 | 危险源关联摄像头事件提高区域风险 |
| 定位 | 报警详情可同时展示附近人员和视频 |

## 8. 接口设计

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/cameras` | GET/POST | 摄像头台账 |
| `/ai-events/ingest` | POST | AI 事件接入 |
| `/ai-events` | GET | 事件列表 |
| `/ai-events/{id}/to-alarm` | POST | 手动转报警 |
| `/ai-events/{id}/ignore` | POST | 忽略（需权限和原因） |
| `/watch-sessions` | POST | 创建作业监护 |
| `/watch-sessions/{id}/capture` | POST | 上传监护截图/片段 |
| `/watch-sessions/{id}/close` | POST | 结束监护 |
| `/cameras/{id}/live-url` | GET | 获取直播地址（受权限控制） |
| `/cameras/{id}/playback-url` | GET | 获取回放地址 |

## 9. 安全要求

- 视频流地址必须短时有效、鉴权访问，禁止明文长期外链。
- AI 事件接入需验签或 IP 白名单。
- 截图/片段存储走统一文件服务，敏感区域视频访问需审计。
- 不支持一期反向控制摄像头云台（仅观看）。

## 10. 验收标准

- 模拟或真实 AI 事件可接入并按类型展示。
- 高等级 AI 事件可自动进入报警中心并关联摄像头。
- 动火/受限空间作业可绑定摄像头并记录过程监护。
- 报警详情可跳转关联视频直播或回放。
- 视频资源和 AI 事件查询受区域数据权限控制。
- 忽略/转报警等操作可审计。
