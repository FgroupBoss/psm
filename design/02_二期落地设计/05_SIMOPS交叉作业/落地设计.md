# SIMOPS 交叉作业落地设计

## 1. 模块目标

识别同一区域、重叠时间段内的**交叉作业冲突（SIMOPS）**，在作业票申请和许可环节提供风险提示、规则阻断或协调审批，降低动火、排放、吊装、受限空间等并行作业风险。

## 2. 功能范围

| 子模块 | 二期范围 |
| --- | --- |
| 冲突矩阵 | 作业类型两两冲突规则配置 |
| 区域时间窗口 | 同区域、计划/实际时间段重叠检测 |
| 冲突识别 | 申请、审批、许可前自动扫描 |
| 处置策略 | 提示、升级审批、硬阻断 |
| 协调审批 | 冲突协调人、会签、条件许可 |
| 冲突记录 | 冲突快照、处理结果、审计 |
| 统计复盘 | 冲突次数、区域 TOP、类型组合分析 |

## 3. 关键流程

### 3.1 冲突检测

```text
作业票提交/许可前
 -> 提取区域、作业类型、计划时间段、实际时间段
 -> 查询同区域重叠作业（草稿除外/可配置）
 -> 匹配冲突矩阵
 -> 生成冲突清单和严重级别
 -> 按策略提示/升级/阻断
 -> 记录冲突快照
```

### 3.2 协调审批

```text
冲突命中且策略=协调审批
 -> 指定协调人（区域负责人/安全管理员）
 -> 协调人查看冲突作业详情
 -> 给出条件许可或驳回
 -> 条件写入作业票备注和审计
 -> 继续原审批或许可流程
```

## 4. 冲突矩阵示例

| 作业 A | 作业 B | 默认策略 | 说明 |
| --- | --- | --- | --- |
| 动火 | 受限空间 | 硬阻断 | Classic SIMOPS |
| 动火 | 吊装 | 协调审批 | 需安全协调 |
| 动火 | 临时用电 | 提示 | 检查隔离和防火 |
| 受限空间 | 盲板抽堵 | 协调审批 | 需确认隔离状态 |
| 动土 | 地下管线检修 | 硬阻断 | 防止误挖 |
| 断路 | 任何作业 | 提示 | 交通与区域影响 |

矩阵支持按企业、区域、风险等级差异化配置，存储于配置规则服务。

## 5. 数据设计

| 表 | 说明 |
| --- | --- |
| `simops_conflict_rule` | 冲突矩阵规则 |
| `simops_scan_result` | 单次扫描结果 |
| `simops_conflict_item` | 冲突明细（作业票对） |
| `simops_coordination_record` | 协调审批记录 |

## 6. 关键字段

### 6.1 冲突规则 `simops_conflict_rule`

| 字段 | 说明 |
| --- | --- |
| work_type_a | 作业类型 A |
| work_type_b | 作业类型 B |
| area_scope | 全厂、指定区域 |
| overlap_minutes | 最小重叠分钟数 |
| action | WARN、COORDINATE、BLOCK |
| enabled | 是否启用 |

### 6.2 扫描结果 `simops_scan_result`

| 字段 | 说明 |
| --- | --- |
| work_permit_id | 当前作业票 |
| scan_stage | SUBMIT、APPROVE、PERMIT |
| conflict_count | 冲突数量 |
| max_severity | 最高严重级别 |
| final_action | 通过、协调、阻断 |
| scanned_at | 扫描时间 |

## 7. 规则引擎集成

SIMOPS 扫描作为规则引擎扩展能力，对外统一接口：

```json
{
  "passed": false,
  "reasons": [
    {
      "code": "SIMOPS_CONFLICT",
      "message": "同区域存在进行中的动火作业 WP-20260528-001",
      "severity": "BLOCK",
      "relatedWorkPermitId": 10086
    }
  ],
  "suggestion": "请调整作业时间或发起协调审批"
}
```

一期 `psm-work-permit-service` 在提交、许可环节调用 `/simops/scan` 规则接口。

## 8. 接口设计

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/simops/rules` | GET/POST | 冲突矩阵维护 |
| `/simops/scan` | POST | 冲突扫描（规则引擎调用） |
| `/simops/conflicts` | GET | 冲突记录查询 |
| `/simops/conflicts/{id}/coordinate` | POST | 协调审批 |
| `/simops/statistics` | GET | 冲突统计 |

## 9. 页面设计

| 页面 | 关键能力 |
| --- | --- |
| 冲突矩阵配置 | 作业类型组合、策略、区域范围 |
| 作业票冲突提示 | 提交/许可前展示冲突列表和关联票 |
| 协调审批 | 协调人查看冲突详情并给出意见 |
| 冲突台账 | 按区域、时间、类型统计 |

## 10. 验收标准

- 冲突矩阵可按作业类型组合配置 WARN/COORDINATE/BLOCK 策略。
- 同区域时间重叠作业可被自动识别。
- BLOCK 策略命中时作业票不得提交或许可。
- COORDINATE 策略可走协调审批后继续流程。
- 冲突扫描结果可在作业票详情和审计中追溯。
- 冲突次数可按区域和作业类型组合统计。
