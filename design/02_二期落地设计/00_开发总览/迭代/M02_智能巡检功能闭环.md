## 1. 目标与边界

**Must**：检查表模板、巡检路线、计划调度、任务执行、NFC/二维码签到、异常登记、漏检统计、转隐患。

**Won't**：EAM 深度集成、无人机巡检、GIS 路线绘制。

## 2. 功能闭环

```text
配置检查表和路线
 -> 创建巡检计划
 -> 自动生成任务
 -> 移动端/NFC 执行
 -> 异常登记和完成任务
 -> 漏检扫描
 -> 异常转隐患/报警
 -> 统计报表
```
