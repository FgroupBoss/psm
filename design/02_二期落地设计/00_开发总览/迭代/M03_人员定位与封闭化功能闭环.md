> **落地设计**：[03_人员定位与封闭化/落地设计.md](../../03_人员定位与封闭化/落地设计.md) · 服务 `psm-location-service` :18103

## 1. 目标与边界

**Must**：标签绑定、实时位置、历史轨迹、电子围栏、定位事件接入、门禁/车辆记录、区域人数、报警联动。

**Won't**：自研定位硬件、UWB 算法、车辆调度系统。

## 2. 功能闭环

```text
准入通过人员绑定标签
 -> 实时位置/轨迹采集
 -> 围栏规则监测
 -> 越界/超员/SOS 事件接入
 -> 转报警中心
 -> 门禁/车辆进出记录
 -> 作业票区域人数校验
 -> 离场解绑
```

## 3. 依赖与输出

| 能力 | 用法 |
| --- | --- |
| 承包商/主数据 | 人员绑定和准入校验 |
| 作业票 | 区域人数、到场交叉验证 |
| 报警中心 | 定位事件标准化接入 |

## 4. 核心 API

`/api/location/tags` · `/api/location/tags/{tagNo}/bind` · `/api/location/locations/realtime` · `/api/location/locations/tracks` · `/api/location/geofences` · `/api/location/events/ingest` · `/api/location/areas/{id}/headcount` · `/api/location/gate/records/ingest`

## 5. 数据对象

`loc_tag`、`loc_tag_binding`、`loc_realtime`、`loc_track_point`、`loc_geofence`、`loc_event`、`gate_access_record`、`vehicle_access_record`
