## 1. 目标与边界

**Must**：风险单元、风险事件、管控措施、风险清单、隐患上报、派单、整改、复查、销项、逾期升级、统计。

**Won't**：完整 PHA/HAZOP 分析、Bowtie 可视化编辑器、集团级风险对标。

## 2. 功能闭环

```text
划分风险单元
 -> 维护风险事件和管控措施
 -> 发布风险清单
 -> 巡检/上报/报警发现隐患
 -> 分级派单和整改
 -> 复查销项
 -> 逾期升级和统计复盘
```

## 3. 依赖与输出

| 能力 | 用法 |
| --- | --- |
| 主数据 | 区域、装置、设备、组织、人员 |
| 重大危险源 | 危险源关联风险单元和隐患 |
| 配置规则 | 隐患逾期、作业阻断规则 |
| 输出 | `/hazards/overdue-check` 供作业票规则调用 |

## 4. 核心 API

`/api/dual-prevention/risk-units` · `/api/dual-prevention/risk-units/tree` · `/api/dual-prevention/hazards` · `/api/dual-prevention/hazards/{id}/confirm` · `/api/dual-prevention/hazards/{id}/rectify` · `/api/dual-prevention/hazards/{id}/review` · `/api/dual-prevention/hazards/overdue-check` · `/api/dual-prevention/hazards/statistics`

## 5. 数据对象

`dp_risk_unit`、`dp_risk_event`、`dp_control_measure`、`dp_hazard_report`、`dp_hazard_action`、`dp_hazard_attachment`、`dp_hazard_escalation`
