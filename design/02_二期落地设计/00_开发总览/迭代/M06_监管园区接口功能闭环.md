## 1. 目标与边界

**Must**：平台配置、字段/编码映射、定时/手动上报、回执处理、失败重试、对账报表、审计。

**Won't**：全国所有监管平台一次性全适配、监管平台反向下发指令处理（除非项目明确要求）。

## 2. 功能闭环

```text
配置监管平台和映射
 -> 调度抽取业务数据
 -> 组装报文并签名
 -> 调用监管接口
 -> 解析回执
 -> 失败重试和补报
 -> 对账和审计
 -> 二期 UAT 签收
```

## 3. 依赖与输出

| 能力 | 用法 |
| --- | --- |
| M01～M05 + 一期模块 | 双重预防、作业票、危险源、报警等数据源 |
| 调度 | XXL-Job 或内置调度 |
| 输出 | 监管合规数据交换 |

## 4. 核心 API

`/api/integration/reg/platforms` · `/api/integration/reg/mappings` · `/api/integration/reg/tasks` · `/api/integration/reg/tasks/trigger` · `/api/integration/reg/tasks/{id}/retry` · `/api/integration/reg/reconciliation` · `/api/integration/reg/preview`

`reg_platform_config`、`reg_field_mapping`、`reg_code_mapping`、`reg_report_task`、`reg_report_receipt`、`reg_retry_queue`、`reg_reconciliation`
