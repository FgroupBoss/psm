# 智能巡检落地设计

## 1. 模块目标

提供**巡检计划、路线、检查表、任务执行和异常处理**能力，支撑日常工艺巡检、设备点检和安全检查，并与双重预防、报警、隐患和重大危险源联动。

## 2. 功能范围

| 子模块 | 二期范围 |
| --- | --- |
| 检查表模板 | 检查项、标准值、异常判定、拍照要求 |
| 巡检路线 | 路线、顺序、NFC/二维码点位、预计时长 |
| 巡检计划 | 周期（日/周/月/自定义）、责任班组、自动生成任务 |
| 巡检任务 | 待执行、执行中、已完成、漏检、异常 |
| 现场执行 | 扫码/NFC 签到、逐项录入、异常拍照、离线草稿同步 |
| 异常处理 | 异常转隐患、转报警、转维修工单预留 |
| 统计分析 | 完成率、漏检率、异常率、按路线/人员统计 |

## 3. 关键流程

### 3.1 计划生成任务

```text
维护检查表和路线
 -> 配置巡检计划（周期、范围、责任人）
 -> 调度器按周期生成任务
 -> 推送到 Web/移动端待办
 -> 执行人领取或自动分配
```

### 3.2 现场执行

```text
打开巡检任务
 -> 按路线到达点位并扫码/NFC 签到
 -> 填写检查表
 -> 正常项提交 / 异常项拍照说明
 -> 全部点位完成后提交任务
 -> 异常项转隐患或报警（可选）
```

## 4. 状态机

```text
待执行 -> 执行中 -> 已完成
待执行/执行中 -> 漏检（超时未完成）
执行中 -> 异常待处理 -> 已完成
```

## 5. 数据设计

| 表 | 说明 |
| --- | --- |
| `insp_checklist_template` | 检查表模板 |
| `insp_checklist_item` | 检查项 |
| `insp_route` | 巡检路线 |
| `insp_route_point` | 路线点位（NFC/二维码/区域） |
| `insp_plan` | 巡检计划 |
| `insp_task` | 巡检任务 |
| `insp_task_item` | 任务检查项执行结果 |
| `insp_sign_record` | 点位签到记录 |
| `insp_abnormal_record` | 异常记录 |

## 6. 关键字段

### 6.1 巡检任务 `insp_task`

| 字段 | 说明 |
| --- | --- |
| task_no | 任务编号 |
| plan_id | 来源计划 |
| route_id | 巡检路线 |
| scheduled_start | 计划开始时间 |
| scheduled_end | 计划结束时间 |
| executor_id | 执行人 |
| status | 待执行、执行中、已完成、漏检 |
| completion_rate | 完成率 |
| abnormal_count | 异常项数 |

### 6.2 检查项执行 `insp_task_item`

| 字段 | 说明 |
| --- | --- |
| item_id | 检查项 |
| result_value | 实测值 |
| result_status | 正常、异常、跳过 |
| photo_urls | 异常照片 |
| remark | 备注 |
| checked_at | 检查时间 |

## 7. 联动规则

| 场景 | 规则 |
| --- | --- |
| 重大危险源 | 危险源绑定默认巡检计划和路线 |
| 隐患 | 异常项可一键生成隐患草稿 |
| 报警 | 关键设备巡检异常可触发业务报警 |
| 承包商 | 外委巡检任务可限定承包商人员执行 |

## 8. 接口设计

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/checklist-templates` | GET/POST | 检查表模板 |
| `/routes` | GET/POST | 巡检路线 |
| `/plans` | GET/POST | 巡检计划 |
| `/tasks` | GET | 任务列表 |
| `/tasks/{id}/start` | POST | 开始任务 |
| `/tasks/{id}/sign-in` | POST | 点位签到 |
| `/tasks/{id}/items` | PUT | 提交检查项结果 |
| `/tasks/{id}/complete` | POST | 完成任务 |
| `/tasks/{id}/abnormals` | POST | 登记异常 |
| `/tasks/overdue-scan` | POST | 漏检扫描（调度） |
| `/tasks/statistics` | GET | 巡检统计 |

## 9. 移动端要求

- 支持弱网草稿缓存，恢复网络后幂等同步。
- NFC/二维码签到必须记录时间、点位、操作人。
- 异常项必须支持拍照，不允许空提交。
- 漏检任务在列表中显著标识。

## 10. 验收标准

- 巡检计划可按周期自动生成任务。
- 执行人可通过扫码/NFC 完成路线签到和检查表填写。
- 超时未完成任务可标记漏检并统计。
- 异常项可转隐患并保留巡检来源。
- 重大危险源可查看关联巡检计划和最近执行记录。
- 巡检完成率、漏检率、异常率可报表统计。
