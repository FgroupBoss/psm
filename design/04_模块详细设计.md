# 04 模块详细设计

## 1. 危险工作票模块

### 1.1 作业类型

一期内置 GB 30871-2022 八类特殊作业：

- 动火作业
- 受限空间作业
- 盲板抽堵作业
- 高处作业
- 吊装作业
- 临时用电作业
- 动土作业
- 断路作业

可扩展企业自定义作业：开挖、射线探伤、检维修、试压、清罐、带压堵漏、动设备检修等。

### 1.2 功能设计

| 功能 | 说明 |
| --- | --- |
| 作业申请 | 选择作业类型、区域、设备、时间、人员、承包商、作业内容 |
| 风险辨识 | JSA/JHA 表单、风险矩阵、危险源选择、措施库推荐 |
| 条件校验 | 人员资质、培训、承包商准入、证书有效期、区域风险、报警状态 |
| 关联票证 | 同一作业包可关联动火、受限空间、临电、盲板等多票 |
| 审批流 | 按作业级别、区域、承包商、时间、风险等级动态路由 |
| 现场许可 | 二维码/NFC 到场、定位、照片、气体检测、措施逐项确认 |
| 作业监护 | 监护签到、过程检查、异常上报、暂停/恢复、延期 |
| 完工验收 | 清场、设备恢复、盲板复位、隔离解除、验收签字 |
| 归档审计 | 全链路操作日志、电子签名、附件、版本快照 |

### 1.3 状态机

```text
草稿 -> 已提交 -> 风险评审中 -> 审批中 -> 待现场许可 -> 作业中
作业中 -> 暂停 -> 作业中
作业中 -> 待验收 -> 已关闭
任意审批前状态 -> 已退回/已取消
作业中/暂停 -> 强制终止
```

### 1.4 自动控制规则

- 作业开始前必须完成所有必填安全措施确认。
- 气体检测结果超过阈值或检测超时，动火/受限空间不得许可。
- 监护人未到场、作业负责人未签到，不得开始作业。
- 作业期间区域发生一级/二级报警，自动提醒暂停或触发强制复核。
- 同一区域交叉作业达到规则阈值时，触发作业协调审批。
- 承包商人员证书过期、培训失效、黑名单命中，禁止加入作业人员。

## 2. 重大危险源模块

### 2.1 档案管理

- 危险源名称、编码、类型、级别、所在区域、装置、储存介质。
- 设计容量、实际容量、临界量、R 值、辨识依据。
- 包保责任人、技术负责人、操作负责人、联系方式。
- 关联设备、储罐、管线、监测点位、安全设施、消防设施、应急预案。
- 备案资料、评估报告、检测报告、平面图、P&ID、SDS。

### 2.2 在线监测

接入数据：

- 温度、压力、液位、流量、密度、阀位。
- 可燃气体、有毒气体、氧含量、火灾报警。
- 视频 AI 事件、人员定位、车辆定位、门禁。
- 消防水压、喷淋、泡沫、联锁状态、UPS/电源状态。

展示：

- 实时卡片、趋势曲线、报警时间线、区域 GIS/3D 可视化。
- 安全屏障健康度：仪表、联锁、报警、消防、巡检、人员响应。
- 风险热力图：按装置、区域、危险源、报警等级聚合。

### 2.3 风险联动

- 危险源附近有动火、受限空间、吊装等作业时提高区域动态风险。
- 报警未关闭时限制新增高风险作业。
- 关键安全设施检修或失效时触发屏障降级和补偿措施。
- 巡检漏检、隐患逾期、报警频发时提高管理风险评分。

## 3. 报警系统模块

### 3.1 报警来源

- DCS/SIS/PLC/SCADA/实时数据库。
- GDS 可燃/有毒气体报警、火灾报警。
- 视频 AI：烟火、人员闯入、未戴 PPE、离岗、聚集。
- 人员定位：越界、静止、跌倒、超员、失联。
- 作业票规则：超时、措施未确认、监护缺失、冲突作业。
- 设备/巡检/隐患：巡检异常、隐患逾期、设备故障。

### 3.2 报警处理能力

| 能力 | 说明 |
| --- | --- |
| 分级 | 一级/二级/三级/提示，可按企业制度配置 |
| 去重 | 同源重复报警合并，保留次数和持续时间 |
| 关联 | 按时间、区域、设备、危险源、作业票聚类 |
| 抑制 | 检维修、停用、已知工况下规则化抑制，需审批和审计 |
| 派发 | 按区域、班组、值班表、专业自动派单 |
| 升级 | 超时未确认/未处置自动升级到上级 |
| 联动 | 推送预案、视频画面、点位趋势、附近人员和作业票 |
| 复盘 | 报警原因、处置时长、误报、漏报、重复报警分析 |

### 3.3 报警闭环状态

```text
新报警 -> 已确认 -> 处置中 -> 待复核 -> 已关闭
新报警/已确认/处置中 -> 已升级
任意状态 -> 误报关闭（需原因和权限）
```

## 4. 承包商系统模块

### 4.1 单位管理

- 基本信息、统一社会信用代码、业务范围、联系人。
- 安全资质、施工资质、保险、合同、HSE 协议。
- 准入评审、年度复审、黑名单、奖惩记录。
- 绩效评分：违章、事故、隐患、培训、作业质量、整改及时率。

### 4.2 人员管理

- 身份信息、所属单位、岗位、工种、联系方式。
- 特种作业证、职业健康、保险、培训考试、入厂教育。
- 人脸/门禁/定位标签绑定。
- 作业记录、违章记录、黑名单、离场记录。

### 4.3 准入规则

- 单位未准入或资质过期，禁止申请作业。
- 人员未通过入厂教育、安全考试或证书过期，禁止进场/加入作业票。
- 高风险作业要求对应工种证书，如焊工、电工、起重、登高等。
- 违章达到阈值自动停权，需整改和复训后恢复。

## 5. 双重预防与隐患模块

- 风险单元、风险事件、管控措施、责任岗位、检查周期。
- 隐患上报、整改、复查、销项、逾期升级。
- 巡检计划、巡检路线、检查表、扫码/NFC、异常拍照。
- 与作业票、报警、重大危险源、承包商绩效联动。

## 6. MOC 与 PSM 扩展模块

二期建议扩展：

- 变更申请、影响分析、PHA 触发、审批、实施、验证、关闭。
- PHA/HAZOP 节点、偏差、原因、后果、保护层、建议项。
- LOPA、Bowtie、屏障管理、SIL 相关信息管理。
- PSSR 开车前安全审查。
- 事故事件调查、根因分析、纠正预防措施。
