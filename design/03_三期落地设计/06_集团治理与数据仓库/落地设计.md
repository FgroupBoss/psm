# 集团治理与数据仓库落地设计

## 1. 模块目标

建立集团级多基地治理、统一指标口径和数据仓库能力，支撑集团 HSE/PSM 管理层跨基地查看风险、作业、报警、隐患、变更、事故和整改绩效。

## 2. 功能范围

| 子模块 | 三期范围 |
| --- | --- |
| 集团模板 | 制度模板、检查模板、指标模板、版本下发 |
| 基地映射 | 基地、组织、区域、装置、业务分类映射 |
| 指标口径 | 指标定义、统计周期、维度、权限、目标值 |
| 数据仓库 | 作业、报警、隐患、巡检、MOC、PHA、事故主题事实表 |
| 驾驶舱 | 风险态势、整改效率、报警绩效、变更和事故趋势 |
| 审计改进 | 审计问题、整改任务、复查、闭环统计 |

## 3. 关键流程

### 3.1 指标治理

```text
定义集团指标
 -> 配置基地映射
 -> 抽取主题数据
 -> 生成指标快照
 -> 驾驶舱展示
 -> 异常指标下钻追溯
```

### 3.2 审计改进

```text
发起集团审计
 -> 记录审计问题
 -> 分派基地整改
 -> 上传证据
 -> 集团复查
 -> 关闭和统计
```

## 4. 状态机

### 4.1 审计问题状态

```text
待分派 -> 整改中 -> 待复查 -> 已关闭
待复查 -> 已退回
任意非关闭 -> 已逾期（并行标记）
```

### 4.2 模板版本状态

```text
草稿 -> 待发布 -> 已发布 -> 已停用
已发布 -> 修订中 -> 已发布
```

## 6. 关键字段

### 6.1 指标定义 `gov_metric_definition`

| 字段 | 说明 |
| --- | --- |
| metric_code | 指标编码 |
| metric_name | 指标名称 |
| metric_domain | 作业、报警、隐患、MOC、事故、PHA |
| statistic_period | 日、周、月、季、年 |
| formula_version | 公式版本 |
| target_value | 目标值 |
| owner_org_id | 指标责任组织 |
| enabled_flag | 是否启用 |

### 6.2 指标快照 `gov_metric_snapshot`

| 字段 | 说明 |
| --- | --- |
| metric_code | 指标编码 |
| site_id | 基地 ID |
| period_start | 周期开始 |
| period_end | 周期结束 |
| metric_value | 指标值 |
| target_value | 目标值 |
| calculation_time | 计算时间 |
| input_hash | 输入数据摘要 |

## 7. 联动规则

| 场景 | 规则 |
| --- | --- |
| 权限 | 集团用户可看授权基地汇总，基地用户只能看本基地 |
| 模板 | 集团模板发布后基地可继承并维护差异化配置 |
| 指标 | 指标计算保留公式版本和输入摘要，便于审计复核 |
| 审计 | 审计问题可转隐患或 CAPA，也可独立闭环 |
| 驾驶舱 | 异常指标必须支持下钻到业务明细或快照 |

## 8. 接口设计

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/governance/templates` | GET/POST | 集团模板维护 |
| `/governance/templates/{id}/publish` | POST | 模板发布 |
| `/governance/sites` | GET/POST | 基地映射 |
| `/governance/metrics` | GET/POST | 指标定义 |
| `/governance/metrics/snapshots` | GET | 指标快照查询 |
| `/governance/audit-issues` | GET/POST | 审计问题 |
| `/governance/dashboard/overview` | GET | 集团驾驶舱 |
| `/governance/benchmark` | GET | 跨基地对标 |

## 9. 页面设计

| 页面 | 关键能力 |
| --- | --- |
| 集团驾驶舱 | 多基地风险、作业、报警、隐患、MOC、事故概览 |
| 指标管理 | 指标定义、口径、目标值、启停 |
| 指标快照 | 周期值、趋势、同比环比、下钻 |
| 模板管理 | 模板版本、发布、基地继承 |
| 审计整改 | 问题分派、整改、复查、关闭 |

## 10. 验收标准

- 集团模板可版本化发布并支持基地差异化映射。
- 指标口径可统一维护，并按周期生成快照。
- 数据仓库可汇总作业、报警、隐患、MOC、PHA、事故主题数据。
- 驾驶舱可跨基地对标并下钻追溯。
- 审计问题可完成分派、整改、复查和关闭。
