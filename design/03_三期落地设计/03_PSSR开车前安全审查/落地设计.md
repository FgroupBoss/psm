# PSSR 开车前安全审查落地设计

## 1. 模块目标

建立 Pre-Startup Safety Review（PSSR）能力，对新建、改造、检维修或重大变更后的装置和设备进行开车前安全确认，确保关键问题关闭后方可批准开车。

## 2. 功能范围

| 子模块 | 三期范围 |
| --- | --- |
| PSSR 项目 | 项目立项、关联 MOC/装置/设备/检维修计划 |
| 清单模板 | 按装置类型、变更类型、专业维护检查项 |
| 审查执行 | 现场检查、责任专业、照片附件、签字 |
| 问题整改 | 问题分级、整改、复查、关闭 |
| 开车批准 | 条件校验、批准/退回、签字和归档 |
| 联动查询 | 对生产调度或作业票提供开车批准状态 |

## 3. 关键流程

```text
创建 PSSR 项目
 -> 选择清单模板
 -> 分派审查任务
 -> 执行现场检查
 -> 问题分级和整改
 -> 关键问题复查关闭
 -> 批准开车
 -> 归档报告
```

## 4. 状态机

### 4.1 PSSR 项目状态

```text
草稿 -> 待审查 -> 审查中 -> 整改中 -> 待批准 -> 已批准 -> 已归档
待批准 -> 已退回
草稿/待审查 -> 已取消
```

### 4.2 PSSR 问题状态

```text
待整改 -> 整改中 -> 待复查 -> 已关闭
待复查 -> 已退回
```

## 5. 数据设计

| 表 | 说明 |
| --- | --- |
| `pssr_project` | PSSR 项目 |
| `pssr_template` | 清单模板 |
| `pssr_check_item` | 检查项 |
| `pssr_execution_record` | 执行记录 |
| `pssr_issue` | 审查问题 |
| `pssr_approval_record` | 开车批准记录 |

## 6. 关键字段

### 6.1 PSSR 项目 `pssr_project`

| 字段 | 说明 |
| --- | --- |
| pssr_no | PSSR 编号 |
| project_name | 项目名称 |
| source_type | MOC、检维修、开停车计划、手工 |
| source_biz_id | 来源业务 ID |
| area_id | 区域 |
| equipment_id | 设备 |
| planned_startup_at | 计划开车时间 |
| approval_status | 未批准、已批准、退回 |
| status | 项目状态 |

### 6.2 问题 `pssr_issue`

| 字段 | 说明 |
| --- | --- |
| issue_level | A、B、C 类 |
| check_item_id | 检查项 ID |
| description | 问题描述 |
| owner_user_id | 整改责任人 |
| due_at | 整改期限 |
| close_required_before_startup | 是否开车前必须关闭 |
| status | 问题状态 |

## 7. 联动规则

| 场景 | 规则 |
| --- | --- |
| MOC | 重大变更关闭前必须完成 PSSR |
| 作业票 | 开车准备作业未关闭时提示 PSSR 风险 |
| 屏障管理 | 关键屏障健康度异常时不得批准开车 |
| 报警 | 开车前关键报警未恢复时阻断批准 |
| 通知 | PSSR 问题逾期自动通知责任人和负责人 |

## 8. 接口设计

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/pssr/projects` | GET/POST | PSSR 项目查询和创建 |
| `/pssr/templates` | GET/POST | 清单模板维护 |
| `/pssr/projects/{id}/execute` | POST | 提交审查执行记录 |
| `/pssr/issues` | GET/POST | 问题查询和新增 |
| `/pssr/issues/{id}/rectify` | POST | 问题整改 |
| `/pssr/issues/{id}/review` | POST | 问题复查 |
| `/pssr/projects/{id}/approve-startup` | POST | 批准开车 |
| `/pssr/projects/{id}/startup-check` | GET | 开车条件查询 |

## 9. 页面设计

| 页面 | 关键能力 |
| --- | --- |
| PSSR 台账 | 项目、来源、装置、状态、计划开车时间 |
| 清单模板 | 专业、检查项、问题等级、是否开车前必关 |
| 现场审查 | 检查项执行、附件、问题创建 |
| 问题整改 | 整改、复查、逾期、证据 |
| 开车批准 | 条件汇总、签字、批准/退回 |

## 10. 验收标准

- PSSR 可关联 MOC、检维修或开停车计划。
- 清单模板可按装置类型和变更类型复用。
- A 类问题或开车前必关问题未关闭时不得批准开车。
- 开车批准状态可供外部模块查询。
- 审查、整改、签字和附件可审计追溯。
