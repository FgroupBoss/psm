## 1. 目标与边界

**Must**：PSSR 项目、清单模板、审查执行、问题整改、开车批准、MOC/检维修/作业联动。

**Won't**：替代生产调度系统、自动执行开车控制命令。

## 2. 功能闭环

```text
创建 PSSR 项目
 -> 选择清单模板和审查团队
 -> 执行现场审查
 -> 发现问题并分级整改
 -> 验证关闭关键问题
 -> 批准开车或退回整改
 -> 归档审计
```

## 3. 依赖与输出

| 能力 | 用法 |
| --- | --- |
| MOC | 变更完成后触发 PSSR |
| 作业票 | 检维修和开车准备作业状态校验 |
| 屏障管理 | 关键屏障有效性校验 |
| 输出 | 开车批准、整改项、阻断规则 |

## 4. 核心 API

`/api/pssr/projects` · `/api/pssr/templates` · `/api/pssr/projects/{id}/execute` · `/api/pssr/issues` · `/api/pssr/issues/{id}/rectify` · `/api/pssr/projects/{id}/approve-startup` · `/api/pssr/projects/{id}/reject-startup`

## 5. 数据对象

`pssr_project`、`pssr_template`、`pssr_check_item`、`pssr_execution_record`、`pssr_issue`、`pssr_approval_record`
