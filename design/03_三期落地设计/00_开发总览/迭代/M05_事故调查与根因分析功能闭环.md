## 1. 目标与边界

**Must**：事故/未遂事件报告、调查立项、时间线、证据、访谈、根因分析、CAPA、经验反馈。

**Won't**：替代法务取证系统、自动判责、公开事故通报门户。

## 2. 功能闭环

```text
事件报告或转入调查
 -> 分级和调查立项
 -> 收集证据、访谈和时间线
 -> 根因分析
 -> 制定 CAPA
 -> 整改验证和复盘
 -> 反哺风险库、培训和规则
```

## 3. 依赖与输出

| 能力 | 用法 |
| --- | --- |
| 报警/隐患/作业票 | 可转事故或未遂事件 |
| 文件服务 | 存储证据、照片、报告 |
| 通知 | CAPA 逾期升级 |
| 输出 | CAPA、经验反馈、风险库更新建议 |

`/api/incidents` · `/api/incidents/{id}/start-investigation` · `/api/incidents/{id}/timeline` · `/api/incidents/{id}/evidence` · `/api/incidents/{id}/root-causes` · `/api/incidents/{id}/capa` · `/api/incidents/capa/{id}/verify` · `/api/incidents/{id}/lessons-learned`
