## 1. 目标与边界

**Must**：屏障台账、屏障健康度、降级管理、补偿措施、机械完整性计划、检验、缺陷、维修闭环。

**Won't**：替代 EAM/CMMS 全功能资产管理，三期聚焦 PSM 关键设备和安全屏障。

## 2. 功能闭环

```text
建立屏障和关键设备台账
 -> 绑定危险源/HAZOP 场景/报警/巡检
 -> 采集检验、缺陷、报警、作业状态
 -> 计算健康度并识别降级
 -> 制定补偿措施和维修任务
 -> 验证恢复并归档
```

## 3. 依赖与输出

| 能力 | 用法 |
| --- | --- |
| 重大危险源 | 关联安全屏障和关键设备 |
| 报警/巡检 | 作为健康度输入 |
| 作业票 | 屏障降级时限制高风险作业 |
| 输出 | 健康度、降级事件、补偿措施、维修需求 |
