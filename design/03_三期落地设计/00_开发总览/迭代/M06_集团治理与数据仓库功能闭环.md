## 1. 目标与边界

**Must**：集团模板、多基地映射、指标口径、数据仓库、驾驶舱、审计、跨基地对标。

**Won't**：完整 BI 自助建模平台、商业化计费、多租户 SaaS 运营后台。

## 2. 功能闭环

```text
定义集团模板和指标口径
 -> 映射基地组织、区域和业务数据
 -> 抽取一二三期主题数据
 -> 生成数据仓库和指标快照
 -> 展示驾驶舱和对标分析
 -> 下发审计问题和改进任务
```

## 3. 依赖与输出

| 能力 | 用法 |
| --- | --- |
| 全业务模块 | 作为主题数据来源 |
| IAM | 控制集团、基地、区域数据权限 |
| 报表服务 | 展示指标、趋势和驾驶舱 |
| 输出 | 集团指标、审计问题、改进任务、数据集市 |
