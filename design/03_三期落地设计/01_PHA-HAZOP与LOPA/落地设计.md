# PHA/HAZOP 与 LOPA 落地设计

## 1. 模块目标

建立结构化 PHA/HAZOP 与 LOPA 能力，支撑装置级过程危害分析、保护层评估、建议项整改和周期复审，补齐完整 PSM 风险分析基础。

## 2. 功能范围

| 子模块 | 三期范围 |
| --- | --- |
| PHA 项目 | 项目立项、装置范围、团队、会议、版本和复审计划 |
| HAZOP 节点 | 节点、设计意图、参数、引导词、偏差 |
| 原因后果 | 偏差原因、后果、严重度、频率和风险等级 |
| 保护层 | 现有保护层、报警、联锁、操作规程、应急措施 |
| 建议项 | 建议项分派、整改、验证、关闭和逾期升级 |
| LOPA | 场景、初始事件频率、IPL、目标风险、SIL 建议 |
| 报告归档 | 分析表、建议项清单、LOPA 报告、版本快照 |

## 3. 关键流程

### 3.1 HAZOP 分析

```text
创建 PHA 项目
 -> 划分分析节点
 -> 选择参数和引导词
 -> 识别偏差、原因和后果
 -> 评估风险和现有保护层
 -> 形成建议项
 -> 审核发布分析版本
```

### 3.2 LOPA 评估

```text
选择高风险场景
 -> 维护初始事件频率
 -> 录入独立保护层和 PFD
 -> 计算中间事件频率
 -> 对比目标风险
 -> 输出 SIL 或新增保护层建议
```

## 4. 状态机

### 4.1 PHA 项目状态

```text
草稿 -> 分析中 -> 待评审 -> 已发布 -> 复审中 -> 已归档
草稿/分析中 -> 已取消
```

### 4.2 建议项状态

```text
待分派 -> 整改中 -> 待验证 -> 已关闭
整改中/待验证 -> 已退回
任意非关闭 -> 已逾期（并行标记）
```

| --- | --- |
| `pha_project` | PHA 项目 |
| `pha_node` | HAZOP 分析节点 |
| `hazop_deviation` | 偏差分析 |
| `hazop_cause` | 偏差原因 |
| `hazop_consequence` | 后果 |
| `hazop_safeguard` | 保护层 |
| `pha_recommendation` | 建议项 |

| `lopa_ipl` | 独立保护层 |

## 6. 关键字段

### 6.1 PHA 项目 `pha_project`

| 字段 | 说明 |
| --- | --- |
| project_no | 项目编号 |
| project_name | 项目名称 |
| site_id | 所属基地 |
| unit_id | 装置/区域 |
| major_hazard_id | 关联重大危险源 |
| method | HAZOP、What-if、Checklist 等 |
| version | 分析版本 |
| review_due_at | 下次复审时间 |
| status | 草稿、分析中、待评审、已发布、复审中、已归档 |

### 6.2 LOPA 场景 `lopa_scenario`

| 字段 | 说明 |
| --- | --- |
| scenario_no | 场景编号 |
| project_id | PHA 项目 ID |
| deviation_id | 关联偏差 |
| initiating_event_frequency | 初始事件频率 |
| consequence_severity | 后果严重度 |
| target_frequency | 目标频率 |
| mitigated_frequency | 保护后频率 |
| sil_recommendation | SIL 建议 |
| calculation_version | 计算模型版本 |

## 7. 联动规则

| 场景 | 规则 |
| --- | --- |
| MOC | 高风险变更可触发 PHA 复审或新增 LOPA 场景 |
| 屏障管理 | HAZOP 保护层可转为屏障台账 |
| 双重预防 | HAZOP 风险可沉淀为风险事件和管控措施 |
| 作业票 | 未关闭高风险建议项可作为作业审批提示 |
| 培训 | PHA 更新后可生成岗位培训需求 |

## 8. 接口设计

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/pha/projects` | GET/POST | PHA 项目查询和新增 |
| `/pha/projects/{id}/nodes` | GET/POST | 节点维护 |
| `/pha/nodes/{id}/deviations` | GET/POST | 偏差分析 |
| `/pha/recommendations` | GET/POST | 建议项维护 |
| `/pha/recommendations/{id}/close` | POST | 建议项关闭 |
| `/pha/lopa-scenarios` | GET/POST | LOPA 场景维护 |
| `/pha/lopa-scenarios/{id}/calculate` | POST | LOPA 计算 |
| `/pha/projects/{id}/report` | GET | 分析报告导出 |

## 9. 页面设计

| 页面 | 关键能力 |
| --- | --- |
| PHA 项目台账 | 项目、装置、状态、复审期限筛选 |
| HAZOP 分析表 | 节点、偏差、原因、后果、保护层、建议项维护 |
| 建议项台账 | 责任人、期限、状态、逾期筛选 |
| LOPA 计算页 | 场景、IPL、频率计算、SIL 建议 |
| PHA 报告 | 版本、分析表、建议项、附件和导出 |

## 10. 验收标准

- PHA 项目可维护节点、团队、会议和复审计划。
- HAZOP 分析可形成结构化偏差、原因、后果和保护层。
- 建议项可分派、整改、验证、关闭并逾期升级。
- LOPA 可完成 IPL 录入和风险频率计算。
- 分析结果可关联危险源、风险单元、屏障和 MOC。
- 关键操作可审计追溯。
