# 屏障管理与机械完整性落地设计

## 1. 模块目标

建立安全屏障和机械完整性管理能力，将重大危险源、HAZOP 场景、报警、巡检、检验、缺陷和作业状态纳入屏障健康度计算，支撑风险动态管控。

## 2. 功能范围

| 子模块 | 三期范围 |
| --- | --- |
| 屏障台账 | 屏障、屏障元素、类型、责任人、关联场景 |
| 健康度 | 基于检验、报警、巡检、缺陷、旁路、作业状态计算 |
| 降级管理 | 屏障失效、旁路、降级、补偿措施、恢复验证 |
| 机械完整性 | 关键设备台账、检验计划、检验记录 |
| 缺陷维修 | 缺陷分级、维修任务、复查关闭 |
| 风险联动 | 作业票、报警、危险源、PSSR 的规则查询 |

## 3. 关键流程

### 3.1 屏障健康管理

```text
建立屏障台账
 -> 绑定危险源/HAZOP 场景/设备
 -> 接入检验、报警、巡检、缺陷状态
 -> 计算健康度
 -> 识别降级或失效
 -> 制定补偿措施
 -> 恢复验证并归档
```

### 3.2 机械完整性闭环

```text
维护关键设备
 -> 制定检验计划
 -> 执行检验
 -> 发现缺陷
 -> 维修整改
 -> 复查关闭
 -> 更新设备可靠性指标
```

## 4. 状态机

### 4.1 屏障状态

```text
正常 -> 降级 -> 失效
降级/失效 -> 恢复中 -> 正常
正常 -> 停用
```

### 4.2 缺陷状态

```text
待确认 -> 待维修 -> 维修中 -> 待复查 -> 已关闭
待复查 -> 已退回
```

## 6. 关键字段

### 6.1 屏障 `barrier`

| 字段 | 说明 |
| --- | --- |
| barrier_code | 屏障编码 |
| barrier_name | 屏障名称 |
| barrier_type | 工程、仪表、管理、应急 |
| major_hazard_id | 关联重大危险源 |
| hazop_scenario_id | 关联 HAZOP/LOPA 场景 |
| owner_org_id | 责任部门 |
| health_score | 当前健康度 |
| status | 正常、降级、失效、停用 |

### 6.2 缺陷 `mi_defect`

| 字段 | 说明 |
| --- | --- |
| defect_no | 缺陷编号 |
| equipment_id | 设备 ID |
| defect_level | 一般、重要、重大 |
| source_type | 检验、巡检、报警、人工 |
| description | 缺陷描述 |
| repair_deadline | 维修期限 |
| status | 缺陷状态 |

## 7. 联动规则

| 场景 | 规则 |
| --- | --- |
| 作业票 | 区域关键屏障失效时，高风险作业阻断或升级审批 |
| PSSR | 开车前关键屏障必须正常或有批准的补偿措施 |
| 报警 | 重复报警降低相关屏障健康度 |
| 巡检 | 屏障相关巡检漏检或异常影响健康度 |
| MOC | 变更影响屏障时必须复核并更新台账 |

## 9. 页面设计

| 页面 | 关键能力 |
| --- | --- |
| 屏障台账 | 类型、区域、危险源、状态、健康度 |

## 10. 验收标准

- 屏障可关联危险源、HAZOP/LOPA 场景和关键设备。
- 健康度可基于多源输入计算并保留快照。
- 屏障降级可生成补偿措施并触发风险联动。
- 关键设备检验、缺陷和维修可闭环。
- 作业票和 PSSR 可查询屏障状态进行规则判断。
