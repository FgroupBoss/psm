# 消息通知落地设计

## 1. 模块目标

统一承载一期**站内信**能力，满足「通知走消息中心、业务模块不直连外通道」的全局约束。短信、邮件、企业微信、钉钉仅预留通道枚举与发送日志，一期不实现真实外发。

## 2. 边界

| 能力 | 归属 | 说明 |
| --- | --- | --- |
| 可办任务（待办） | `psm-mobile-bff` | 聚合作业票、报警等「待处理动作」 |
| 提醒消息（通知） | `psm-notification-service` | 升级、到期、超时等站内信收件箱 |
| 通知模板配置 | `psm-config-rule-service` | `/api/config/notifications/templates` |
| 报警侧发送记录 | `psm-alarm-service` | `alarm_notification_record` 对账 |

## 3. 数据表

| 表 | 说明 |
| --- | --- |
| `notification_message` | 用户收件箱（已读/未读） |
| `notification_delivery_log` | 发送尝试与结果 |

## 4. 接口

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/api/notifications/health` | GET | 健康检查 |
| `/api/notifications/send` | POST | 业务/内部发送（幂等键 `requestId`） |
| `/api/notifications/inbox` | GET | 收件箱分页 |
| `/api/notifications/{id}` | GET | 消息详情 |
| `/api/notifications/{id}/read` | POST | 标记已读 |
| `/api/notifications/read-all` | POST | 全部已读 |

## 5. 一期业务接入

| 场景 | 触发 | 模板编码 |
| --- | --- | --- |
| 报警升级 | `AlarmEscalationServiceImpl` | `ALARM_ESCALATION` |
| 证书到期 | 承包商定时任务 | `CERT_EXPIRE_WARN` |
| 作业超时 | 作业票定时任务 | `WKP_TIMEOUT_WARN` |

## 6. 验收

- AC-N01：send 后 inbox 可查到未读消息
- AC-N02：同 `requestId` 幂等不重复
- AC-N03：模板/参数缺失返回可解释错误
- AC-N04：未认证访问 inbox 经网关返回 401
