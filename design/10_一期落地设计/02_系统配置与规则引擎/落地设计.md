# 系统配置与规则引擎落地设计

## 1. 模块目标

支撑作业票、报警、承包商和通知等能力配置化，减少一期试点现场因制度差异产生的硬编码改造。

## 2. 功能范围

| 子模块 | 一期范围 |
| --- | --- |
| 字典配置 | 作业类型、风险等级、报警等级、证书类型、单位、状态 |
| 表单模板 | 八大特殊作业票字段、必填规则、安全措施模板 |
| 流程配置 | 审批节点、审批人规则、加签、转办、超时提醒 |
| 规则配置 | 资质、培训、证书、气体检测、区域报警、延期 |
| 通知配置 | 站内信，短信、邮件、企业微信/钉钉预留 |
| 附件配置 | 文件类型、大小限制、业务归属、保留策略 |

## 3. 配置生效原则

- 配置必须有生效状态：草稿、已发布、已停用。
- 已发布配置原则上不直接覆盖，变更生成新版本。
- 业务单据引用配置时记录配置版本，保证归档可回放。
- 高风险配置变更必须审计，包括审批流、报警阈值、强制拦截规则。

## 4. 规则引擎设计

### 4.1 规则调用场景

| 场景 | 调用时机 | 输出 |
| --- | --- | --- |
| 作业票提交 | 申请人提交审批前 | 是否允许提交、阻断原因、提醒项 |
| 现场许可 | 许可人开工前 | 是否允许许可、需升级审批项 |
| 作业延期 | 延期申请时 | 是否允许延期、是否需要审批 |
| 报警接入 | 报警进入系统时 | 等级、是否合并、关联对象 |
| 承包商选人 | 添加作业人员时 | 人员是否合格、证书培训风险 |

### 4.2 规则结果模型

| 字段 | 说明 |
| --- | --- |
| passed | 是否通过 |
| level | BLOCK/WARN/PASS |
| rule_code | 规则编码 |
| message | 面向用户的提示 |
| evidence | 命中依据，如证书编号、报警编号 |
| suggestion | 建议处理方式 |

## 5. 核心规则清单

| 规则 | 等级 | 一期处理 |
| --- | --- | --- |
| 作业区域停用 | BLOCK | 禁止提交 |
| 承包商未准入 | BLOCK | 禁止选择或提交 |
| 人员培训不合格 | BLOCK | 禁止加入作业 |
| 特种作业证过期 | BLOCK | 禁止参与对应作业 |
| 气体检测不合格 | BLOCK | 禁止现场许可 |
| 气体检测超有效期 | BLOCK | 禁止现场许可 |
| 监护人未签到 | BLOCK | 禁止现场许可 |
| 区域高等级报警未关闭 | BLOCK/WARN | 按配置阻断或升级审批 |
| 作业超出计划结束时间 | WARN/BLOCK | 提醒延期或自动暂停 |

## 6. 接口设计

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/config/dictionaries` | GET/POST | 字典查询和维护 |
| `/config/forms` | GET/POST | 表单模板维护 |
| `/config/workflows` | GET/POST | 审批流配置 |
| `/config/rules/evaluate` | POST | 通用规则评估 |
| `/config/notifications/templates` | GET/POST | 通知模板维护 |

## 7. 数据设计

| 表 | 说明 |
| --- | --- |
| `sys_dict_type` / `sys_dict_item` | 字典类型和字典项 |
| `form_template` | 表单模板 |
| `form_template_field` | 表单字段 |
| `workflow_template` | 流程模板 |
| `workflow_node` | 流程节点 |
| `rule_definition` | 规则定义 |
| `rule_version` | 规则版本 |
| `notification_template` | 通知模板 |
| `file_attachment` | 附件元数据 |

## 8. 验收标准

- 可配置作业类型、风险等级、报警等级和证书类型。
- 动火和受限空间作业票可通过模板控制字段和安全措施。
- 审批流可按作业类型、风险等级、区域选择审批人。
- 规则引擎可返回明确阻断原因。
- 配置发布、停用、变更均有审计记录。
