# 一期开发总览

## 1. 目标

一期研发目标是支撑试点区域上线运行，形成“基础数据可用、承包商可校验、危险源可关联、报警可闭环、作业票可现场许可、移动端可留痕、报表可验收”的最小业务闭环。

## 2. 范围边界

### 2.1 一期必须交付

- 基础主数据：组织、用户、岗位、区域、装置、设备、监测点位。
- 权限审计：登录、角色、菜单、按钮、数据权限、操作日志、关键变更审计。
- 系统配置：字典、表单模板、审批流、规则、通知、附件。
- 承包商：单位、人员、资质、证书、培训、违章、黑名单。
- 重大危险源：档案、分级、责任人、点位绑定、附件、报警和作业关联。
- 报警中心：报警接入、分级、去重、确认、派发、处置、升级、关闭。
- 危险工作票：八大特殊作业票，优先动火和受限空间完整闭环。
- 移动端：待办、签到、气体检测、措施确认、拍照、电子签名、监护。
- 报表大屏：作业、报警、重大危险源、承包商基础统计。

### 2.2 一期不做

- 完整 PHA/HAZOP、LOPA、Bowtie。
- 完整 MOC、PSSR 和机械完整性管理。
- 复杂三维数字孪生。
- AI 自动生成风险分析结论。
- DCS/SIS 反向控制。
- 集团级多租户商业计费。

## 3. 研发迭代顺序

### 3.1 第 1 迭代：平台底座

交付模块：
- 基础主数据与权限审计。
- 系统配置与规则引擎基础能力。

完成标准：
- 用户可登录并按角色访问菜单。
- 区域、装置、设备、点位可维护。
- 操作日志可记录关键新增、修改、删除。
- 字典、附件、通知模板、审批流配置具备基础能力。

### 3.2 第 2 迭代：准入与风险对象

交付模块：
- 承包商准入。
- 重大危险源档案。

完成标准：
- 承包商单位和人员可完成准入审核。
- 证书、培训、黑名单状态可被规则接口查询。
- 重大危险源可绑定区域、责任人、点位和附件。

### 3.3 第 3 迭代：报警闭环

交付模块：
- 报警中心基础闭环。
- 报警规则、升级、通知。

完成标准：
- 工业报警或模拟报警可进入系统。
- 报警可分级、去重、确认、派发、处置、关闭。
- 高等级报警可影响作业许可规则判断。

### 3.4 第 4 迭代：作业票核心闭环

交付模块：
- 危险工作票 Web 端核心流程。
- 动火、受限空间优先完整闭环。
- 作业风险规则校验。

完成标准：
- 作业票可创建、提交、审批、许可、暂停、恢复、验收、归档。
- 承包商资质、人员证书、培训、气体检测、区域报警可参与拦截。
- 状态流转符合 PRD 状态机。

### 3.5 第 5 迭代：移动现场闭环

交付模块：
- 移动端待办和现场动作。
- 附件、拍照、电子签名、弱网草稿。

完成标准：
- 手机端可完成现场签到、措施确认、气体检测、签名和监护。
- 许可开工必须在线校验。
- 关键动作记录人员、时间、终端、位置或扫码结果。

### 3.6 第 6 迭代：报表、验收和上线

交付模块：
- 报表大屏。
- 数据迁移、接口联调、验收用例、上线切换。

完成标准：
- 报表指标可追溯到明细。
- 试点区域完成端到端 UAT。
- 完成部署、备份、监控、培训和上线切换。

## 4. 跨模块依赖

| 依赖方 | 被依赖方 | 说明 |
| --- | --- | --- |
| 作业票 | 基础主数据 | 作业区域、设备、人员、组织权限 |
| 作业票 | 承包商 | 外来单位和人员资格校验 |
| 作业票 | 报警中心 | 区域高等级报警阻断或升级审批 |
| 作业票 | 系统配置 | 表单模板、审批流、安全措施、规则 |
| 报警中心 | 重大危险源 | 报警关联危险源和责任人 |
| 报警中心 | 监测点位 | 点位映射区域、设备和阈值 |
| 移动端 | 作业票 | 现场许可和监护任务 |
| 报表大屏 | 全部业务模块 | 统计指标和明细追溯 |

## 5. 全局设计约束

- 所有关键操作必须审计：人、时间、终端、操作对象、前后值、结果。
- 所有业务主表保留创建人、创建时间、更新人、更新时间、删除标记或状态。
- 附件统一走文件中心，不在业务表存储大文件。
- 通知统一走消息中心，不在业务模块直接对接短信、邮件或企业微信。
- 规则校验必须返回可解释的阻断原因，供 Web 和移动端展示。
- 工业数据只读接入，不做控制反写。

## 6. 完成定义

- 模块设计评审通过。
- 数据表、接口、状态机、权限点、审计点明确。
- 核心验收用例通过。
- 关键异常路径有明确提示和审计。
- 与上下游模块完成联调。
- 试点用户完成 UAT 确认。
