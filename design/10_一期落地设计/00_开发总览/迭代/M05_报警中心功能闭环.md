## 1. 目标与边界

**Must**：报警接入、标准化、点位映射、分级、去重、生命周期、派发处置、超时升级、误报关闭、区域活动报警检查。

**Won't**：DCS/SIS 反向控制、复杂报警根因分析、全量工业协议采集网关。

## 2. 功能闭环

```text
报警接入
 -> 标准化和点位映射
 -> 分级和去重
 -> 进入实时报警列表
 -> 值班确认
 -> 派发处置
 -> 现场反馈
 -> 复核关闭或误报关闭
 -> 超时自动升级
 -> 作业票许可前区域检查
```

## 3. 状态机

```text
NEW -> ACKED -> DISPATCHED -> PROCESSING -> PENDING_REVIEW -> CLOSED
NEW/ACKED/DISPATCHED/PROCESSING -> ESCALATED
NEW/ACKED/DISPATCHED/PROCESSING -> FALSE_CLOSED
```

## 4. 关键决策

| 项 | 方案 |
| --- | --- |
| 去重时间窗 | 默认 300s，按 `alarm_dedup_rule` |
| 升级 | `@Scheduled` 每分钟扫描 |
| blockingAlarm | major-hazard 调 `area-active-check` |
| 字典 | `ALARM_LEVEL`、`ALARM_SOURCE` |

## 5. 对外契约

| 接口 | 用途 |
| --- | --- |
| `POST /api/alarms/area-active-check` | 作业许可区域报警阻断 |
| `POST /api/alarms/ingest` | 模拟报警或外部报警接入 |

## 6. 核心 API

`/api/alarms/ingest` · `/api/alarms/events` · `/api/alarms/events/{id}` · `/api/alarms/events/{id}/ack` · `/api/alarms/events/{id}/dispatch` · `/api/alarms/events/{id}/feedback` · `/api/alarms/events/{id}/close` · `/api/alarms/events/{id}/false-close` · `/api/alarms/rules` · `/api/alarms/dedup-rules` · `/api/alarms/area-active-check`
