# M07 · 移动端现场作业功能闭环

> **状态**：✅ 已落地 · **批次**：5/5  
> **所属迭代**：第 5 迭代 · 移动现场闭环  
> **落地设计**：[07_移动端现场作业/落地设计.md](../../07_移动端现场作业/落地设计.md) · 服务 `psm-mobile-bff`

## 1. 目标与边界

**Must**：移动登录态、待办、作业票详情、现场签到、气体检测、措施确认、附件拍照、电子签名、许可开工、监护记录、暂停恢复、验收、报警反馈、弱网草稿。

**Won't**：完全离线许可开工、复杂移动原生能力、第三方 CA 签名。

## 2. 依赖

| 能力 | 用法 |
| --- | --- |
| 作业票详情/状态机 | 移动许可、监护、验收动作 |
| `pre-check` | 移动许可前全量规则校验 |
| 文件服务 | 拍照、签名和附件上传 |
| 报警中心 | 移动报警详情和处置反馈 |
| IAM 权限 | 移动菜单、待办和动作授权 |

## 3. 功能闭环

```text
移动端登录
 -> 获取角色待办
 -> 查看作业票详情
 -> 现场签到和到场确认
 -> 气体检测和措施确认
 -> 拍照上传和电子签名
 -> 在线许可开工
 -> 监护巡检和异常上报
 -> 暂停、恢复或完工验收
 -> 同步 Web 时间线和审计
```

## 5. 离线策略

| 动作 | 是否允许离线 | 要求 |
| --- | --- | --- |
| 查看最近详情 | 是 | 显示缓存时间 |
| 监护记录 | 是 | 联网后同步 |
| 拍照附件 | 是 | 本地队列重试 |
| 气体检测 | 可暂存 | 许可前必须在线提交 |
| 措施确认 | 可暂存 | 许可前必须在线校验 |
| 现场许可 | 否 | 必须在线全量 pre-check |
| 完工验收 | 否 | 必须在线签名和校验 |
