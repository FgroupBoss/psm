> **签收**：2026-05-27 · **批次**：第 2 迭代 1、4～6 批次  
> **所属迭代**：第 2 迭代 · 准入与风险对象  
> **落地设计**：[04_重大危险源/落地设计.md](../../04_重大危险源/落地设计.md) · 服务 `psm-major-hazard-service`

## 1. 目标与边界

**Must**：危险源档案、分级、区域设备绑定、包保责任人、监测点位绑定、附件、发布、状态变更、风险上下文。

**Won't**：完整 PHA/HAZOP、LOPA、Bowtie、复杂趋势预测、监管平台全量上报。

## 2. 功能闭环

```text
新建危险源档案
 -> 维护等级、介质、容量、区域和设备
 -> 配置责任人
 -> 绑定监测点位和附件
 -> 审核发布
 -> 报警按点位映射危险源
 -> 作业票按区域查询风险上下文
 -> 报表大屏统计危险源态势
```

## 3. 状态机

```text
草稿 -> 已发布 -> 检修
已发布 -> 停用
检修 -> 已发布
草稿 -> 作废
```

## 4. 对外契约

| 接口 | 用途 |
| --- | --- |
| `POST /api/major-hazards/risk-context` | 作业票创建、提交和许可前查询区域风险上下文 |
| `GET /api/major-hazards/{id}/alarms` | 危险源详情报警 Tab |
| `GET /api/major-hazards/{id}/permits` | 危险源详情作业 Tab |

`/api/major-hazards` · `/api/major-hazards/{id}` · `/api/major-hazards/{id}/publish` · `/api/major-hazards/{id}/responsibilities` · `/api/major-hazards/{id}/points` · `/api/major-hazards/{id}/attachments` · `/api/major-hazards/{id}/alarms` · `/api/major-hazards/{id}/permits` · `/api/major-hazards/risk-context`

## 6. 数据表

`major_hazard`、`major_hazard_responsibility`、`major_hazard_point_rel`、`major_hazard_attachment`、`major_hazard_status_log`、`major_hazard_audit_record`

## 7. 关键规则

| 规则 | 触发点 | 处理 |
| --- | --- | --- |
| 危险源无责任人 | 发布 | 阻断发布 |
| 未绑定区域 | 发布 | 阻断发布 |
| 关键点位停用 | 点位绑定、risk-context | 预警 |
| 高等级报警未关闭 | 作业许可 | 阻断或升级 |
| 危险源停用 | 作业票选择风险对象 | 不可引用 |
