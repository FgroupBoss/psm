# M08 · 报表大屏与上线验收功能闭环

> **状态**：✅ 已落地 · **批次**：5/5  
> **所属迭代**：第 6 迭代 · 报表与上线验收  
> **落地设计**：[08_报表大屏与上线验收/落地设计.md](../../08_报表大屏与上线验收/落地设计.md) · 服务 `psm-report-service`

## 1. 目标与边界

**Must**：作业、报警、危险源、承包商、审计统计；明细下钻；导出；大屏总览；UAT 用例；上线准备、试运行、签收。

**Won't**：复杂 BI 自助分析、实时流式大屏、全厂一次性推广。

## 2. 依赖

| 能力 | 用法 |
| --- | --- |
| 作业票 | 作业统计、超时、暂停、许可留痕 |
| 报警中心 | 报警闭环率、确认时长、处置时长 |
| 重大危险源 | 档案完整率、等级、报警态势 |
| 承包商 | 准入、证书过期、培训、违章统计 |
| 审计 | 关键操作覆盖率、配置和权限变更 |

## 3. 功能闭环

```text
定义指标口径
 -> 聚合业务数据
 -> 报表查询和明细下钻
 -> 报表导出和审计
 -> 大屏展示态势和刷新时间
 -> UAT 用例执行
 -> 缺陷修复和试运行
 -> 上线切换、培训、运维移交
 -> 签收归档
```

## 5. 指标口径

| 指标 | 口径 | 明细来源 |
| --- | --- | --- |
| 特殊作业系统办理率 | 系统内作业票数量 / 试点实际作业数量 | 作业票、线下台账 |
| 现场许可留痕率 | 有签到、检测、措施、签名的作业票 / 需许可作业票 | 作业票现场记录 |
| 承包商资质校验覆盖率 | 执行 eligibility 的承包商作业票 / 涉及承包商作业票 | 作业票人员、eligibility |
| 重大危险源档案完整率 | 必填完整危险源 / 试点危险源总数 | 危险源档案 |
| 报警闭环率 | 已关闭报警 / 应处置报警 | 报警事件 |
| 关键操作审计覆盖率 | 有审计记录关键操作 / 关键操作总数 | 中央审计、状态日志 |
