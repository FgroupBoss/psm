# 危险工作票落地设计

## 1. 模块目标

实现 GB 30871-2022 八大特殊作业票电子化闭环，覆盖创建、风险分析、审批、现场许可、监护、暂停恢复、延期、完工验收和归档。

## 2. 作业票范围

- 动火安全作业票。
- 受限空间安全作业票。
- 盲板抽堵安全作业票。
- 高处安全作业票。
- 吊装安全作业票。
- 临时用电安全作业票。
- 动土安全作业票。
- 断路安全作业票。

一期研发优先级：
- 第一优先：动火、受限空间完整闭环。
- 第二优先：高处、吊装、临时用电。
- 第三优先：盲板抽堵、动土、断路。

## 3. 状态机

```text
草稿 -> 已提交 -> 审批中 -> 待现场许可 -> 作业中 -> 待验收 -> 已关闭
审批中 -> 已退回
已退回 -> 已提交
待现场许可 -> 已取消
作业中 -> 暂停
暂停 -> 作业中
暂停 -> 强制终止
作业中 -> 强制终止
```

## 4. 核心流程

```text
新建作业票
 -> 填写作业信息和人员
 -> 规则校验基础条件
 -> 风险分析和安全措施
 -> 提交审批
 -> 审批通过
 -> 现场签到
 -> 气体检测和措施确认
 -> 电子签名许可开工
 -> 作业中监护
 -> 完工验收
 -> 关闭归档
```

## 5. 功能设计

### 5.1 作业票创建

字段：
- 作业类型、作业区域、装置、设备、计划开始/结束时间。
- 作业内容、作业负责人、许可人、监护人、作业人员。
- 承包商单位、承包商人员、附件。

规则：
- 作业开始时间不得早于当前时间，补录需特殊权限。
- 作业区域必须有效。
- 作业人员必须来自员工或已准入承包商人员。
- 必填字段缺失不得提交。

### 5.2 风险分析与安全措施

能力：
- 支持 JSA/JHA 风险分析。
- 支持风险矩阵评估风险等级。
- 按作业类型、区域、设备推荐安全措施。
- 安全措施支持适用、不适用、已完成和附件证明。

规则：
- 高风险作业必须完成风险分析。
- 必需措施未确认不得进入现场许可。

### 5.3 审批

能力：
- 按作业类型、风险等级、区域动态选择审批流。
- 支持同意、退回、驳回、加签、转办。
- 支持审批意见、附件、待办和通知。

规则：
- 审批通过前不得现场许可。
- 退回再次提交保留历史审批记录。

### 5.4 现场许可

能力：
- 扫码或定位签到。
- 确认作业人员、监护人、许可人到场。
- 录入气体检测结果。
- 逐项确认安全措施。
- 电子签名后许可开工。

规则：
- 气体检测不合格不得许可。
- 气体检测超过有效期不得许可。
- 监护人未签到不得许可。
- 区域存在未关闭高等级报警时按配置阻断或升级审批。

### 5.5 作业中监护

能力：
- 监护检查记录。
- 拍照、文字、异常上报。
- 暂停、恢复、延期、终止。
- 作业超时提醒。

规则：
- 暂停后不得完工验收，必须恢复或终止。
- 延期需重新审批或走配置化简化审批。

### 5.6 完工验收

能力：
- 作业负责人提交完工。
- 许可人或区域负责人验收。
- 确认清场、隔离解除、设备恢复、人员撤离。
- 电子签名关闭作业票。
- 生成归档快照，支持导出 PDF 或电子档案。

规则：
- 必需验收项未完成不得关闭。
- 关闭后普通用户不得修改，补正需走补正流程。

## 6. 作业风险规则

| 规则 | 阻断点 |
| --- | --- |
| 承包商未准入 | 提交 |
| 人员证书过期 | 添加人员、提交、许可 |
| 培训失效 | 添加人员、提交、许可 |
| 气体检测不合格 | 现场许可 |
| 气体检测超有效期 | 现场许可 |
| 监护人未签到 | 现场许可 |
| 区域高等级报警未关闭 | 现场许可或升级审批 |
| 作业超时未延期 | 作业中自动暂停或提醒 |

## 7. 接口设计

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/work-permits` | GET/POST | 查询和创建作业票 |
| `/work-permits/{id}` | GET/PUT | 详情和修改 |
| `/work-permits/{id}/submit` | POST | 提交审批 |
| `/work-permits/{id}/approve` | POST | 审批处理 |
| `/work-permits/{id}/risk-analysis` | GET/POST | 风险分析 |
| `/work-permits/{id}/safety-measures` | GET/POST | 安全措施 |
| `/work-permits/{id}/gas-tests` | GET/POST | 气体检测 |
| `/work-permits/{id}/site-permit` | POST | 现场许可 |
| `/work-permits/{id}/monitor-records` | GET/POST | 监护记录 |
| `/work-permits/{id}/suspend` | POST | 暂停 |
| `/work-permits/{id}/resume` | POST | 恢复 |
| `/work-permits/{id}/acceptance` | POST | 完工验收 |

## 9. 验收标准

- 动火和受限空间可完成端到端闭环。
- 八大作业票可按模板创建并进入统一状态机。
- 资质、培训、气体检测、区域报警可触发规则拦截。
- 每个关键节点可追溯人员、时间、位置、签名和附件。
- 作业票状态不允许非法跳转。
