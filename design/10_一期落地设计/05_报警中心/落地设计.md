# 报警中心落地设计

## 1. 模块目标

统一接入工业报警、业务规则报警和预留事件，形成报警分级、去重、确认、派发、处置、升级、关闭和复盘闭环。

## 2. 功能范围

| 子模块 | 一期范围 |
| --- | --- |
| 报警接入 | GDS/DCS/实时库关键报警，业务规则报警 |
| 标准化 | 来源、点位、等级、区域、设备、危险源映射 |
| 去重合并 | 同源同类短时间合并，保留次数和最近发生时间 |
| 生命周期 | 新报警、已确认、处置中、待复核、已关闭、已升级、误报关闭 |
| 派发处置 | 值班确认、派发、现场反馈、复核关闭 |
| 升级通知 | 超时未确认、超时未处置自动升级 |
| 统计复盘 | 高频报警、MTTA、MTTR、误报率 |

## 3. 状态机

```text
新报警 -> 已确认 -> 处置中 -> 待复核 -> 已关闭
新报警/已确认/处置中 -> 已升级
新报警/已确认/处置中 -> 误报关闭
```

## 4. 报警处理流程

```text
报警接入
 -> 标准化和点位映射
 -> 规则分级
 -> 去重或合并
 -> 进入实时报警列表
 -> 值班人员确认
 -> 派发处置
 -> 现场反馈
 -> 复核关闭
 -> 指标统计
```

## 5. 关键规则

| 规则 | 说明 |
| --- | --- |
| 分级 | 按来源等级、阈值、危险源等级和区域风险综合判断 |
| 去重 | 同一来源、同一指标、同一区域在时间窗口内合并 |
| 超时确认 | 一级报警必须在配置时限内确认，否则升级 |
| 超时处置 | 超过处置时限仍未关闭时升级并通知上级 |
| 误报关闭 | 需权限、原因和审计，不允许无原因关闭 |
| 作业联动 | 区域高等级报警未关闭时，作业许可阻断或升级审批 |

## 6. 页面设计

| 页面 | 关键能力 |
| --- | --- |
| 实时报警列表 | 等级、区域、来源、状态、时间筛选 |
| 报警详情 | 点位、趋势、设备、危险源、作业票、处置记录 |
| 处置任务 | 确认、派发、反馈、复核、关闭 |
| 报警规则 | 分级、去重、抑制、升级、通知配置 |
| 报警统计 | 高频报警、确认时长、处置时长、误报率 |

## 7. 接口设计

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/alarms/ingest` | POST | 报警接入 |
| `/alarms` | GET | 报警列表 |
| `/alarms/{id}` | GET | 报警详情 |
| `/alarms/{id}/confirm` | POST | 确认 |
| `/alarms/{id}/dispatch` | POST | 派发 |
| `/alarms/{id}/feedback` | POST | 处置反馈 |
| `/alarms/{id}/close` | POST | 复核关闭 |
| `/alarms/{id}/false-close` | POST | 误报关闭 |
| `/alarms/area-active-check` | POST | 区域未关闭高等级报警查询 |

## 8. 数据设计

| 表 | 说明 |
| --- | --- |
| `alarm_event` | 报警主表 |
| `alarm_occurrence` | 报警发生明细 |
| `alarm_action_record` | 确认、派发、反馈、关闭记录 |
| `alarm_escalation_record` | 升级记录 |
| `alarm_notification_record` | 通知记录 |
| `alarm_rule` | 报警规则 |
| `alarm_dedup_rule` | 去重规则 |

## 9. 验收标准

- 模拟报警可进入统一报警列表并按等级展示。
- 报警能完成确认、派发、处置、复核关闭和误报关闭。
- 重复报警可合并并保留发生次数。
- 超时未确认或未处置可自动升级。
- 关联重大危险源和作业票的报警可双向查看。
