# 承包商准入落地设计

## 1. 模块目标

建立承包商单位、人员、资质、培训、证书、违章和黑名单的准入体系，并为作业票提供强校验能力。

## 2. 功能范围

| 子模块 | 一期范围 |
| --- | --- |
| 单位管理 | 基本信息、联系人、业务范围、准入审核、复审、停权、黑名单 |
| 资质管理 | 营业执照、资质证书、保险、合同、HSE 协议 |
| 人员管理 | 人员信息、工种、联系方式、门禁卡、定位标签 |
| 证书管理 | 证书类型、编号、有效期、附件、到期提醒 |
| 培训管理 | 培训记录、考试结果、有效期 |
| 违章管理 | 违章记录、整改、扣分、停权触发 |

## 3. 状态机

### 3.1 单位状态

```text
待提交 -> 待审核 -> 已准入 -> 待复审 -> 已准入
已准入 -> 已停权
已准入/已停权 -> 黑名单
待审核 -> 已退回
```

### 3.2 人员状态

```text
待完善 -> 待审核 -> 已准入
已准入 -> 已停权
已准入/已停权 -> 黑名单
证书过期/培训失效 -> 受限准入
```

## 4. 作业票联动规则

| 校验项 | 阻断点 | 处理 |
| --- | --- | --- |
| 单位未准入 | 作业票选择承包商 | 禁止选择 |
| 单位核心资质过期 | 提交或现场许可 | 禁止提交或许可 |
| 人员未准入 | 添加作业人员 | 禁止添加 |
| 人员培训失效 | 添加作业人员 | 禁止添加 |
| 特种作业证过期 | 对应作业类型 | 禁止添加 |
| 人员黑名单 | 任意作业 | 禁止添加并提示原因 |

## 5. 页面设计

| 页面 | 关键能力 |
| --- | --- |
| 承包商单位列表 | 查询、状态筛选、新增、导入、停权、黑名单 |
| 单位详情 | 基本信息、资质、合同、人员、作业历史、违章 |
| 资质证书 | 上传、审核、到期提醒、历史版本 |
| 人员列表 | 查询、导入、证书状态、培训状态、准入状态 |
| 人员详情 | 证书、培训、违章、参与作业、门禁/定位信息 |
| 准入审核 | 审核意见、退回、通过、停权原因 |

## 6. 接口设计

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/contractors` | GET/POST | 单位查询和新增 |
| `/contractors/{id}` | GET/PUT | 单位详情和修改 |
| `/contractors/{id}/approve` | POST | 准入审核 |
| `/contractors/{id}/suspend` | POST | 停权 |
| `/contractor-workers` | GET/POST | 人员查询和新增 |
| `/contractor-workers/{id}/certificates` | GET/POST | 人员证书 |
| `/contractor-workers/{id}/trainings` | GET/POST | 培训记录 |
| `/contractor-workers/eligibility-check` | POST | 作业票选人校验 |

## 7. 数据设计

| 表 | 说明 |
| --- | --- |
| `contractor_company` | 承包商单位 |
| `contractor_qualification` | 单位资质 |
| `contractor_worker` | 承包商人员 |
| `worker_certificate` | 人员证书 |
| `worker_training_record` | 培训记录 |
| `contractor_violation` | 违章记录 |
| `contractor_blacklist` | 黑名单 |
| `contractor_audit_record` | 准入审核记录 |

## 8. 审计要求

- 准入、退回、停权、复审、黑名单必须审计。
- 资质和证书有效期变更必须记录前后值。
- 黑名单解除必须记录审批人、原因和附件。

## 9. 验收标准

- 承包商单位可完成准入、停权、复审和黑名单流程。
- 人员证书、培训、黑名单状态可影响作业票选人。
- 证书和资质过期有提醒、记录和规则拦截。
- 人员详情可查看证书、培训、作业和违章历史。
