# 一期落地设计文档目录

本文档包基于 `design/09_一期总体PRD.md` 拆解，按研发落地顺序组织。目标是把总体 PRD 转换为可评审、可开发、可测试、可上线的模块设计说明。

## 开发顺序

| 顺序 | 模块目录 | 交付重点 | 依赖关系 |
| --- | --- | --- | --- |
| 00 | `00_开发总览` | 版本范围、迭代节奏、跨模块依赖、完成标准 | 总体 PRD |
| 01 | `01_基础主数据与权限审计` | 组织、用户、区域、装置、设备、点位、RBAC、数据权限、审计 | 所有业务模块前置 |
| 02 | `02_系统配置与规则引擎` | 字典、表单模板、流程、规则、通知、附件 | 依赖基础权限 |
| 03 | `03_承包商准入` | 承包商单位、人员、资质、培训、黑名单 | 作业票人员校验前置 |
| 04 | `04_重大危险源` | 一源一档、点位绑定、责任人、附件、趋势与报警关联 | 依赖主数据和点位 |
| 05 | `05_报警中心` | 报警接入、分级、去重、确认、派发、处置、升级、关闭 | 依赖区域、点位、危险源 |
| 06 | `06_危险工作票` | 八大特殊作业票、审批、风险分析、现场许可、监护、验收 | 依赖承包商、报警、配置 |
| 07 | `07_移动端现场作业` | 待办、签到、气体检测、措施确认、拍照、签名、监护 | 依赖作业票和报警 |
| 08 | `08_报表大屏与上线验收` | 指标、报表、大屏、测试验收、上线切换 | 依赖核心业务数据 |

## 版本建议

- `V1.0.0 试点版`：完成 01-07 的核心闭环，08 完成基础统计和验收。
- `V1.1.0 扩展版`：补齐八大作业票模板细节、报警去重升级增强、危险源趋势和大屏增强。
- `V1.2.0 推广版`：全厂推广、更多接口接入、监管接口和报表指标完善。

## 使用方式

1. 产品和 HSE 专家先评审每个模块的业务规则、流程和字段。
2. 架构师和研发负责人评审接口、数据模型、状态机和依赖。
3. 测试负责人按每个模块的验收用例扩展测试用例。
4. 实施团队按上线准备清单推进主数据、模板、规则和接口联调。
