# 产品设计 · 外通道触达（短信 / 邮件 / 企微 / 钉钉）

## 1. 产品目标

在站内信基础上，按**租户策略、场景优先级、用户偏好**将关键提醒触达至手机短消息与邮箱，并预留企业 IM，满足值班响应与离线办公场景。一期仅预留通道，本专项定义 N2 起的产品规则与配置项。

## 2. 通道能力矩阵

| 通道 | 编码 | 一期 | N2 | N3 |
| --- | --- | --- | --- | --- |
| 站内信 | `IN_APP` | ✅ 已实现 | 持续增强 | — |
| 短信 | `SMS` | 枚举预留 | 真实发送 | 模板报备、回执 |
| 邮件 | `EMAIL` | 枚举预留 | 真实发送 | 附件、HTML 模板 |
| 企业微信 | `WECHAT` | 枚举预留 | — | 应用消息 |
| 钉钉 | `DINGTALK` | 枚举预留 | — | 工作通知 |

## 3. 路由策略（产品规则）

发送请求可携带 `channels[]`；未指定时按**通知模板默认渠道** + **租户开关**解析：

```text
模板默认渠道
    → 租户是否启用该通道
    → 用户偏好（若配置「仅站内信」则降级）
    → 静默时段（仅站内信，短信顺延或丢弃按策略）
    → 频控（同用户同模板 1h 内仅 1 条短信）
```

| 策略项 | 配置位置 | 说明 |
| --- | --- | --- |
| 租户通道开关 | 系统配置 | 总开关 + 分通道 |
| 场景默认渠道 | 通知模板 | 如 `ALARM_ESCALATION` = IN_APP + SMS |
| 用户偏好 | 用户设置（N2） | 紧急是否发短信 |
| 静默时段 | 租户配置 | 如 22:00–07:00 不发短信 |
| 频控 | 消息中心 | 防轰炸 |

## 4. 短信产品设计

### 4.1 内容约束

- 使用**平台报备模板**，变量占位符与站内信 `variables` 同源。
- 单条 ≤ 70 字（中文按厂商计费规则），超长截断摘要 + 「请登录平台查看」。
- 必须带**短信签名**（租户级配置）。

### 4.2 适用场景（建议默认开启短信）

| 场景 | 理由 |
| --- | --- |
| 报警升级且未确认超阈值 | 值班必须触达 |
| 特级/一级动火待审批（可配置） | 高风险 |
| 作业票强制终止通知负责人 | 安全责任 |

### 4.3 用户可见

- 消息详情页展示「已通过短信通知」及发送时间（不展示完整手机号）。
- 发送失败展示「短信发送失败，请查看站内信」（不阻断站内信）。

## 5. 邮件产品设计

### 5.1 内容

- 主题：`[PSM] {title}`
- 正文：HTML 模板（标题、摘要、业务链接、租户名称）。
- 可选附件：一期不支持；二期仅系统报告类。

### 5.2 适用场景

| 场景 | 理由 |
| --- | --- |
| 证书/资质批量到期周报 | 管理员批量处理 |
| 审批超时汇总 | 桌面办公 |
| 非紧急通知备份 | 用户偏好邮件 |

## 6. 企微 / 钉钉（N3）

- 以**应用消息**推送卡片：标题、摘要、跳转 H5/小程序链接。
- 与 OA 待办集成时，卡片「去处理」与平台深链一致。
- 需企业管理员完成应用安装与 `corpId`/`agentId` 配置。

## 7. 管理端配置页（规划）

| 配置页 | 字段示例 |
| --- | --- |
| 通道配置 | SMS 厂商、AccessKey（加密）、签名、邮件 SMTP |
| 通知模板 | `templateCode`、标题/正文模板、默认 `channels` |
| 场景路由 | 业务事件 → 模板映射 |
| 投递查询 | 按用户/时间/通道/状态筛选 `delivery_log` |

## 8. 合规与退订

- 短信需符合运营商模板审核；未审核模板不得生产发送。
- 营销类短信**禁止**；仅安全与业务必需类。
- 提供租户级「关闭短信」与关键场景白名单（报警升级可突破，需审计）。

## 9. 验收标准

- AC-EXT-01：模板配置 `IN_APP+SMS` 时，站内信必达，短信成功写入 `SENT` 回执。
- AC-EXT-02：短信失败时站内信仍成功，且 delivery_log 为 `FAILED` + 原因码。
- AC-EXT-03：频控命中时不重复发短信，日志记 `SKIPPED`。
- AC-EXT-04：日志与界面不展示完整手机号/邮箱明文。
