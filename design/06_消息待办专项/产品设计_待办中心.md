# 产品设计 · 待办中心

## 1. 产品目标

提供**可执行动作**的统一入口：Web 工作台与移动端现场待办列表一致语义，用户能快速进入「审批、许可、监护、验收、报警处置」等业务页完成操作。

## 2. 待办项模型（产品语义）

| 字段 | 说明 | 示例 |
| --- | --- | --- |
| `taskType` | 动作类型编码 | `SITE_PERMIT`、`APPROVE` |
| `bizType` | 业务实体 | `WORK_PERMIT`、`ALARM` |
| `bizId` | 业务主键 | 票证 ID |
| `title` | 展示标题 | 作业位置 + 票号 |
| `status` | 业务当前状态 | `PENDING_SITE_PERMIT` |
| `priority` | 展示优先级 | HIGH / MEDIUM / NORMAL |
| `dueAt` | 截止时间参考 | 计划结束时间 |
| `actionHint` | 动作提示文案 | 「待现场许可」 |
| `assigneeUserId` | 期望处理人（可选） | 许可人 ID |
| `deepLink` | 前端路由（可选） | `/mobile/work-permits/{id}` |

> 待办项**不落库为独立业务状态**；列表为实时聚合。关闭待办的唯一方式是完成业务动作（状态迁移）。

## 3. 页面清单

| 端 | 页面 | 功能 |
| --- | --- | --- |
| Web | 工作台待办 | 分类 Tab：全部 / 审批 / 现场 / 报警；排序、筛选 |
| Web | 待办卡片 | 标题、类型、优先级、截止时间、主按钮「处理」 |
| 移动 | 待办首页 | 与一期 `mobile-site` 待办列表对齐，支持搜索 |
| 移动 | 待办详情入口 | 进入作业票/报警详情执行动作 |

## 4. 待办类型清单

### 4.1 一期已有（移动聚合）

| taskType | bizType | 角色/条件 | actionHint |
| --- | --- | --- | --- |
| `SITE_PERMIT` | `WORK_PERMIT` | 许可人/监护人 | 待现场许可 |
| `MONITOR` | `WORK_PERMIT` | 监护人；状态 IN_PROGRESS/SUSPENDED | 待监护巡检 |
| `ACCEPTANCE` | `WORK_PERMIT` | 负责人 | 待完工验收 |
| `ALARM_FEEDBACK` | `ALARM` | 值班相关 | 待报警处置反馈 |

### 4.2 二期补齐（Web + 审批）

| taskType | bizType | 说明 |
| --- | --- | --- |
| `APPROVE` | `WORK_PERMIT` | 当前审批节点持有人；或签/会签 |
| `APPROVE` | `WORKFLOW_TASK` | 通用审批任务（联票、延期等） |
| `CERT_REVIEW` | `CONTRACTOR` | 承包商资质复审 |
| `HAZARD_RECTIFY` | `HAZARD` | 隐患整改验收 |

## 5. 列表交互

| 规则 | 说明 |
| --- | --- |
| 排序 | `priority` 降序 → `dueAt` 升序（临期优先） |
| 过滤 | 按 `taskType`、业务类型、关键字（票号/区域） |
| 角色 | Web 按登录用户权限 + 单据参与人；移动按 `MobileRole` |
| 空状态 | 明确「暂无待办」，区分未登录与无权限 |
| 刷新 | 进入页拉取；支持下拉刷新（移动） |

## 6. 与站内信联动

| 事件 | 待办 | 站内信 |
| --- | --- | --- |
| 提交审批 | 创建 `APPROVE` 待办 | 可选 `WKP_SUBMITTED` 给申请人 |
| 分配审批人 | — | `WKP_PENDING_APPROVE` 给审批人 |
| 审批通过进入待许可 | `SITE_PERMIT` | `WKP_APPROVED` 给许可人 |
| 审批驳回 | 关闭审批待办 | `WKP_REJECTED` |

原则：**待办驱动操作，站内信驱动知晓**；高优先级场景可叠加短信（见外通道设计）。

## 7. 审批待办专项（动火等票种）

与 `05_作业票专项` 审批流对齐：

| 模式 | 待办展示 |
| --- | --- |
| 或签 `ANY` | 多人并行待办；一人处理后其余自动从列表消失 |
| 会签 `ALL` | 每人独立待办；未全员完成前节点不过 |

待办卡片需展示：**票种、等级、区域、当前节点名称、剩余会签人数（可选）**。
