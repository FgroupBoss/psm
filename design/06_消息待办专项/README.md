# 06 消息待办专项

统一设计**站内信、外通道触达（短信/邮件/企微/钉钉）、待办中心**的产品与技术方案，与一期 `09_消息通知` 落地设计衔接并扩展二期能力。

## 1. 定位

| 概念 | 定义 | 用户感知 |
| --- | --- | --- |
| **通知（提醒）** | 告知类消息，不要求立即在业务单据上执行动作 | 消息中心收件箱、角标、可选外通道 |
| **待办（可办任务）** | 需当前用户在本系统内完成审批、许可、处置等动作 | 待办列表、工作台、移动端首页 |
| **外通道** | 站内信之外的触达方式 | 短信、邮件、企业微信、钉钉 |

**全局约束**（与一期开发总览一致）：业务模块**不直连**短信/邮件/IM 厂商，统一经消息中心编排；待办**不复制**业务状态，以业务单据为事实源聚合展示。
