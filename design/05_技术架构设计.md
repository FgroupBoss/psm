# 05 技术架构设计

## 1. 总体架构

```text
用户层
  Web 管理端 | 移动端 | 中控大屏 | 开放门户

应用层
  作业票 | 重大危险源 | 报警中心 | 承包商 | 双重预防 | 应急 | 报表

平台层
  工作流引擎 | 表单引擎 | 规则引擎 | 消息中心 | 文件中心 | 审计中心
  组织权限 | 电子签名 | 指标中心 | GIS/3D | 任务中心 | AI 助手

数据层
  业务库 | 时序库 | 搜索库 | 对象存储 | 缓存 | 数据仓库/湖

集成层
  API 网关 | 消息总线 | ETL/CDC | IoT 网关 | 视频网关 | 监管接口

边缘/工业层
  DCS | SIS | PLC | SCADA | GDS | FAS | PI/实时数据库 | 门禁 | 定位 | 视频 AI
```

## 2. 推荐技术路线

| 层级 | 推荐 |
| --- | --- |
| 前端 | Vue/React + TypeScript，移动端可用 Flutter/React Native/企业微信小程序 |
| 后端 | Java Spring Boot/Spring Cloud 或 .NET，按企业技术栈选择 |
| 工作流 | Flowable/Camunda/国产 BPM，支持动态审批和审计 |
| 规则引擎 | Drools/自研规则 DSL，覆盖许可校验、报警规则、风险评分 |
| 数据库 | PostgreSQL/MySQL/达梦/人大金仓，按信创要求适配 |
| 时序库 | TimescaleDB/InfluxDB/TDengine，用于传感器和报警趋势 |
| 消息 | Kafka/RabbitMQ/RocketMQ，用于报警、物联数据、通知 |
| 搜索 | Elasticsearch/OpenSearch，用于日志、票证、报警全文检索 |
| 缓存 | Redis |
| 文件 | MinIO/S3/企业对象存储 |
| 可观测 | Prometheus + Grafana + Loki/ELK + OpenTelemetry |
| 部署 | Kubernetes/容器化，支持私有化、集团云、边缘节点 |

## 3. 关键设计原则

- 工业控制隔离：平台只读接入生产控制数据，任何联动控制必须经过独立安全评估和企业批准。
- 边缘优先：工业数据采集、协议转换、断点续传、初步清洗在边缘网关完成。
- 事件驱动：报警、作业状态、人员定位、视频 AI 事件进入统一事件总线。
- 配置驱动：票证、流程、字段、审批、规则、指标均可配置。
- 可追溯：任何审批、签名、阈值、规则和报警处置必须留审计。
- 高可用：报警和作业许可属于关键业务，核心服务需支持集群、容灾和离线降级。

| 门禁/访客 | API/数据库/消息 | 进出记录、授权状态 |

## 5. 数据流

### 5.1 作业票许可数据流

```text
申请人提交作业票
 -> 表单服务保存
 -> 规则引擎校验人员/承包商/区域/报警/气体检测
 -> 工作流引擎路由审批
 -> 移动端现场确认
 -> 报警中心监听作业区域事件
 -> 作业关闭后进入审计和报表
```

### 5.2 报警数据流

```text
工业/视频/定位/业务事件
 -> 边缘网关标准化
 -> 消息总线
 -> 报警规则引擎
 -> 去重/关联/分级
 -> 报警中心派发
 -> 通知服务推送
 -> 处置记录入库
 -> 指标中心统计
```

## 6. 安全架构

- 身份认证：SSO、OAuth2/OIDC、SAML、LDAP/AD、MFA。
- 权限：RBAC + ABAC，按集团、企业、厂区、装置、区域、承包商隔离。
- 数据安全：传输 TLS，敏感字段加密，附件防病毒扫描，水印。
- 审计：不可关闭的安全审计日志，支持导出和归档。
- 接口安全：API 网关签名、限流、IP 白名单、接口审计。
- 终端安全：移动端设备绑定、定位校验、离线数据加密。
- 工业安全：OT/IT 分区、DMZ、只读采集、白名单通信、最小端口开放。

## 7. 高可用与灾备

- 核心服务无状态化，横向扩展。
- 数据库主从/集群，定期备份和恢复演练。
- 消息队列持久化，报警事件不丢失。
- 边缘网关断网缓存，恢复后补传。
- 移动端弱网离线草稿，关键许可仍需在线校验。
- 中控大屏可降级展示最近缓存数据，并明确数据时间。

## 8. 可观测性

- 技术指标：服务可用率、接口延迟、错误率、队列积压、采集延迟。
- 业务指标：作业票审批时长、报警确认时长、隐患整改率、承包商违章率。
- 数据质量：点位离线率、报警重复率、人员定位漂移、证书过期率。
- 审计指标：权限变更、规则变更、阈值变更、异常登录。
