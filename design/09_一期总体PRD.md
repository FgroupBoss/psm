# 09 一期总体 PRD

## 1. 文档信息

| 项目 | 内容 |
| --- | --- |
| 产品名称 | 企业级石油化工 PSM 安全管理平台 |
| 版本 | 一期 V1.0 |
| 文档类型 | 总体 PRD |
| 适用范围 | 危险工作票、重大危险源、报警中心、承包商准入、移动端现场作业、基础配置 |
| 目标用户 | 石油化工、煤化工、精细化工、危化品仓储等企业 |

## 2. 背景

石油化工企业在特殊作业、重大危险源、承包商和报警处置方面普遍存在以下问题：

- 作业票纸质化或半电子化，审批和现场许可脱节。
- 承包商资质、人员证书、培训记录与作业票未形成强校验。
- 重大危险源台账、监测数据、报警、隐患和作业活动分散。
- 报警推送多但闭环弱，确认、处置、升级、复盘不可追踪。
- 现场过程留痕不足，事故倒查时证据链不完整。

一期建设目标是先把高风险作业、重大危险源和报警处置管住，形成可上线、可推广、可验收的最小闭环。

## 3. 产品目标

### 3.1 业务目标

1. 实现 GB 30871-2022 八大特殊作业票电子化和全过程闭环。
2. 实现作业许可前的人员、承包商、培训、证书、气体检测、区域报警校验。
3. 建立重大危险源一源一档，关联监测点位、报警、作业和责任人。
4. 建立统一报警中心，实现报警确认、派发、处置、升级和关闭。
5. 建立承包商单位、人员、证书、培训和黑名单管理。
6. 支持移动端现场签到、确认、拍照、签名和监护。
7. 建立基础报表、审计追溯和大屏态势能力。

### 3.2 非目标

一期不做以下内容：

- 完整 PHA/HAZOP、LOPA、Bowtie。
- 完整 MOC、PSSR 和机械完整性管理。
- 复杂三维数字孪生。
- AI 自动生成风险分析结论。
- 集团级多租户商业化运营计费。
- 对 DCS/SIS 执行反向控制。

## 7. 总体业务流程

## 7.1 作业许可流程

```text
新建作业票
 -> 填写作业信息
 -> 系统校验基础条件
 -> 风险分析和安全措施
 -> 提交审批
 -> 审批通过
 -> 现场签到
 -> 气体检测/措施确认
 -> 现场许可开工
 -> 作业中监护
 -> 完工验收
 -> 关闭归档
```

异常分支：

- 审批不通过：退回申请人修改或取消。
- 条件不满足：禁止提交、禁止许可或要求补充资料。
- 作业中异常：暂停作业，整改后恢复或终止。
- 作业超时：提醒延期，超时未处理进入暂停或异常状态。

## 7.2 报警处置流程

```text
报警接入
 -> 规则分级和去重
 -> 进入报警中心
 -> 值班人员确认
 -> 派发处置
 -> 现场反馈
 -> 复核关闭
 -> 统计复盘
```

异常分支：

- 超时未确认：自动升级。
- 超时未处置：升级并通知上级。
- 误报：有权限人员填写原因后关闭。
- 重复报警：合并为同一报警事件，保留发生次数。

## 7.3 承包商准入流程

```text
录入承包商单位
 -> 上传资质和合同
 -> 审核准入
 -> 录入人员
 -> 维护证书和培训
 -> 授权参与作业
 -> 记录违章和绩效
 -> 复审或停权
```

## 8. 功能需求

## 8.1 基础主数据

### 8.1.1 组织与用户

功能：

- 支持集团、企业、厂区、部门、班组多级组织。
- 支持用户、岗位、角色、联系方式、在职状态维护。
- 支持从 HR/AD/LDAP 同步用户，手工维护作为兜底。
- 支持人员所属区域、审批权限、值班身份配置。

验收：

- 用户可按组织查询。
- 禁用用户无法登录和参与新流程。
- 用户角色变更后权限立即或按配置生效。

### 8.1.2 区域、装置、设备

功能：

- 维护厂区、区域、装置、设备层级。
- 支持设备编码、名称、类型、所属区域、状态。
- 支持区域风险等级和是否重大危险源区域标识。

验收：

- 作业票、报警、重大危险源均可选择或关联区域/设备。
- 区域停用后不可新建关联作业。

### 8.1.3 监测点位

功能：

- 维护点位编码、名称、来源系统、原始点号、单位、阈值。
- 支持点位与区域、设备、重大危险源绑定。
- 支持在线、离线、停用状态。

验收：

- 报警事件能根据点位映射到区域、设备和重大危险源。
- 点位停用需记录原因和操作审计。

## 8.2 权限与审计

功能：

- 支持账号密码登录，预留 SSO 接口。
- 支持菜单、按钮、接口权限。
- 支持按企业、厂区、区域、装置的数据权限。
- 支持操作日志和关键数据变更审计。

关键审计范围：

- 作业票提交、审批、许可、暂停、恢复、关闭。
- 报警确认、派发、关闭、误报关闭。
- 承包商准入、停权、黑名单。
- 点位阈值、报警规则、流程配置、权限变更。

验收：

- 未授权用户无法访问越权数据。
- 关键操作可追溯到人、时间、终端、操作前后内容。

## 8.3 危险工作票

### 8.3.1 作业票创建

功能：

- 选择作业类型、区域、装置、设备、计划时间。
- 填写作业内容、作业负责人、监护人、作业人员、承包商。
- 支持复制历史作业票创建新票。
- 支持上传附件，如方案、图纸、照片。

规则：

- 作业开始时间不得早于当前时间，补录需特殊权限。
- 作业人员必须来自员工或已准入承包商人员。
- 作业区域必须有效。

验收：

- 不同作业类型展示对应表单字段。
- 必填字段缺失时不能提交。

### 8.3.2 风险分析与安全措施

功能：

- 支持 JSA/JHA 风险分析。
- 支持风险矩阵评估风险等级。
- 支持按作业类型、区域、设备推荐安全措施。
- 支持逐项确认措施是否适用、是否完成。

规则：

- 高风险作业必须完成风险分析。
- 必需措施未确认不得进入现场许可。

验收：

- 风险分析记录可随作业票归档。
- 安全措施确认人、时间、附件可追溯。

### 8.3.3 审批

功能：

- 支持按作业类型、风险等级、区域动态选择审批流。
- 支持同意、退回、驳回、加签、转办。
- 支持审批意见和附件。
- 支持待办、消息提醒。

规则：

- 审批通过前不得现场许可。
- 退回后再次提交需保留历史审批记录。

验收：

- 审批流转符合配置。
- 审批记录完整展示。

### 8.3.4 现场许可

功能：

- 移动端扫码或定位签到。
- 现场确认作业人员、监护人、许可人到场。
- 录入气体检测结果。
- 逐项确认安全措施。
- 电子签名后许可开工。

规则：

- 气体检测不合格不得许可。
- 气体检测超过有效期不得许可。
- 监护人未签到不得许可。
- 区域存在未关闭高等级报警时不得许可或需升级审批。

验收：

- 现场许可记录包含人员、时间、位置、签名、检测数据。
- 条件不满足时系统明确提示阻断原因。

### 8.3.5 作业中监护

功能：

- 记录监护检查。
- 支持拍照、文字、异常上报。
- 支持暂停、恢复、延期、终止。
- 支持作业超时提醒。

规则：

- 暂停后不得进行完工验收，必须恢复或终止。
- 延期需重新审批或按配置走简化审批。

验收：

- 监护记录可按时间线查看。
- 暂停和恢复有原因、人员、时间和附件。

### 8.3.6 完工验收

功能：

- 作业负责人提交完工。
- 许可人/区域负责人验收。
- 确认清场、隔离解除、设备恢复、人员撤离。
- 电子签名关闭作业票。

规则：

- 未完成必需验收项不得关闭。
- 关闭后普通用户不得修改，需补正流程。

验收：

- 已关闭作业票生成归档快照。
- 可导出作业票 PDF 或电子档案。

## 8.4 重大危险源

功能：

- 建立重大危险源档案。
- 维护危险源等级、介质、容量、区域、责任人、预案。
- 绑定监测点位、设备、安全设施。
- 展示实时值、趋势、报警记录、关联作业票。
- 支持附件管理，如评估报告、备案材料、SDS、平面图。

规则：

- 危险源必须绑定责任人和区域。
- 关键点位离线超过阈值触发报警。
- 危险源区域高等级报警未关闭时，影响作业许可。

验收：

- 能按危险源查看档案、点位、报警、作业和附件。
- 点位数据能进入趋势图和报警中心。

## 8.5 报警中心

功能：

- 接入工业报警、业务规则报警、人员定位/视频 AI 事件预留。
- 支持报警分级、去重、合并、关联区域和设备。
- 支持确认、派发、处置、复核、关闭。
- 支持报警升级和通知。
- 支持误报关闭，但必须填写原因。
- 支持报警统计和高频报警 TOP。

规则：

- 一级报警必须在配置时限内确认。
- 超时未确认或未处置自动升级。
- 报警关闭必须填写处置结论。
- 报警规则和阈值变更必须审计。

验收：

- 报警全生命周期状态清晰。
- 能按区域、等级、来源、状态筛选。
- 关联重大危险源和作业票的报警可双向查看。

## 8.6 承包商管理

### 8.6.1 单位管理

功能：

- 维护承包商基本信息、联系人、业务范围。
- 上传营业执照、资质证书、保险、合同、HSE 协议。
- 支持准入审核、复审、停权、黑名单。

规则：

- 单位未准入不得参与新增作业。
- 单位核心资质过期自动停权或预警。

验收：

- 承包商准入状态能影响作业票选择。
- 资质过期有提醒和记录。

### 8.6.2 人员管理

功能：

- 维护承包商人员、工种、联系方式、证书、培训。
- 支持证书到期提醒。
- 支持培训考试结果维护。
- 支持黑名单和违章记录。

规则：

- 人员未培训合格不得加入作业票。
- 特种作业证过期不得参与对应作业。
- 黑名单人员不得进场或参与作业。

验收：

- 作业票选人时能实时校验人员状态。
- 人员详情能查看证书、培训、作业和违章历史。

## 8.7 移动端

功能：

- 登录和待办。
- 查看作业票详情。
- 现场签到。
- 气体检测录入。
- 安全措施确认。
- 拍照和附件上传。
- 电子签名。
- 监护检查、异常上报、暂停/恢复。
- 报警查看和处置反馈。

规则：

- 移动端关键动作必须记录时间、人员和终端。
- 需要现场真实性的动作应记录定位或扫码结果。
- 弱网情况下可保存草稿，许可开工必须在线校验。

验收：

- 手机端能完成作业现场许可和监护核心流程。
- 附件上传失败时有重试机制和明确提示。

## 8.8 报表与大屏

功能：

- 作业票统计：类型、状态、区域、风险等级、超时、暂停。
- 报警统计：等级、区域、来源、确认时长、处置时长、高频报警。
- 重大危险源态势：数量、等级、在线率、报警状态。
- 承包商统计：准入、证书过期、培训合格、违章。
- 大屏展示：厂区风险态势、作业态势、报警态势、重大危险源。

验收：

- 报表数据可追溯到明细。
- 大屏数据刷新时间明确展示。

## 8.9 系统配置

功能：

- 字典配置：作业类型、风险等级、报警等级、证书类型等。
- 表单模板配置：不同作业票字段和措施。
- 流程配置：审批节点、审批人规则、超时规则。
- 规则配置：资质、培训、气体检测、报警联动、延期。
- 通知配置：短信、企业微信/钉钉、站内信、邮件预留。

验收：

- 配置变更有审计。
- 配置生效范围和时间明确。

## 9. 状态机

## 9.1 作业票状态

```text
草稿
 -> 已提交
 -> 审批中
 -> 待现场许可
 -> 作业中
 -> 待验收
 -> 已关闭

审批中 -> 已退回
已退回 -> 已提交
待现场许可 -> 已取消
作业中 -> 暂停
暂停 -> 作业中
暂停 -> 强制终止
作业中 -> 强制终止
```

## 9.2 报警状态

```text
新报警
 -> 已确认
 -> 处置中
 -> 待复核
 -> 已关闭

新报警/已确认/处置中 -> 已升级
新报警/已确认/处置中 -> 误报关闭
```

## 9.3 承包商状态

```text
待提交 -> 待审核 -> 已准入 -> 已停权
已准入 -> 待复审 -> 已准入
已准入/已停权 -> 黑名单
```

## 10. 数据需求

## 10.1 主数据

- 组织、部门、班组。
- 用户、岗位、角色。
- 区域、装置、设备。
- 承包商单位、承包商人员。
- 监测点位、报警来源。
- 作业类型、证书类型、风险等级、报警等级。

## 10.2 业务数据

- 作业票、风险分析、安全措施、审批记录、气体检测、现场确认、监护记录、验收记录。
- 重大危险源档案、责任人、点位绑定、附件。
- 报警事件、处置记录、升级记录、通知记录。
- 承包商资质、人员证书、培训记录、违章记录。

## 10.3 数据迁移

一期上线前建议迁移：

- 当前有效承包商单位和人员。
- 未过期人员证书和培训记录。
- 重大危险源台账。
- 区域、装置、设备和点位清单。

历史作业票可不全量迁移，按审计需要导入最近 3-12 个月摘要或附件归档。

## 12. 非功能需求

## 12.1 性能

- 普通列表查询响应时间 P95 <= 3 秒。
- 作业票提交、审批、许可响应时间 P95 <= 2 秒。
- 报警进入系统到展示延迟 P95 <= 10 秒，具体以现场网络和数据源能力校准。
- 大屏刷新周期可配置，默认 10-30 秒。

## 12.2 可用性

- 核心服务支持集群部署。
- 系统可用性目标 >= 99.5%。
- 报警数据和作业票数据不得因服务重启丢失。
- 移动端支持弱网重试和草稿保存。

## 12.3 安全

- 全站 HTTPS/TLS。
- 密码加密存储。
- 敏感信息脱敏展示。
- 支持接口鉴权、签名、限流和 IP 白名单。
- 关键操作强审计，不允许普通管理员删除审计日志。

## 12.4 兼容性

- Web 支持 Chrome、Edge 最近两个稳定版本。
- 移动端支持主流 Android 设备，iOS 按企业要求适配。
- 私有化部署支持企业内网环境。

## 12.5 可维护性

- 票证模板、审批流、规则、字典、通知配置可后台维护。
- 系统提供健康检查、日志、指标和告警。
- 接口失败需记录错误并支持重试。

## 13. 权限需求

| 权限对象 | 控制方式 |
| --- | --- |
| 菜单 | 按角色授权 |
| 按钮 | 创建、审批、许可、暂停、关闭、导出等操作授权 |
| 数据 | 按企业、厂区、区域、装置授权 |
| 特殊操作 | 阈值修改、误报关闭、强制终止、黑名单需高权限 |
| 移动端 | 按角色展示待办和可执行动作 |

## 14. 通知需求

通知渠道：

- 站内信。
- 短信预留。
- 企业微信/钉钉预留。
- 邮件预留。

通知场景：

- 作业票待审批。
- 作业票退回、通过、即将开始、即将超时。
- 作业现场许可待处理。
- 报警新产生、超时未确认、超时未处置、升级。
- 证书、资质、培训即将过期。
- 承包商停权或黑名单。

## 15. 验收标准

## 15.1 总体验收

- 一期范围内所有模块能在试点区域完成端到端业务闭环。
- 关键流程有完整审计记录。
- 关键数据能按角色和数据权限隔离。
- 报表指标与明细数据一致。
- 系统完成部署、备份、监控和培训。

## 15.2 核心场景验收

| 场景 | 验收标准 |
| --- | --- |
| 动火作业闭环 | 创建、审批、气体检测、许可、监护、验收、归档全流程可完成 |
| 受限空间作业闭环 | 人员、气体检测、措施确认和监护记录完整 |
| 资质拦截 | 证书过期、培训失效、黑名单人员不能加入作业 |
| 区域报警联动 | 高等级报警未关闭时，关联区域作业许可被阻断或升级审批 |
| 报警闭环 | 报警可确认、派发、处置、升级、关闭，状态和记录完整 |
| 重大危险源视图 | 可查看档案、点位、报警、作业票和责任人 |
| 移动端现场许可 | 可完成签到、措施确认、气体检测、拍照、签名 |
| 审计追溯 | 关键操作可追溯到人、时间、终端和内容 |

## 16. 上线策略

### 16.1 试点范围

建议选择一个典型装置或区域试点：

- 作业频率较高。
- 有重大危险源或关键监测点位。
- 管理边界清晰。
- 现场团队配合度高。

### 16.2 上线步骤

1. 主数据清洗和导入。
2. 作业票模板、审批流、规则配置。
3. 承包商和人员证书导入。
4. 重大危险源和点位绑定。
5. 报警接入和规则调试。
6. 关键用户培训。
7. 试运行 2-4 周。
8. 问题修复和规则优化。
9. 正式上线。
10. 推广到其他区域。

## 17. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 现场人员不愿使用 | 优先优化移动端高频流程，减少录入字段 |
| 数据质量差 | 上线前做主数据清洗，设置数据责任人 |
| 点位映射不准确 | 建立点位字典和现场复核机制 |
| 报警过多 | 先接关键报警，逐步优化去重和分级规则 |
| 审批流程过复杂 | 一期按关键风险节点设计，非必要节点后移 |
| 承包商数据不完整 | 设置准入过渡期，关键证书先强校验 |
| 纸质与系统双轨长期并行 | 明确试点期后系统为准，纸质仅作应急兜底 |
