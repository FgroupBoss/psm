# 技术设计 · 多存储适配器

## 1. 适配器接口

```java
public interface StorageAdapter {
    String backend();  // LOCAL, MINIO, ALIYUN_OSS, ...

    StoredObject store(StoreContext ctx, InputStream in, String fileName);

    InputStream open(StoredObjectRef ref);

    void delete(StoredObjectRef ref);

    PresignedUrl presignGet(StoredObjectRef ref, Duration ttl, String downloadFileName);

    HealthCheckResult testConnection(StorageProfileConfig config);
}
```

| 类型 | 说明 |
| --- | --- |
| `StoreContext` | tenantId、profile、bizType、contentType |
| `StoredObject` | bucket、objectKey、size、sha256、backend |
| `StoredObjectRef` | 从 `file_object` 还原 |

`FileStorageProfileResolver` 根据 tenant + profileCode + bizType 路由选择 `StorageAdapter` Bean。

## 2. 实现清单与依赖

| backend | 实现类 | 连接方式 | Maven 依赖建议 |
| --- | --- | --- | --- |
| `LOCAL` | `LocalStorageAdapter` | 已有 `LocalFileStorageSupport` 迁移 | 无 |
| `MINIO` | `MinioStorageAdapter` | MinIO Java SDK / OkHttp | `io.minio:minio` |
| `ALIYUN_OSS` | `AliyunOssStorageAdapter` | 阿里云 OSS SDK | `com.aliyun.oss:aliyun-sdk-oss` |
| `TENCENT_COS` | `TencentCosStorageAdapter` | 腾讯 COS SDK | `com.qcloud:cos_api` |
| `HUAWEI_OBS` | `HuaweiObsStorageAdapter` | 华为 OBS SDK | `com.huaweicloud:esdk-obs-java` |
| `QINIU_KODO` | `QiniuKodoStorageAdapter` | 七牛 SDK | `com.qiniu:qiniu-java-sdk` |
| `BAIDU_BOS` | `BaiduBosStorageAdapter` | 百度 BOS SDK | `com.baidubce:bce-java-sdk` |
| `S3_COMPAT` | `S3CompatStorageAdapter` | AWS SDK v1 S3 客户端指自定义 endpoint | `com.amazonaws:aws-java-sdk-s3` |

**原则**：业务层只依赖接口；厂商 SDK 仅在对应 Adapter 模块或类路径内加载。

## 4. 对象键规范

```text
{tenantId}/{yyyyMM}/{uuid}_{sanitizedFileName}
```

- 禁止 `..` 与绝对路径；`sanitizedFileName` 与现网一致替换非法字符。
- 跨租户禁止共享前缀。

## 5. HTTP 网关模式（可选）

若客户已有**统一对象存储网关**（不支持直连 SDK），可增加：

| backend | 说明 |
| --- | --- |
| `HTTP_GATEWAY` | POST 字节或预签名申请 JSON 到 `httpUrl`，由客户网关写入 OSS/COS |

请求体字段：`tenantId`、`fileName`、`contentBase64` 或 `streamUrl`、`backendHint`。

用于极端定制；默认仍优先官方 SDK Adapter。

## 6. 分片上传（F2 预留）

| 接口 | 说明 |
| --- | --- |
| `POST /api/files/multipart/init` | 返回 uploadId |
| `POST /api/files/multipart/{uploadId}/parts` | 上传分片 |
| `POST /api/files/multipart/{uploadId}/complete` | 合并并写 `file_object` |

大文件（>100MB）视频类场景使用；一期不实现。

## 7. Bean 注册

```text
StorageAdapterRegistry
  → 启动时注册各 Adapter
  → 按 storage_backend 查找
  → 未启用厂商不创建 Bean（@ConditionalOnProperty）
```

平台 `psm.file.enabled-backends=LOCAL,MINIO,ALIYUN_OSS` 控制打包体积。

## 8. 失败与重试

| 场景 | 处理 |
| --- | --- |
| 上传超时 | 客户端重试；服务端不写 file_object |
| 元数据已写、对象失败 | 事务：先 store 后 insert；insert 失败则 delete 对象 |
| 下载对象丢失 | 404 + 日志 alarm |

## 9. 验收（技术）

- AC-ADP-01：仅配置 MinIO 环境变量即可上传并在 MinIO 可见。
- AC-ADP-02：切换租户 profile 为 COS 后新记录 `storage_backend=TENCENT_COS`。
- AC-ADP-03：错误 AK 时 test 接口返回 FAILED 且不保存 profile 为 default。
