# 07 文件系统专项

统一设计**附件上传、下载、预览、存储后端选型**及与 **SSO/平台鉴权** 的协同方案。支持**本地磁盘、MinIO、国内主流云对象存储**，租户按配置选择存储，**填配置即可启用**，业务模块不直连厂商 SDK。

## 1. 定位

| 概念 | 定义 |
| --- | --- |
| **文件元数据** | `file_object` 表：谁、何时、关联哪条业务、存储在哪、校验值 |
| **存储后端** | 实际字节落盘位置：LOCAL / MINIO / 阿里云 OSS / 腾讯 COS 等 |
| **存储配置档** | 租户级「用哪套后端 + 连接参数」，可多套、一套为默认 |
| **访问鉴权** | 平台 Token（含 SSO 登录态）或短时签名 URL，禁止裸链越权 |

**全局约束**：业务模块（作业票、报警、移动端等）统一走 **`/api/files`** 或 `FileClient`；禁止在业务服务内散落各云厂商 SDK。

## 4. 支持的后端（摘要）

| 编码 | 说明 | 典型场景 |
| --- | --- | --- |
| `LOCAL` | 本地目录（一期已实现） | 开发、私有化小规模 |
| `MINIO` | S3 兼容自建对象存储 | 私有化、园区机房 |
| `ALIYUN_OSS` | 阿里云对象存储 | 国内公有云 |
| `TENCENT_COS` | 腾讯云对象存储 | 国内公有云 |
| `HUAWEI_OBS` | 华为云对象存储 | 国企/政务云 |
| `QINIU_KODO` | 七牛云 | CDN 加速场景 |
| `BAIDU_BOS` | 百度云 BOS | 混合云 |
| `S3_COMPAT` | 通用 S3 兼容（除 MinIO 外的兼容端点） | 其他兼容存储 |

租户在管理端选择**默认存储配置档**；可按 `bizType` 覆盖（如监管导出走 COS、现场照片走 MinIO）。

## 5. 分期建议（摘要）

| 批次 | 范围 |
| --- | --- |
| **F0** | 元数据完善、策略校验、下载鉴权加固、预签名下载（MinIO/OSS） |
| **F1** | MinIO + 阿里云 OSS + 腾讯 COS 适配器，租户配置档 CRUD |
| **F2** | 华为 OBS、七牛、百度 BOS；分片上传、断点续传（大文件） |
| **F3** | 病毒扫描、水印、归档生命周期、跨域复制（可选） |
