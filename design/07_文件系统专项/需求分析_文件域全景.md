# 需求分析 · 文件域全景

## 1. 背景与目标

PSM 平台大量业务依赖附件留痕：作业票气体检测照片、签字图片、报警处置影像、承包商资质扫描件、验收报告等。一期已实现**本地磁盘**存储与基础 upload/download API，尚未支持 MinIO 与国内云厂商的统一选型。

本专项目标：

1. 定义**统一文件服务**边界，业务只认 `fileId` 与平台下载入口。
2. 支持**多存储后端**，租户按部署环境**选择并配置**即可切换，无需改业务代码。
3. 与**SSO / 平台登录**一致：任何下载必须可追溯到租户与用户，禁止未授权直链。
4. 满足危化行业**审计、完整性、保留周期**要求。

## 2. 域边界

```text
业务域（作业票/报警/承包商/移动现场…）
        │ Multipart 上传 / 引用 fileId
        ▼
┌─────────────────────────────────────────┐
│  文件服务（psm-identity-api / file）       │
│  · 策略校验（类型/大小）                    │
│  · 元数据 file_object                     │
│  · StorageAdapter 路由                    │
└───────────────┬─────────────────────────┘
                │
     ┌──────────┼──────────┬──────────────┐
     ▼          ▼          ▼              ▼
   LOCAL     MINIO    阿里云 OSS      腾讯 COS …
```

| 能力 | 归属 | 说明 |
| --- | --- | --- |
| 登录 / SSO | `identity.auth` | 颁发平台 Token；文件 API 只认 Token + 租户 |
| 文件字节读写 | `identity.file` | 适配器写入/读出 |
| 存储连接配置 | 租户配置 / `file_storage_profile` | 加密保存密钥，管理端维护 |
| 附件业务策略 | `config-rule` | 允许类型、单文件大小、保留天数 |

## 3. 用户角色与诉求

| 角色 | 诉求 |
| --- | --- |
| 现场人员（移动） | 弱网上传、拍照、重试；上传后立即可在票证详情查看 |
| 管理员 | 配置本租户用 MinIO 还是 COS；限制承包商上传类型 |
| 审计员 | 可查谁何时上传/下载、文件哈希、是否被删 |
| 实施工程师 | 只改 `application.yml` 或环境变量即可切存储，无需发版 |
| 安全负责人 | SSO 统一入口；下载链接短时有效；敏感区禁止公网直链 |

## 4. 场景矩阵

| 场景编码 | 触发 | 文件特点 | 存储建议 |
| --- | --- | --- | --- |
| `WKP_SITE_PHOTO` | 现场许可/措施确认 | 图片，≤10MB | MinIO/COS |
| `WKP_SIGNATURE` | 电子签名 | PNG/SVG，小文件 | 同租户默认 |
| `WKP_GAS_REPORT` | 气体检测附件 | PDF/图片 | 同默认 |
| `ALARM_EVIDENCE` | 报警处置 | 图片/视频 | COS+CDN（可选） |
| `CTR_CERT_SCAN` | 承包商资质 | PDF | 长期保留 |
| `AUDIT_EXPORT` | 报表导出 | ZIP/XLSX | 短期 + 生命周期删除 |
| `REG_SUBMIT` | 监管报送包 | ZIP | 隔离 bucket |

## 5. 与一期现状的差异

| 项 | 一期现状 | 本专项目标 |
| --- | --- | --- |
| 存储 | `LocalFileStorageSupport` 本地目录 | 可插拔 `StorageAdapter` |
| 元数据 | `file_object`，无 `storage_backend` | 增加 backend、profile_id、bucket、object_key |
| 下载 | 网关带 Token 即可 GET download | + 业务权限校验 + 可选预签名重定向 |
| SSO | Auth 已支持 OIDC 等流程 | 文件接口强制鉴权；SSO 用户与 LOCAL 用户一致 |
| 租户选型 | 无 | 管理端选择默认 profile |
| 云厂商 | 未接 | OSS/COS/OBS 等配置化 |

## 6. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 安全 | 密钥 Jasypt/环境变量；日志不打印 Secret；路径穿越防护（已有） |
| 性能 | 普通文件上传 P95 ≤ 5s（10MB 内网）；下载首字节 ≤ 2s |
| 可用性 | 存储故障时上传返回明确错误；已上传文件元数据不丢 |
| 合规 | 保留 SHA-256；删除为逻辑删 + 可选物理延迟清除 |
| 扩展 | 新厂商 = 新 Adapter + 配置项，不改 Controller 契约 |

## 7. 验收原则（域级）

- 租户配置为 MinIO 后，新上传文件可在 MinIO 控制台看到对象，且 `file_object.storage_backend=MINIO`。
- SSO 登录用户与本地用户均可上传/下载，跨租户下载返回 403/404。
- 切换默认存储只影响**新文件**，历史文件仍从原 backend 读取。
- 未配置云密钥时，对应 Adapter 为 PLACEHOLDER，管理端可见「未配置」且不误导为已启用。
