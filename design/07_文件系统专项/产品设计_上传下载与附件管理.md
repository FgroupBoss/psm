# 产品设计 · 上传下载与附件管理

## 1. 产品目标

为 Web 管理端、移动端、内部服务提供一致的**上传 → 引用 → 下载/预览**体验，附件始终挂在业务对象上，支持审计追溯。

## 2. 用户旅程

```text
选择文件 → 前端校验（类型/大小）→ 上传 API → 获得 fileId
    → 业务保存时提交 fileId 列表
    → 详情页展示附件列表 → 下载/预览（鉴权后）
```

## 3. 页面与入口

| 端 | 入口 | 能力 |
| --- | --- | --- |
| Web | 作业票/报警/承包商详情「附件」区 | 上传、列表、下载、删除（权限控制） |
| Web | 系统配置 → 文件存储 | 存储配置档、默认后端、连通性测试 |
| 移动 | 许可/监护/验收页「拍照上传」 | 调用 `/api/mobile/files/upload` 或统一 `/api/files/upload` |
| 移动 | 弱网 | 失败提示、重试；大文件二期分片 |

## 4. 上传交互

| 规则 | 说明 |
| --- | --- |
| 类型白名单 | 按 `bizType` 读取配置：如现场照片仅 `image/jpeg,image/png` |
| 大小上限 | 默认单文件 20MB，视频场景可单独提高 |
| 进度 | Web 显示上传进度；移动简化百分比 |
| 结果展示 | 成功后显示文件名、大小、上传人、时间 |
| 失败 | 明确原因：超大、类型不允许、存储未配置、网络错误 |

## 5. 下载与预览

| 模式 | 适用 | 用户感知 |
| --- | --- | --- |
| **代理下载** | LOCAL、内网 MinIO | 浏览器访问 `/api/files/{id}/download`，平台流式输出 |
| **预签名跳转** | 公有云 OSS/COS | 平台校验后 302 到短时 HTTPS URL（5~15 分钟） |
| **预览** | 图片/PDF | 同下载鉴权；`Content-Disposition: inline` |

禁止：在列表接口返回**长期有效**的公有 URL；禁止前端拼接 bucket 密钥访问。

## 6. 附件与业务关系

| 字段 | 说明 |
| --- | --- |
| `bizType` | 如 `WORK_PERMIT`、`ALARM`、`CONTRACTOR_CERT` |
| `bizId` | 业务主键 |
| 业务表 | 可仅存 `file_id` 或独立 `file_attachment` 关联表（配置中心已有模型） |

删除业务单据时：附件默认**保留**（审计）；可配置「随单归档」或「逻辑删除附件」。

## 7. 与消息/待办的区别

文件服务只负责**字节与元数据**；不在此模块做「通知某人下载」。如需提醒，走 `06_消息待办专项` 发站内信。

## 8. 验收标准

- AC-FILE-01：10MB 内图片上传后，详情页可下载且哈希与上传一致。
- AC-FILE-02：无 Token 访问 download 返回 401。
- AC-FILE-03：A 租户用户无法下载 B 租户 `fileId`。
- AC-FILE-04：超类型/超大小上传被拒绝且文案可读。
