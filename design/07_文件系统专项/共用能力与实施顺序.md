# 文件系统 · 共用能力与实施顺序

## 1. 共用能力

### 1.1 文件策略（与配置中心）

| 能力 | 来源 |
| --- | --- |
| 允许 MIME | `config` → `attachments/policies` 或 `psm.file.allowed-content-types` |
| 单文件大小 | `max-size-bytes` |
| 保留天数 | 二期生命周期任务 |

### 1.2 完整性

- 上传流式计算 **SHA-256**（已实现），入库 `file_object.sha256`。
- 下载可选校验（DEBUG）；监管导出记录哈希。

### 1.3 多租户

- 所有 API 带 `tenantId`；`file_storage_profile` 按租户隔离。
- 对象键前缀含 `tenantId`，防止桶内串租。

### 1.4 SSO 协同

- 不单独实现文件 SSO；统一依赖 `auth` 模块 Token。
- 详见 [产品设计_SSO与文件访问鉴权.md](./产品设计_SSO与文件访问鉴权.md)。

### 1.5 审计

- 上传/下载/删除/存储测试写入 `audit`（best-effort）。
- `biz_type`：`FILE_UPLOAD`、`FILE_DOWNLOAD`、`STORAGE_PROFILE_CHANGE`。

## 2. 业务接入检查表

- [ ] 是否通过 `/api/files/upload` 或 `FileClient`，未直写磁盘/云 SDK
- [ ] 是否保存 `fileId` 而非完整 URL
- [ ] 是否设置 `bizType` / `bizId` 便于权限校验
- [ ] 列表是否用平台 `downloadUrl`，未拼 bucket 公网地址
- [ ] 敏感附件是否限制角色下载

## 3. 实施顺序

| 批次 | 范围 | 依赖 | 验收 |
| --- | --- | --- | --- |
| **F0** | `StorageAdapter` 抽象；LOCAL 迁移；下载鉴权；`file_object` 扩展字段；策略校验 | 无 | 现网等价 + 跨租户阻断 |
| **F1** | MinIO、阿里云 OSS、腾讯 COS Adapter；`file_storage_profile` CRUD；管理端配置页；presign 下载 | MinIO/OSS/COS 账号 | AC-STG-01、AC-ADP-01 |
| **F2** | 华为 OBS、七牛、百度 BOS；`file_biz_storage_route`；分片上传 | 厂商账号 | 大文件、路由 |
| **F3** | 病毒扫描接口、生命周期清理、跨域复制、HTTP_GATEWAY | 客户安全要求 | 合规增强 |

## 4. 配置落地示例（MinIO）

```yaml
psm:
  file:
    default-backend: MINIO
    enabled-backends: LOCAL,MINIO

# 或租户 profile 存在 DB 后，平台仅兜底：
PSM_FILE_MINIO_ENDPOINT=http://minio:9000
PSM_FILE_MINIO_ACCESS_KEY=minioadmin
PSM_FILE_MINIO_SECRET_KEY=minioadmin
PSM_FILE_MINIO_BUCKET=psm-files
```

## 5. 配置落地示例（腾讯 COS）

```yaml
# 租户管理端填写 profile，或环境变量注入：
PSM_FILE_COS_REGION=ap-guangzhou
PSM_FILE_COS_SECRET_ID=***
PSM_FILE_COS_SECRET_KEY=***
PSM_FILE_COS_BUCKET=psm-1250000000
```

下载模式建议：`download-mode: PRESIGNED`。

## 6. 与作业票 / 移动专项协同

| 业务 | bizType | 说明 |
| --- | --- | --- |
| 措施拍照 | `WORK_PERMIT_MEASURE` | 移动 upload |
| 电子签名 | `WORK_PERMIT_SIGNATURE` | 小图 |
| 气体检测 | `WORK_PERMIT_GAS` | PDF/图 |
| 验收 | `WORK_PERMIT_ACCEPTANCE` | 多附件 |

## 7. 上线底线

- 密钥不入库明文、不入 Git。
- 切换存储不影响已上传文件的下载能力（按 `storage_backend` 选 Adapter）。
- 公网 bucket 默认私有读，仅平台 presign 暴露短时 URL。
- LOCAL 路径必须 `normalize` 防穿越（现网已有，保持）。
