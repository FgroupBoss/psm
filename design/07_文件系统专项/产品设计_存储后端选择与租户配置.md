# 产品设计 · 存储后端选择与租户配置

## 1. 产品目标

实施或租户管理员可在后台**选择存储类型并填写连接信息**，保存后即可用于该租户新上传文件；支持**多套配置、一套默认**，按业务场景可选覆盖。

## 2. 配置档模型（产品语义）

| 字段 | 说明 |
| --- | --- |
| `profileCode` | 租户内唯一编码，如 `default`、`cos-prod` |
| `profileName` | 展示名 |
| `storageBackend` | LOCAL / MINIO / ALIYUN_OSS / … |
| `enabled` | 是否可用 |
| `isDefault` | 租户默认（仅一个） |
| `priority` | 多档时的备选顺序（可选） |

连接参数按后端类型动态表单展示，**密钥字段仅写入不回显**。

## 3. 后端选型指引（给实施/客户）

| 后端 | 何时选用 | 必填配置（摘要） |
| --- | --- | --- |
| **LOCAL** | 开发机、小规模私有化、无对象存储 | `storage-root` 目录 |
| **MINIO** | 园区机房自建、S3 工具链成熟 | `endpoint`、`access-key`、`secret-key`、`bucket` |
| **ALIYUN_OSS** | 已采购阿里云、需 OSS 控制台 | `endpoint`、`access-key-id`、`access-key-secret`、`bucket` |
| **TENCENT_COS** | 已采购腾讯云 | `region`、`secret-id`、`secret-key`、`bucket` |
| **HUAWEI_OBS** | 华为云/政务云 | `endpoint`、`ak`、`sk`、`bucket` |
| **QINIU_KODO** | 需要 CDN 加速静态资源 | `access-key`、`secret-key`、`bucket`、`domain` |
| **BAIDU_BOS** | 百度云 | `endpoint`、`ak`、`sk`、`bucket` |
| **S3_COMPAT** | 其他兼容 S3 的厂商 | 同 MinIO 表单项 + 自定义 `endpoint` |

## 4. 管理端页面

| 页面 | 功能 |
| --- | --- |
| 存储配置列表 | 展示后端类型、是否默认、连通状态 |
| 新建/编辑 | 选择后端 → 动态表单 → 测试连接 → 保存 |
| 设为默认 | 切换后提示「仅影响新上传」 |
| 连通性测试 | 写入测试对象 `healthcheck.txt` 并读回 |

## 5. 选择规则（运行时）

```text
上传请求携带 tenantId + 可选 storageProfileCode
    → 若指定 profile：用该档（需 enabled）
    → 否则用租户 isDefault=true 的 profile
    → 否则用平台 psm.file.default-backend（环境变量）
    → 否则 LOCAL
```

| 覆盖场景 | 配置方式 |
| --- | --- |
| 监管包走 COS | `bizType=REG_SUBMIT` 映射到 `profileCode=cos-reg` |
| 现场照片走 MinIO | `bizType=WKP_SITE_PHOTO` 映射 `minio-site` |

映射表存 `file_biz_storage_route` 或配置中心 JSON。

## 6. 模式：PLACEHOLDER vs 真实连接

与 `06_消息待办` 外通道一致：

| 模式 | 行为 |
| --- | --- |
| `PLACEHOLDER` | 未填密钥或 `enabled=false`；上传返回「存储未配置」 |
| `ACTIVE` | 配置完整且连通性测试通过 |

管理端展示：**已配置 / 未配置 / 测试失败** 三色状态。

## 7. 密钥与安全

- 界面保存后密钥显示 `******`，仅支持「重新填写」覆盖。
- 支持 Jasypt `ENC(...)` 或 K8s Secret 注入环境变量。
- 禁止将 SK 写入前端或导出 Excel。

## 8. 验收标准

- AC-STG-01：租户设为 MinIO 默认后，新文件 `storage_backend=MINIO`。
- AC-STG-02：切换默认 OSS 后，旧文件仍可从原 OSS 下载。
- AC-STG-03：连通性测试失败时不允许设为默认（可强制 override 需高权限审计）。
