# 技术设计 · 文件服务落地

## 1. 服务定位

文件能力落在 **`psm-identity-api`** 的 `file` 包（对应规划中的 `psm-file-service`）。对外 HTTP 契约保持稳定，存储实现通过 **`StorageAdapter`** 可插拔。

## 2. 架构

```text
Client（Web/移动/业务服务 FileClient）
        │ Multipart / GET download
        ▼
FileController  (/api/files/*)
        ▼
FileServiceImpl
   ├─ FilePolicyValidator（类型/大小，读 config）
   ├─ FileObjectMapper（元数据）
   ├─ FileStorageProfileResolver（租户 → profile → adapter）
   └─ StorageAdapter（LOCAL / MINIO / OSS / …）
```

**约束**：`psm-operation-api` 的 `FileClient` 仅 HTTP 转发，不本地落盘。

## 4. HTTP API

### 4.1 一期已有（保持）

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/api/files/health` | GET | 健康 |
| `/api/files/upload` | POST | multipart 上传 |
| `/api/files/{id}` | GET | 元数据 |
| `/api/files/{id}/download` | GET | 下载（增强鉴权+适配器） |

### 4.2 本专项新增

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/api/files/{id}/preview` | GET | 在线预览（inline） |
| `/api/files/{id}/presign` | GET | 获取预签名 URL（JSON，供前端跳转） |
| `/api/files/profiles` | GET/POST | 租户存储配置档 CRUD |
| `/api/files/profiles/{id}/test` | POST | 连通性测试 |
| `/api/files/profiles/default` | GET | 当前默认档 |
| `/api/files/backends` | GET | 支持的后端列表及所需配置项 schema |

上传请求扩展（可选 query/form）：

- `storageProfileCode`：指定配置档
- 仍必填 `tenantId`；头透传 `X-PSM-User-Id`

### 4.3 响应 `FileObjectVO` 扩展

```json
{
  "id": 1,
  "fileName": "site.jpg",
  "storageBackend": "MINIO",
  "downloadUrl": "/api/files/1/download?tenantId=1",
  "previewUrl": "/api/files/1/preview?tenantId=1",
  "presignedUrl": null,
  "sha256": "…"
}
```

`presignedUrl` 仅在请求 presign 且后端为云存储时返回；列表接口不默认带。

## 5. 配置（平台级 `application.yml`）

```yaml
psm:
  file:
    default-backend: LOCAL          # 无租户 profile 时的兜底
    storage-root: ./data/psm-files  # LOCAL 根目录
    max-size-bytes: 20971520        # 20MB 默认
    allowed-content-types: image/jpeg,image/png,application/pdf
    download-mode: AUTO             # AUTO | PROXY | PRESIGNED
    presign-ttl-seconds: 300
```

租户 profile 覆盖平台 default-backend。

## 6. 与 SSO / 网关

- 网关 `18080` 对 `/api/files/**` 由 identity 直接处理（**不**走 operation 代理）。
- `GatewayProxyController` 不代理 files；鉴权与 SSO 与 `/auth/*` 同一套 `GatewayAuthService`。
- 下载大文件时注意网关超时，云存储优先 `PRESIGNED` 减轻网关压力。

## 7. 业务接入

| 调用方 | 方式 |
| --- | --- |
| 移动端 | `POST /api/mobile/files/upload` → 内部调 file 服务 |
| 管理端 | `POST /api/files/upload` |
| 作业票服务 | 保存 `fileId` 至措施/签字表；不持有多余路径 |

## 8. 验收（技术）

- AC-FT-01：LOCAL 上传下载与现网行为一致。
- AC-FT-02：配置 MinIO 后对象键为 `{tenantId}/{yyyyMM}/{uuid}_{name}`。
- AC-FT-03：COS 下载走 presign 时响应含 HTTPS URL 且 TTL 有效。
- AC-FT-04：`file_storage_profile` 密钥不出现在 GET 接口 JSON 中。
