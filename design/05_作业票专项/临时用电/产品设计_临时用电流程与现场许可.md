# 临时用电 · 流程与现场许可产品设计

## 1. 页面清单

| 页面 | 功能 |
| --- | --- |
| 列表 | 电源点、电压、负荷、期限、电工、巡检状态、阻断项 |
| 创建编辑 | 接入方案、用电设备、配电设施、电工、危险场所 |
| 送电许可向导 | 电工 → 箱体 → 开关漏保 → 接地 → 线路 → 防雨防爆 → 签名送电 |
| 使用监护 | 每日巡检、异常停电、恢复送电 |
| 拆除验收 | 停电、拆线、拆箱、清点、销项 |

## 2. 字段与校验

| 分组 | 字段 |
| --- | --- |
| 电源 | `powerSourceId`、电压、负荷、接入点、危险区域 |
| 设施 | 配电箱、总开关、漏保、接地、线路、照明 |
| 人员 | 安装电工、巡检电工、拆除电工、证书快照 |
| 期限 | 起止时间、巡检周期、拆除计划 |

## 3. 状态节点

```text
申请 → 接入方案 → 交底签字 → 审批中 → 待送电
→ 使用中 ⇄ 停电暂停 → 待拆除 → 待验收 → 待关闭 → 关闭
```

主状态仍复用通用状态机，使用 `permit_phase_marker` 表达“待拆除”。

## 4. 移动端与通知

- 配电箱二维码进入巡检页，按箱体记录漏保、接地、线路和环境。
- 巡检超时、漏保异常、箱体进水、线路破损触发停电提示。
- 恢复送电必须由持证电工在线确认。

## 5. 误操作防范与验收

- 不允许非电工执行送电、恢复和拆除确认。
- 未确认停电不得提交拆除，未拆除不得关闭。
- 危险场所未满足防爆规则时硬阻断。
- 归档包含安装、送电、巡检、停电、拆除和验收记录。
