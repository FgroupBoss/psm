# 临时用电 · 专项落地技术设计

## 1. 设计结论

在 `psm-operation-api.workpermit.temporaryelectric` 下新增用电详情、配电设施、巡检和拆除销项。主状态机保持不变，用子阶段表达“待拆除”。

## 2. 数据模型

| 表 | 用途 | 核心字段 |
| --- | --- | --- |
| `temporary_electric_detail` | 用电详情 | `permit_id, source_id, voltage, load_kw, hazardous_area_flag, plan_ref, valid_until` |
| `temporary_electric_facility` | 配电设施 | `permit_id, facility_type, facility_no, protection_type, grounding_result, qr_code, status` |
| `temporary_electric_inspection` | 巡检 | `permit_id, facility_id, result, issue, rectification, inspected_at` |
| `temporary_electric_removal` | 拆除销项 | `permit_id, power_off, wire_removed, box_removed, accepted_by, accepted_at` |

## 3. 接口与规则

| HTTP | Path |
| --- | --- |
| GET/PUT | `/api/work-permits/{id}/temporary-electric-detail` |
| GET/POST | `/api/work-permits/{id}/temporary-electric/facilities` |
| GET/POST | `/api/work-permits/{id}/temporary-electric/inspections` |
| POST | `/api/work-permits/{id}/temporary-electric/power-on` |
| POST | `/api/work-permits/{id}/temporary-electric/power-off` |
| POST | `/api/work-permits/{id}/temporary-electric/removal` |
| POST | `/api/work-permits/{id}/temporary-electric/pre-check` |

`SITE_PERMIT` 即送电许可，校验电工资质、箱体、漏保、接地、线路、防雨和防爆；`MONITOR` 校验巡检时效；`ACCEPTANCE` 校验停电拆除。

## 4. 事件、安全与测试

- 事件：`TEMP_POWER_ON`、`INSPECTION_OVERDUE`、`TEMP_POWER_OFF`、`REMOVED`、`CLOSED`。
- 仅持证电工可送电、恢复、拆除；关键动作在线校验并审计。
- 测试覆盖漏保失败、接地失败、防爆规则、电工资质、巡检超时、重复送电、未拆除关闭。

## 5. 上线

批次 `S2`，开关 `psm.temporary-electric.enabled=false`。先完成配电箱二维码和电工证书数据治理，再启用移动巡检。
