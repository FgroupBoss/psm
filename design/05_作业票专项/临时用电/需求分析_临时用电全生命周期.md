# 临时用电 · 全生命周期需求分析

> **依据**：`GB 30871-2022` 第 10 章、平台 M06 危险工作票闭环  
> **编码**：`TEMPORARY_ELECTRIC`

## 1. 结论

临时用电专项以“电源接入、配电层级、保护装置、线路敷设、每日巡检、拆除销项”为主线。审批和送电必须分离，拆除验收是关闭前置条件。

## 2. 主流程

```text
申请 → 用电负荷与接入方案 → JSA/JHA及交底签字 → 审批
→ 待送电：电工资质、配电箱、漏保、接地、线路、环境检查
→ 许可送电 → 使用中：每日巡检、异常停电 ⇄ 恢复送电
→ 停电拆除 → 验收销项 → 关闭归档
```

## 3. 关键规则

- 在运行生产装置、罐区和具有火灾爆炸危险场所内不得接入临时电源，确需使用时应按企业制度落实防爆和专项审批。
- 临时用电应由持证电工安装、维修和拆除，其他人员不得擅自操作。
- 配电箱应设置总开关和漏电保护器；用电设备执行“一机一闸一保护”。
- 临时线路应采用耐压等级符合要求的绝缘导线，避免架设在树木、脚手架等非专用支撑物上。
- 室外配电箱应有防雨措施，临时照明应满足现场环境要求。
- 使用期间执行巡检；线路、箱体、漏保、接地或环境发生变化时暂停送电并复核。
- 完工后必须停电、拆线、拆箱、清点并确认无遗留。

## 4. 异常与联动

| 异常 | 行为 |
| --- | --- |
| 电工资质失效 | 阻断提交、送电和恢复 |
| 漏保、接地、箱体或线路检查失败 | 阻断送电 |
| 危险场所防爆要求未满足 | 硬阻断或升级审批 |
| 巡检超时 | 提醒，超时后暂停使用 |
| 与动火、受限空间、高处作业冲突 | SIMOPS 提示或协调 |
| 拆除未完成 | 阻断关闭 |

## 5. 数据与证据

| 数据 | 证据 |
| --- | --- |
| 用电详情 | 电源点、电压、负荷、设备、期限、方案 |
| 配电设施 | 箱体、开关、漏保、接地、线路、检查照片 |
| 电工 | 人员、证书、有效期、操作记录 |
| 巡检 | 日期、设施状态、异常、整改、复检 |
| 拆除 | 停电、拆线、拆箱、清点、验收签名 |

## 6. 验收标准

- 未完成电工资质、漏保、接地和线路检查无法送电。
- 每日巡检可追溯，异常可停电暂停并复核恢复。
- 危险场所可触发强化防爆和审批规则。
- 临时设施未拆除时无法关闭。
- 归档包含安装、送电、巡检、停电、拆除和验收证据。
