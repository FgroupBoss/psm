# 受限空间 · 流程与现场许可产品设计

## 1. 页面清单

| 页面 | 功能 |
| --- | --- |
| 列表 | 空间、状态、人数、检测有效期、监护人、阻断项、下一步 |
| 创建编辑 | 空间档案、隔离方案、人员、风险、交底、救援 |
| 现场许可向导 | 隔离 → 通风 → 检测 → 签到 → 救援 → 签名许可 |
| 作业监护 | 出入登记、持续监测、通风、异常撤离、暂停恢复 |
| 验收 | 人员工具清点、空间清场、隔离处理、关闭 |

## 2. 专项字段

| 分组 | 字段 |
| --- | --- |
| 空间 | `spaceId`、名称、位置、介质、出入口、容积 |
| 隔离 | 隔离点、盲板号、挂牌、位置图 |
| 检测 | 点位、氧含量、可燃气体、有毒气体、设备、检测人、有效期 |
| 出入 | 人员、进出时间、当前在内人数、工具设备 |
| 救援 | 预案、联络人、装备、通信、救援口 |

## 3. 状态与节点

```text
申请 → 隔离与风险分析 → 交底签字 → 审批中 → 待作业
→ 作业中 ⇄ 暂停中 → 待验收 → 待关闭 → 作业关闭
```

主状态复用 `DRAFT / APPROVING / PENDING_SITE_PERMIT / IN_PROGRESS / SUSPENDED / PENDING_ACCEPTANCE / PENDING_CLOSURE / CLOSED`。

## 4. 移动端

- 出入口扫码签到和签退，实时显示空间内人数。
- 检测录入优先选择点位和气体模板，显示剩余有效时间。
- 监护页固定展示通风、最近检测、当前人数、救援联络和“立即撤离并暂停”按钮。
- 弱网允许普通监护草稿；许可、恢复、入内和撤离清点必须在线。

## 5. 通知与误操作防范

- 检测即将过期、检测异常、通风故障、监护超时、人员未签退时通知负责人和许可人。
- 禁止一键确认全部隔离点；每个隔离点和检测点单独留证。
- 人数不一致时禁用验收按钮。

## 6. 可配置项与验收

| 配置项 | 默认策略 |
| --- | --- |
| 检测有效期 | 按企业制度配置 |
| 中断复测 | 超过阈值强制复测 |
| 持续监测 | 默认开启 |
| 必签角色 | 负责人、监护人、作业人员、许可人 |

验收重点：隔离、检测、出入、通风、监护、救援和人数清点均可追溯。
