# 受限空间 · 专项落地技术设计

## 1. 设计结论

在 `psm-operation-api.workpermit.confinedspace` 下新增专项能力，复用通用状态机、交底、审批、SIMOPS、审计和归档。现有 `gas_test_record` 扩展检测点位和设备信息，新增隔离、出入、救援记录。

## 2. 数据模型

| 表 | 用途 | 核心字段 |
| --- | --- | --- |
| `confined_space_detail` | 空间详情 | `work_permit_id, space_id, entry_count, ventilation_type, continuous_monitoring, valid_until` |
| `permit_isolation_record` | 通用隔离记录 | `permit_id, isolation_type, position, blind_plate_no, tag_no, status, attachment_ref` |
| `confined_space_entry_record` | 出入记录 | `permit_id, worker_id, action, operated_at, location, operator` |
| `confined_space_rescue_plan` | 救援确认 | `permit_id, plan_ref, contact, equipment_json, confirmed_at` |
| `gas_test_record` | 扩展检测 | 增加 `sample_point, device_no, valid_until, source_stage` |

## 3. 接口与规则

| HTTP | Path |
| --- | --- |
| GET/PUT | `/api/work-permits/{id}/confined-space-detail` |
| GET/POST | `/api/work-permits/{id}/isolations` |
| GET/POST | `/api/work-permits/{id}/confined-space/gas-tests` |
| GET/POST | `/api/work-permits/{id}/confined-space/entries` |
| GET/PUT | `/api/work-permits/{id}/confined-space/rescue-plan` |
| POST | `/api/work-permits/{id}/confined-space/pre-check` |
| GET | `/api/work-permits/{id}/confined-space/flow-progress` |

检查点统一使用 `SAVE/SUBMIT/SITE_PERMIT/RESUME/MONITOR/ACCEPTANCE`。许可校验隔离、通风、检测、签到和救援；恢复增加复测；验收校验空间内人数为零。

## 4. 事件、安全与测试

- 事件：`CONFINED_SPACE_ENTERED`、`EXITED`、`GAS_BLOCKED`、`EVACUATED`、`CLOSED`。
- 检测设备或服务不可用时不得静默放行；人工录入需保留设备、人员、时间和证据。
- 测试覆盖气体边界、检测过期、隔离缺失、人数不一致、并发入内、撤离和 SIMOPS。

## 5. 上线

批次 `S1`：先扩展现有受限空间闭环，再启用持续监测、出入清点和救援确认开关。DDL 仅新增表和可空字段，回滚时关闭专项开关并保留数据。
