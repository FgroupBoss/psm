# 受限空间 · 全生命周期需求分析

> **依据**：`GB 30871-2022` 第 6 章、平台 M06 危险工作票闭环  
> **编码**：`CONFINED_SPACE`

## 1. 结论

受限空间属于优先完整闭环票种。专项重点不是单次气体检测，而是“隔离 → 通风 → 检测 → 入内 → 持续监测 → 人员清点 → 救援准备”的全过程控制。

## 2. 主流程

```text
申请 → 空间识别与隔离方案 → JSA/JHA及交底签字 → 审批
→ 待作业：隔离确认、通风、气体检测、人员签到、救援确认
→ 作业中：出入登记、持续监测、监护记录 ⇄ 暂停恢复
→ 人员清点 → 验收 → 关闭归档
```

## 3. 角色与场景

| 角色 | 职责 |
| --- | --- |
| 负责人 | 识别空间、组织隔离和交底、报完工 |
| 作业人员 | 签到、签字、进出登记 |
| 监护人 | 出入口监护、清点、联络、异常暂停 |
| 气体检测人 | 按点位和频次检测并留痕 |
| 许可人 | 核验隔离、通风、检测、救援后许可 |
| 救援联络人 | 确认预案、装备和响应方式 |

## 4. 关键规则

- 作业前必须与其他系统有效隔离，采取加盲板或拆除一段管线等可靠措施；不得以水封或关闭阀门代替盲板。
- 作业前清洗或置换，并采取通风措施；禁止向受限空间充纯氧。
- 气体检测应覆盖上、中、下部及可能积聚点，记录氧含量、可燃气体和有毒气体。
- 作业前检测合格后方可进入；作业中断时间超过企业配置阈值后，恢复前重新检测。
- 作业期间必须持续通风和监护；监护人不得离岗，不得从事与监护无关事项。
- 进出人员、时间、工具和设备必须登记；完工时人员与工具清点一致。
- 必须配置应急救援预案、联络方式和救援装备；异常时先撤离，禁止盲目施救。

## 5. 异常与联动

| 异常 | 行为 |
| --- | --- |
| 氧含量、可燃或有毒气体不合格 | 阻断许可；作业中触发撤离和暂停 |
| 检测过期或中断后未复测 | 阻断许可或恢复 |
| 隔离未完成、盲板状态异常 | 硬阻断 |
| 监护人离岗或出入人数不一致 | 暂停并核查 |
| 通风设备故障 | 暂停并撤离 |
| 与动火、盲板抽堵等作业冲突 | SIMOPS 扫描，按规则协调或阻断 |
| 弱网 | 草稿和普通记录可暂存；许可、恢复和入内确认必须在线 |

## 6. 数据与证据

| 数据 | 证据 |
| --- | --- |
| 空间档案 | 空间编号、位置、介质、风险、照片 |
| 隔离 | 隔离点、盲板号、挂牌、确认人、位置图 |
| 检测 | 点位、气体、数值、单位、结论、检测人、设备、时间 |
| 出入 | 人员、进出时间、人数、工具设备 |
| 救援 | 预案、联络人、装备清单、确认照片 |
| 监护 | 通风、检测、异常、撤离和恢复记录 |

## 7. 验收标准

- 隔离、通风、检测、救援任一未完成时无法许可。
- 气体检测超期或不合格时无法许可和恢复。
- 可追溯每名作业人员进出时间，完工时自动核对人数。
- 作业中检测异常可触发撤离、暂停和通知。
- 归档包含隔离、检测、出入、监护、验收和签名证据。
