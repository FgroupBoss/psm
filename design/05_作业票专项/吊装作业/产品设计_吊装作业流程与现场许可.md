# 吊装作业 · 流程与现场许可产品设计

## 1. 页面清单

| 页面 | 功能 |
| --- | --- |
| 列表 | 吊装级别、吨位、区域、吊车、状态、天气、阻断项 |
| 创建编辑 | 吊物、吨位、起吊点、落点、半径、方案、人员 |
| 许可向导 | 资质 → 设备吊具 → 地基支腿 → 警戒 → 天气 → 试吊 → 签名 |
| 作业监护 | 指挥、警戒区、天气、异常暂停 |
| 验收 | 吊装完成、吊具撤离、区域清场 |

## 2. 字段与校验

| 字段 | 校验 |
| --- | --- |
| `loadWeightT` | 必填，自动计算 `LEVEL_1/2/3` |
| `liftingPlanRef` | 一级、二级必填 |
| `craneId` | 必填，校验设备状态 |
| `commanderUserId`、`riggerUserIds`、`operatorUserId` | 必填并校验证书 |
| `liftingRadiusM`、`liftingPoint`、`landingPoint` | 必填 |
| `trialLiftResult` | 许可前必须为 `PASS` |

## 3. 状态节点

```text
申请 → 分级及吊装方案 → 交底签字 → 审批中 → 待作业
→ 试吊确认 → 作业中 ⇄ 暂停中 → 待验收 → 待关闭 → 关闭
```

## 4. 移动端与通知

- 移动端逐项确认吊具、索具、制动、限位、支腿、地基、警戒和天气。
- 试吊结果单独签字并附照片，不允许与正式起吊合并确认。
- 天气超限、警戒区闯入、试吊失败和设备异常触发暂停通知。

## 5. 误操作防范与验收

- 吨位变更后自动重新分级并校验方案。
- 未完成试吊不得进入正式作业。
- 不提供“批量吊具合格”按钮。
- 归档可回放设备、吊具、人员、天气、试吊和监护证据。
