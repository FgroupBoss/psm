# 吊装作业 · 专项落地技术设计

## 1. 设计结论

在 `psm-operation-api.workpermit.lifting` 下新增吊装详情、设备吊具检查、试吊和天气快照。复用通用状态机、环境检查、SIMOPS 和归档。

## 2. 数据模型

| 表 | 用途 | 核心字段 |
| --- | --- | --- |
| `lifting_work_detail` | 吊装详情 | `permit_id, load_name, load_weight_t, lifting_level, crane_id, radius_m, lifting_point, landing_point, plan_ref` |
| `lifting_equipment_check` | 设备吊具检查 | `permit_id, equipment_type, equipment_no, item_code, result, attachment_ref` |
| `lifting_trial_record` | 试吊 | `permit_id, result, issue, confirmed_by, attachment_ref, trial_at` |
| `permit_environment_check` | 通用环境快照 | `permit_id, stage, weather, wind_level, sampled_at, result` |

## 3. 接口与规则

| HTTP | Path |
| --- | --- |
| GET/PUT | `/api/work-permits/{id}/lifting-detail` |
| GET/POST | `/api/work-permits/{id}/lifting/equipment-checks` |
| GET/POST | `/api/work-permits/{id}/lifting/trial-records` |
| POST | `/api/work-permits/{id}/lifting/pre-check` |
| GET | `/api/work-permits/{id}/lifting/flow-progress` |

`SUBMIT` 校验吨位分级、方案和人员资质；`SITE_PERMIT` 校验设备、吊具、支腿地基、警戒、天气和试吊；`RESUME` 强制复核变化项。

## 4. 事件、安全与测试

- 事件：`LIFTING_LEVEL_CHANGED`、`TRIAL_FAILED`、`WEATHER_BLOCKED`、`SUSPENDED`、`CLOSED`。
- 天气只读接入，展示来源和采集时间；不可用时按规则人工复核或阻断。
- 测试覆盖 `40t/100t` 边界、方案缺失、资质过期、吊具失败、试吊失败、天气和并发许可。

## 5. 上线

批次 `S2`，开关 `psm.lifting.enabled=false` 默认关闭。先录入吊车和人员基础数据，再灰度启用三级、二级、一级吊装。
