# 吊装作业 · 全生命周期需求分析

> **依据**：`GB 30871-2022` 第 9 章、平台 M06 危险工作票闭环  
> **编码**：`LIFTING`

## 1. 结论

吊装专项围绕“分级、方案、人员、设备、吊具、试吊、警戒、天气”闭环。审批通过后必须现场核验，不能仅凭吊装方案直接开工。

## 2. 主流程

```text
申请 → 吊装分级与方案 → JSA/JHA及交底签字 → 审批
→ 待作业：人员资质、设备吊具、站位、警戒、天气、试吊确认
→ 作业中：指挥、监护、异常暂停 ⇄ 恢复复核
→ 吊装结束、现场清理 → 验收 → 关闭归档
```

## 3. 关键规则

- 按吊装质量分级：一级 `m > 100t`，二级 `40t ≤ m ≤ 100t`，三级 `m < 40t`。
- 一级、二级吊装作业必须编制吊装作业方案；企业制度可扩大方案范围。
- 吊装指挥、司索、起重机械操作等人员资质和职责必须明确。
- 作业前核验起重机械、吊具、索具、制动、限位、支腿和地基条件。
- 正式起吊前应试吊，确认制动、受力、平衡和环境无异常。
- 吊物下方、吊臂回转范围内和危险区域禁止人员停留或通行。
- 遇大风、雷电、雨雪、能见度不足等不具备条件的天气时禁止作业。
- 不得利用管道、管架、电杆、机电设备等作为吊装锚点。

## 4. 异常与联动

| 异常 | 行为 |
| --- | --- |
| 超过吨位但未上传方案 | 阻断提交 |
| 设备、吊具检查失败 | 阻断许可 |
| 试吊异常 | 暂停，整改后重新试吊 |
| 警戒区闯入人员 | 暂停并记录异常 |
| 天气超限 | 阻断许可或触发暂停 |
| 与动火、高处、断路作业冲突 | SIMOPS 协调或阻断 |

## 5. 数据与证据

| 数据 | 证据 |
| --- | --- |
| 吊装详情 | 吊物、质量、级别、起吊点、落点、半径、方案 |
| 设备吊具 | 机械编号、吊具索具、检查结果、照片 |
| 人员 | 指挥、司索、司机、监护及资质快照 |
| 试吊 | 试吊时间、结果、确认人、照片 |
| 现场 | 警戒范围、站位、天气快照、监护记录 |

## 6. 验收标准

- 吨位边界可正确计算一至三级。
- 一级、二级未上传方案无法提交。
- 吊具、设备、警戒、天气或试吊未通过时无法许可。
- 作业中异常可暂停，恢复前重新核验关键条件。
- 归档可回放方案、设备、人员、试吊和监护证据。
