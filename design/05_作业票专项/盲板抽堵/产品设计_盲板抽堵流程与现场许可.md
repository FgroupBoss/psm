# 盲板抽堵 · 流程与现场许可产品设计

## 1. 页面清单

| 页面 | 功能 |
| --- | --- |
| 盲板台账 | 编号、位置、介质、规格、挂牌、当前状态、关联票 |
| 创建编辑 | 选择单块盲板、动作、介质、位置图、措施、人员 |
| 许可向导 | 停工 → 降温降压 → 排空 → 隔离 → 挂牌 → 现场复核 → 签名 |
| 动作确认 | 抽板或堵板结果、照片、状态变更 |
| 验收 | 复位、挂牌、台账一致性和关闭 |

## 2. 字段与校验

| 字段 | 校验 |
| --- | --- |
| `blindPlateId` | 必填且一票一块 |
| `operationType` | `INSTALL/REMOVE` |
| `pipelineId`、`positionDescription`、`positionDiagramRef` | 必填 |
| `mediumName`、温度、压力、危险特性 | 必填 |
| `tagNo`、规格、材质 | 必填 |

## 3. 状态节点

```text
申请 → 盲板识别及介质分析 → 交底签字 → 审批中 → 待作业
→ 抽堵作业 → 动作确认 → 待验收 → 待关闭 → 关闭
```

## 4. 移动端与通知

- 扫描盲板挂牌二维码加载台账、位置图和目标动作。
- 动作确认展示前后状态，不允许手工跳过状态。
- 同管线并行抽堵、挂牌不一致、台账冲突即时阻断。

## 5. 误操作防范与验收

- 禁止一票绑定多块盲板。
- 状态更新采用条件更新，防止并发覆盖。
- 位置图、挂牌照片和动作照片必须留证。
- 未复位或台账不一致时无法关闭。
