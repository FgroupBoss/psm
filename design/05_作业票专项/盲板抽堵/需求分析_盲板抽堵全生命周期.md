# 盲板抽堵 · 全生命周期需求分析

> **依据**：`GB 30871-2022` 第 7 章、平台 M06 危险工作票闭环  
> **编码**：`BLIND_PLATE`

## 1. 结论

盲板抽堵专项执行“一块盲板一张票”。系统核心是盲板台账与现场状态一致：编号、位置图、介质、规格、挂牌、抽堵动作、复位和审计链不能缺失。

## 2. 主流程

```text
申请 → 盲板识别与位置图 → 介质风险分析及交底签字 → 审批
→ 待作业：停工降温降压、排空、隔离、盲板挂牌、现场复核
→ 抽板或堵板作业 ⇄ 暂停恢复
→ 动作确认、台账更新 → 验收复位 → 关闭归档
```

## 3. 关键规则

- 一块盲板对应一张作业票；同一设备或管线多块盲板分别编号、分别留痕。
- 作业前辨识介质、温度、压力、流向和可能残留，落实停工、降温、降压、排空等措施。
- 盲板位置图、编号、规格材质、挂牌信息必须与现场一致。
- 不得在同一管道上同时进行两处及以上盲板抽堵作业。
- 作业人员不得正对法兰缝隙，应采取防喷溅和个体防护。
- 涉及有毒、有害、易燃易爆介质时，增加气体检测、防护和监护门槛。

## 4. 异常与联动

| 异常 | 行为 |
| --- | --- |
| 盲板号、位置图或现场挂牌不一致 | 阻断许可 |
| 介质未排空、压力温度未满足 | 阻断许可 |
| 同一管线并行抽堵 | 硬阻断 |
| 抽堵动作与台账状态冲突 | 阻断更新并告警 |
| 与受限空间、动火作业冲突 | SIMOPS 协调或阻断 |
| 完工未复位或未更新台账 | 阻断关闭 |

## 5. 数据与证据

| 数据 | 证据 |
| --- | --- |
| 盲板台账 | 盲板号、位置、图纸、规格、材质、状态 |
| 介质 | 名称、温度、压力、危险特性、处置措施 |
| 作业动作 | `INSTALL/REMOVE`、前后状态、确认人、照片 |
| 挂牌 | 标签号、二维码、现场照片 |
| 验收 | 复位状态、台账一致性、验收签名 |

## 6. 验收标准

- 一张票仅允许绑定一块盲板。
- 盲板号、位置图、挂牌、介质和现场状态齐全后方可许可。
- 同一管线并行抽堵可被系统识别并阻断。
- 动作完成后台账状态与审计记录同步更新。
- 未复位或台账不一致时无法关闭。
