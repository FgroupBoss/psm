# 盲板抽堵 · 专项落地技术设计

## 1. 设计结论

在 `psm-operation-api.workpermit.blindplate` 下新增盲板台账和动作记录。一块盲板一张票，状态更新使用数据库条件更新，避免并发覆盖。

## 2. 数据模型

| 表 | 用途 | 核心字段 |
| --- | --- | --- |
| `blind_plate_registry` | 盲板台账 | `id, tenant_id, blind_plate_no, pipeline_id, position, diagram_ref, spec, material, tag_no, status, version_no` |
| `blind_plate_work_detail` | 作业详情 | `permit_id, blind_plate_id, operation_type, medium_name, temperature, pressure, hazard_json` |
| `blind_plate_action_record` | 动作记录 | `permit_id, blind_plate_id, from_status, to_status, attachment_ref, operated_at` |
| `permit_isolation_record` | 通用隔离 | `permit_id, isolation_type, position, status, attachment_ref` |

## 3. 接口与规则

| HTTP | Path |
| --- | --- |
| GET/POST | `/api/blind-plates` |
| GET/PUT | `/api/blind-plates/{id}` |
| GET/PUT | `/api/work-permits/{id}/blind-plate-detail` |
| POST | `/api/work-permits/{id}/blind-plate/action-confirm` |
| POST | `/api/work-permits/{id}/blind-plate/pre-check` |
| GET | `/api/work-permits/{id}/blind-plate/flow-progress` |

`SUBMIT` 校验一票一盲板、图纸、介质和动作合法；`SITE_PERMIT` 校验降温降压、排空、隔离、挂牌；`ACCEPTANCE` 校验台账与现场状态一致。

## 4. 并发、安全与测试

- 台账更新条件：`where id=? and version_no=? and status=?`，失败返回 HTTP `409`。
- 事件：`BLIND_PLATE_INSTALLED`、`REMOVED`、`STATE_CONFLICT`、`CLOSED`。
- 测试覆盖一票多盲板、同管线并行抽堵、挂牌不一致、状态冲突、介质未排空、未复位关闭。

## 5. 上线

批次 `S3`，先完成盲板台账导入和二维码挂牌，再启用作业票强校验。关闭开关后保留台账和动作记录。
