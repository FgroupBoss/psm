# 高处作业 · 流程与现场许可产品设计

> **文档类型**：产品设计  
> **关联**：[需求分析_高处作业全生命周期.md](./需求分析_高处作业全生命周期.md)  
> **适用端**：管理端、移动端、态势视图

---

## 1. 设计目标

高处作业页面优先回答五个问题：在哪里作业、离基准面多高、为什么属于当前等级、防坠措施是否可靠、当前是否允许继续作业。

流程图是只读进度视图，不直接改变状态。所有推进动作通过业务按钮完成，并由后端规则门槛校验。

## 2. 页面与功能清单

### 2.1 管理端

| 页面 | 功能 |
| --- | --- |
| 高处作业票列表 | 状态、高度级别、A/B 类、区域、负责人、有效期、阻断原因、下一步动作 |
| 创建/编辑 | 基础信息、分级分类、危险因素、JSA/JHA、措施、交底、审批流 |
| 详情 | 流程进度、专项详情、防护检查、环境检查、监护、审批、验收、审计 |
| 当前流程弹窗 | 11 节点进度、当前责任人、停留时长、阻断项、节点下钻 |
| 配置管理 | 危险因素、措施模板、审批路由、天气阈值、复核频次、SIMOPS 规则 |

### 2.2 移动端

| 页面 | 功能 |
| --- | --- |
| 待办 | 现场检查、交底签字、许可、监护、暂停恢复、验收 |
| 现场许可向导 | 扫码签到 → 防护检查 → 环境检查 → SIMOPS → 救援条件 → 签名许可 |
| 监护记录 | 快速选择正常/异常、拍照、位置、暂停 |
| 恢复向导 | 暂停原因回显 → 环境复核 → 防护复核 → 在线签字恢复 |
| 验收向导 | 人员工具清点、清场、防护设施处理、签字 |

## 3. 关键操作路径

### 3.1 创建与提交

```text
创建高处作业票
→ 填写区域、位置、高度和作业方式
→ 系统自动计算高度级别
→ 勾选或自动命中客观危险因素
→ 系统计算 A/B 类并推荐措施
→ 完成 JSA/JHA 和交底
→ 必签人员签字
→ 提交审批
```

### 3.2 现场许可

```text
审批通过
→ 到场扫码和定位
→ 检查登高设施
→ 检查安全带、生命线、防坠器和锚点
→ 检查落物防护和下方隔离
→ 获取天气数据并现场复核
→ 执行 SIMOPS 扫描
→ 四级或配置场景确认救援条件
→ 许可人在线签字
→ 作业中
```

### 3.3 暂停与恢复

```text
监护人、许可人、安全管理员或规则触发暂停
→ 记录原因、位置、照片和条件变化
→ 恢复前重新执行防护检查、环境检查和必要的 SIMOPS 扫描
→ 许可人在线签字
→ 恢复作业
```

## 4. 字段与校验

### 4.1 基础信息

| 字段 | 校验 |
| --- | --- |
| `workType` | 固定 `HEIGHT_WORK` |
| `workHeightM` | 必填，正数；用于自动计算高度级别 |
| `fallDatumDescription` | 必填，说明坠落高度基准面 |
| `workLocation` | 必填，支持区域、装置、文字位置、定位 |
| `workMethod` | 必填，脚手架/平台/吊篮/梯具/其他 |
| `planStartAt` / `planEndAt` | 必填，跨度不得超过 `7 天` |
| `guardianUserId` | 必填 |
| `permitIssuerUserId` | 必填 |

### 4.2 分级分类

| 字段 | 说明 |
| --- | --- |
| `heightLevel` | `LEVEL_1` 至 `LEVEL_4`，系统计算 |
| `riskClass` | `A` / `B`，由危险因素计算 |
| `manualUpgradeFlag` | 是否人工提高控制等级 |
| `manualUpgradeReason` | 人工提高等级时必填 |
| `hazardFactors[]` | 标准因素和企业扩展因素 |

### 4.3 现场检查

| 分组 | 必检项 |
| --- | --- |
| 登高设施 | 脚手架、平台、吊篮、梯具、通道、临边和孔洞 |
| 防坠落 | 安全带、安全绳、生命线、防坠器、锚点 |
| 防落物 | 工具袋、防坠绳、警戒区、下方隔离 |
| 环境 | 风速、天气、温度、能见度、照度、地面状态 |
| 专项风险 | 临近带电体、上下交叉、振动、高温热源 |
| 救援 | 联络人、通信工具、救援方案、救援资源 |

## 5. 状态机与展示

### 5.1 主状态机

```text
DRAFT → APPROVING → PENDING_SITE_PERMIT → IN_PROGRESS ⇄ SUSPENDED
  ↑         │ return                                    ↓
  └── RETURNED                                 PENDING_ACCEPTANCE
APPROVING ──reject──▶ CLOSED                            ↓
IN_PROGRESS/SUSPENDED ──terminate──▶ CLOSED       PENDING_CLOSURE → CLOSED
```

### 5.2 流程图映射

| 展示节点 | 主状态/子阶段 |
| --- | --- |
| 申请 | `DRAFT` |
| 分级分类 | `DRAFT` + `HEIGHT_CLASSIFIED` |
| 安全分析及交底 | `DRAFT` + `DISCLOSURE_PREPARED` |
| 安全交底签字 | `DRAFT` + `DISCLOSURE_SIGNED` |
| 审批中 | `APPROVING` |
| 待作业 | `PENDING_SITE_PERMIT` |
| 作业中 | `IN_PROGRESS` |
| 暂停中 | `SUSPENDED` |
| 待验收 | `PENDING_ACCEPTANCE` |
| 待关闭 | `PENDING_CLOSURE` |
| 作业关闭 | `CLOSED` |

## 6. 通知与待办

| 事件 | 通知对象 |
| --- | --- |
| 交底待签 | 作业人员、监护人、负责人 |
| 审批待办 | 当前审批人 |
| 待现场许可 | 许可人、监护人、负责人 |
| 天气阈值预警 | 监护人、许可人、安全管理员 |
| 作业即将到期 | 负责人、监护人、许可人 |
| 暂停超时 | 负责人、许可人、安全管理员 |
| 待验收/待关闭 | 验收人、关闭责任人 |

通知内容包含票号、区域、高度级别、A/B 类、有效期、当前阻断原因和下一步动作，不输出敏感个人信息。

## 7. 端侧差异

| 能力 | 管理端 | 移动端 | 态势视图 |
| --- | --- | --- | --- |
| 申请编辑 | 完整编辑 | 简化补录、拍照 | 不支持 |
| 分级分类 | 完整展示、人工提高等级 | 现场复核 | 按等级统计 |
| 现场许可 | 查看 | 主操作端 | 展示许可状态 |
| 监护记录 | 查询、审计 | 快速录入 | 展示异常数量 |
| 弱网 | 不强调 | 草稿、照片暂存；许可与恢复在线 | 标记数据时间 |

## 8. 可配置项

| 配置项 | 默认策略 |
| --- | --- |
| 适用起始高度 | `2m`，仅允许企业配置更严格值 |
| 最大有效期 | `7 天`，仅允许配置更短值 |
| 危险因素 | 标准项不可删除，企业项可追加 |
| 天气阈值 | 阵风五级及以上阻断；其余按企业制度配置 |
| 检查模板 | 按作业方式、高度级别、A/B 类加载 |
| 审批路由 | 按高度级别、A/B 类、区域配置 |
| 监护频次 | B 类、四级和复杂交叉作业提高频次 |
| 恢复复核 | 默认强制环境检查、防护检查和 SIMOPS |
| 气体检测 | 默认关闭；关联票或区域规则命中时开启 |

## 9. 误操作防范

- 不提供“一键全部确认”。
- 必检项逐项确认，关键项要求照片或扫码证据。
- 环境数据展示来源和采集时间，过期数据不得静默使用。
- 人工复核、人工提高等级、强制暂停和终止必须填写原因。
- 离线状态下禁用许可和恢复按钮。

## 10. 验收标准

- 创建页可自动计算高度级别和 A/B 类。
- 现场许可向导可按作业方式动态加载检查项。
- B 类和四级作业可展示强化检查和救援要求。
- 天气、SIMOPS、防护、人员资格任一硬阻断项未通过时不可许可。
- 流程图节点、主状态和子阶段保持一致。
- 管理端和移动端均可追溯现场证据。
