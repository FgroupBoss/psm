# 高处作业 · 全生命周期需求分析

> **文档类型**：需求分析  
> **适用范围**：单张高处安全作业票  
> **依据**：`GB 30871-2022` 第 8 章、`GB 3608-2025`《高处作业分级》、平台 M06 危险工作票闭环  
> **服务**：`psm-operation-api`

---

## 1. 结论

高处作业专项采用“**通用作业票底座 + 高处专项详情 + 配置化规则门槛**”。流程复用动火专项的全生命周期骨架，但控制重点改为坠落防护、落物防护、环境变化、交叉作业和应急救援。

高处作业必须同时记录：

1. 作业高度分级：一级、二级、三级、四级。
2. 作业风险分类：A 类或 B 类。存在客观危险因素时按 B 类管理。
3. 作业条件快照：防护设施、环境、天气、交叉作业、救援条件。
4. 条件变化闭环：作业条件发生变化时暂停，恢复前重新复核。

## 2. 业务目标

| 目标 | 说明 |
| --- | --- |
| 分级准确 | 根据坠落高度和客观危险因素自动计算建议级别，人工调整必须留痕 |
| 许可受控 | 审批通过不等于开工，必须完成现场防护和环境检查 |
| 动态管控 | 天气、防护、人员、交叉作业变化可触发暂停和恢复复核 |
| 证据完整 | 关键节点沉淀人员、时间、地点、照片、签名、检查项和规则命中记录 |
| 单票闭环 | 单张高处作业票独立完成申请、审批、许可、执行、验收、关闭和归档 |

## 3. 适用范围与分级

### 3.1 适用范围

距坠落高度基准面 `2m` 及以上，且存在坠落可能的作业纳入高处作业票管理。企业制度可扩大适用范围，不得降低标准要求。

### 3.2 高度分级

| 高度级别 | 坠落高度 |
| --- | --- |
| 一级 | `2m ≤ h ≤ 5m` |
| 二级 | `5m < h ≤ 15m` |
| 三级 | `15m < h ≤ 30m` |
| 四级 | `h > 30m` |

### 3.3 A/B 类管理

系统保存“高度级别”和“A/B 类”两个维度。存在客观危险因素时，标记为 `B` 类并执行更严格门槛。

| 客观危险因素 | 系统校验 |
| --- | --- |
| 阵风风力五级及以上 | 禁止露天高处作业或按企业规则硬阻断 |
| 高温、低温环境 | 要求防暑、防寒和作业时长控制 |
| 雨、雪、雾、结冰 | 阻断或升级审批，要求防滑和能见度复核 |
| 接触冷水温度低于 `12℃` | 标记 B 类，增加防护措施 |
| 作业场地有冰、雪、霜、水、油等易滑物 | 标记 B 类，未完成清理不得许可 |
| 作业场所光线不足或能见度差 | 标记 B 类，照度不满足不得许可 |
| 接近或接触带电体 | 标记 B 类，校验隔离和安全距离 |
| 摆动、立足处不稳或振动环境 | 标记 B 类，校验稳定措施 |
| 可能发生物体打击、机械伤害、灼伤等危险 | 标记 B 类，增加专项措施 |

> 企业可配置新增危险因素，但不得删除标准要求项。规则变更必须版本化并审计。

## 4. 角色

| 角色 | 主要职责 |
| --- | --- |
| 作业申请人 | 创建票、填写作业位置、高度、时间、人员和关联作业 |
| 作业负责人 | 组织 JSA/JHA、交底、现场检查、暂停、报完工 |
| 作业人员 | 参加交底、签字、按措施作业 |
| 监护人 | 现场监护、环境复核、异常上报、建议暂停 |
| 许可人 | 审批通过后实施现场许可，确认防护和环境条件 |
| 验收人 | 完工验收、清场、防护设施处理确认 |
| 安全管理员 | 模板配置、监督检查、强制暂停或终止、审计复盘 |
| 装置/区域负责人 | 审批、SIMOPS 协调、区域风险确认 |

## 5. 主流程

```text
1. 申请
   创建高处作业票 → 填写区域/位置/高度/作业方式/人员/时间 → 保存草稿

2. 分级分类
   高度级别自动计算 → 客观危险因素识别 → A/B 类建议 → 人工复核

3. 安全分析及交底
   JSA/JHA → 推荐措施 → 编制交底内容 → 组织交底

4. 安全交底签字
   作业人员/监护人/负责人等签字 → 必签角色全部完成

5. 审批中
   按高度级别、A/B 类、区域和企业制度路由审批

6. 待作业
   现场签到 → 防护设施检查 → 环境天气检查 → SIMOPS 扫描
   → 救援条件确认 → 许可人在线签字开工

7. 作业中 ⇄ 暂停中
   监护记录 → 条件变化或异常触发暂停 → 恢复前重新复核

8. 待验收
   负责人报完工 → 清点人员和工具 → 清场 → 验收签字

9. 待关闭
   最终关闭确认 → 归档快照 → PDF/监管报送
```

### 5.1 展示节点

| 展示节点 | 关键产出 |
| --- | --- |
| 申请 | 票号、作业位置、高度、人员、附件 |
| 分级分类 | 高度级别、A/B 类、危险因素、人工调整原因 |
| 安全分析及交底 | JSA/JHA、措施清单、交底内容 |
| 安全交底签字 | 多方签字记录 |
| 审批中 | 审批链、意见、待办 |
| 待作业 | 现场检查、环境快照、许可签名 |
| 作业中 | 监护日志、异常、定位、照片 |
| 暂停中 | 暂停原因、复核项、恢复签字 |
| 待验收 | 完工说明、人员工具清点、清场证据 |
| 待关闭 | 验收签字、关闭确认 |
| 作业关闭 | 归档快照、审计链 |

## 6. 关键业务规则

### 6.1 申请与提交

- 作业高度、坠落基准面、作业区域、作业位置、作业方式、计划时间必填。
- 作业票最长有效期为 `7 天`。超过有效期重新办理，不允许直接延长。
- 高度级别由系统计算；人工调整必须填写原因，只允许提高控制等级。
- B 类危险因素必须逐项确认；命中因素不得人工删除，只能补充处置证据。
- 作业人员必须通过承包商准入、培训、证书和企业适岗规则校验。

### 6.2 待作业现场许可

- 必须确认脚手架、平台、吊篮、梯具等登高设施适用且检查合格。
- 必须确认安全带、安全绳、生命线、防坠器、锚点可靠。
- 必须确认工具袋、防坠绳、下方警戒区和防落物措施。
- 临近带电体、孔洞临边、上下交叉、振动、高温热源等场景必须完成专项措施。
- 四级高处作业必须确认通信联络、应急救援方案和救援资源。
- 气体检测默认不是高处作业固定门槛；关联动火、受限空间或命中区域规则时动态增加。

### 6.3 作业中与恢复

- 作业条件、作业内容、人员、天气或防护设施变化时必须暂停。
- 暂停恢复前重新执行环境检查、防护检查和必要的 SIMOPS 扫描。
- 作业票过期后不得恢复。
- 监护记录频次按高度级别和 A/B 类配置，B 类和四级作业提高频次。

## 7. 异常流程

| 异常 | 触发点 | 系统行为 |
| --- | --- | --- |
| 高度低于 `2m` | 创建 | 提示不在标准强制范围；企业规则要求时仍可办理 |
| 作业高度或危险因素变化 | 提交前、作业中 | 重新分级；作业中先暂停再复核 |
| 天气阈值超限 | 许可、作业中 | 阻断开工或触发暂停通知 |
| 防护设施缺失、锚点不可用 | 许可、恢复 | 硬阻断 |
| 人员资质、培训或适岗失效 | 提交、许可、恢复 | 硬阻断并列出人员 |
| 下方未隔离或存在人员进入 | 许可、作业中 | 阻断许可或记录异常并暂停 |
| SIMOPS 冲突 | 提交、许可、恢复 | 按规则 `WARN/COORDINATE/BLOCK` |
| 票证超过 `7 天` | 作业中、恢复 | 自动标记过期并禁止继续 |
| 天气或定位服务不可用 | 许可、恢复 | 展示数据时间戳，转人工复核并留痕，不静默放行 |
| 弱网 | 移动端 | 草稿和照片暂存；许可、恢复必须在线 |

## 8. 数据与证据

| 数据 | 关键证据 |
| --- | --- |
| 高处详情 | 高度、级别、分类、方式、位置、有效期、救援方案 |
| 危险因素 | 因素编码、命中来源、处置措施、附件、确认人 |
| 防护检查 | 设施类型、检查项、结果、照片、检查人、时间、位置 |
| 环境检查 | 风速、天气、温度、能见度、照度、地面状态、数据来源和采集时间 |
| 交底签字 | 内容版本、签字人、角色、签字时间、终端、位置 |
| 许可与恢复 | 许可人、在线校验结果、签名、时间、位置 |
| 监护记录 | 正常/异常、描述、照片、监护人、时间 |
| 验收关闭 | 人员工具清点、清场、防护设施处理、签名和归档快照 |

## 9. 权限与审计

- 使用 RBAC + 租户、厂区、装置、区域数据权限。
- 作业人员不得代替许可人实施现场许可。
- 安全管理员可强制暂停或终止，但必须填写原因并留痕。
- 人工调整等级、人工复核天气、规则版本变更、审批、签名、许可、暂停、恢复、验收和关闭均写审计日志。
- 归档后只读；补正通过独立流程产生新版本，不覆盖原始证据。

## 10. 验收标准

| 编号 | 验收项 |
| --- | --- |
| AC-HW-01 | 输入边界高度可正确计算一级至四级 |
| AC-HW-02 | 任一标准客观危险因素命中后自动标记 B 类 |
| AC-HW-03 | 防护设施或锚点未确认时无法现场许可 |
| AC-HW-04 | 四级高处未确认通信和救援方案时无法许可 |
| AC-HW-05 | 天气阈值超限时阻断许可，作业中可触发暂停 |
| AC-HW-06 | 暂停后未复核环境和防护时无法恢复 |
| AC-HW-07 | 超过 `7 天` 的作业票无法恢复或继续作业 |
| AC-HW-08 | SIMOPS 冲突按配置执行提示、协调或阻断 |
| AC-HW-09 | 关键节点均可追溯人员、时间、位置、签名和附件 |
| AC-HW-10 | 非高处作业票不返回高处专项流程和字段 |
