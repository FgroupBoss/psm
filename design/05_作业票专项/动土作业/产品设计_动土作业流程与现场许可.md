# 动土作业 · 流程与现场许可产品设计

## 1. 页面清单

| 页面 | 功能 |
| --- | --- |
| 列表 | 区域、深度、面积、地下设施状态、会签状态、阻断项 |
| 创建编辑 | 范围、坐标、深度、方式、图纸、设施、会签 |
| 许可向导 | 放线 → 探测 → 试挖 → 支护放坡 → 临边 → 通道 → 排水 → 警示 → 签名 |
| 作业监护 | 土体、积水、不明设施、渗漏、临边巡检 |
| 恢复验收 | 回填、夯实、路面、标识和设施状态 |

## 2. 字段与校验

| 分组 | 字段 |
| --- | --- |
| 开挖 | `excavationArea`、坐标、深度、面积、机械、图纸 |
| 地下设施 | 类型、权属、位置、深度、探测方法、会签人 |
| 防护 | 支护、放坡、临边、通道、排水、夜间警示 |
| 恢复 | 回填、夯实、路面、标识、设施确认 |

## 3. 状态节点

```text
申请 → 地下设施识别及会签 → 交底签字 → 审批中 → 待作业
→ 开挖中 ⇄ 暂停中 → 回填恢复 → 待验收 → 待关闭 → 关闭
```

## 4. 移动端与通知

- 地图或平面图标记开挖范围，现场拍照校核。
- 发现不明设施、异味、渗漏、积水或土体变形时提供醒目的暂停按钮。
- 降雨预警、会签缺失、巡检超时通知负责人和许可人。

## 5. 误操作防范与验收

- 地下设施未确认时禁止机械开挖许可。
- 无法确认时必须记录探测和试挖。
- 深度、范围变化触发暂停复核。
- 未完成回填恢复和设施验收无法关闭。
