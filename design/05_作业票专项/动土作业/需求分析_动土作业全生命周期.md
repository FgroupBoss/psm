# 动土作业 · 全生命周期需求分析

> **依据**：`GB 30871-2022` 第 11 章、平台 M06 危险工作票闭环  
> **编码**：`EXCAVATION`

## 1. 结论

动土专项以“地下设施确认、开挖范围、探测会签、支护放坡、临边防护、出入口、积水和恢复验收”为主线。未经地下设施确认，不得开挖。

## 2. 主流程

```text
申请 → 开挖范围与深度 → 地下设施探测及会签 → JSA/JHA及交底签字
→ 审批 → 待作业：放线、探测、试挖、支护、临边、出入口、警示确认
→ 开挖中：监护、巡检、异常暂停 ⇄ 恢复复核
→ 回填恢复 → 验收 → 关闭归档
```

## 3. 关键规则

- 明确开挖区域、深度、面积、方式和机械设备。
- 作业前核查地下电缆、管道、通信、消防、排水等设施，完成相关专业会签。
- 无法确认地下设施时，先探测、试挖，禁止直接机械开挖。
- 深坑、槽、井、沟按现场条件采取放坡、支护、防坍塌、防坠落和上下通道措施。
- 开挖区域设置围栏、警示灯和夜间警示；防止人员、车辆坠入。
- 发现不明设施、异味、渗漏、土体异常或积水时立即停止作业。
- 回填前核验设施状态，完工后恢复地面、道路和标识。

## 4. 异常与联动

| 异常 | 行为 |
| --- | --- |
| 地下设施未确认或会签缺失 | 阻断提交和许可 |
| 发现不明设施、异味、渗漏 | 立即暂停并上报 |
| 支护、放坡、临边或通道不合格 | 阻断许可或恢复 |
| 降雨积水、土体变形 | 暂停并复核 |
| 与地下管线检修、断路、吊装冲突 | SIMOPS 协调或阻断 |
| 回填恢复未验收 | 阻断关闭 |

## 5. 数据与证据

| 数据 | 证据 |
| --- | --- |
| 动土详情 | 区域、坐标、深度、面积、方式、图纸 |
| 地下设施 | 类型、位置、深度、权属、探测、会签 |
| 现场检查 | 放线、试挖、支护、临边、通道、排水、警示 |
| 监护 | 土体、积水、设施异常、照片、位置 |
| 恢复 | 回填、夯实、路面、标识、验收签字 |

## 6. 验收标准

- 未完成地下设施确认和专业会签无法许可。
- 无法确认地下设施时必须进入探测、试挖流程。
- 支护、临边、通道、排水任一必检项失败时无法开工。
- 发现不明设施可暂停并形成处置闭环。
- 回填恢复证据齐全后方可关闭。
