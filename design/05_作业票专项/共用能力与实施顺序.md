# 八大作业票 · 共用能力与实施顺序

## 1. 目标

八大特殊作业票采用“通用闭环 + 票种专项”的方式落地。通用模块负责一致性，专项模块只承载行业差异，避免复制状态机和审计逻辑。

## 2. 通用状态机

```text
DRAFT → APPROVING → PENDING_SITE_PERMIT → IN_PROGRESS ⇄ SUSPENDED
  ↑         │ return                                    ↓
  └── RETURNED                                 PENDING_ACCEPTANCE
APPROVING ──reject──▶ CLOSED                            ↓
IN_PROGRESS/SUSPENDED ──terminate──▶ CLOSED       PENDING_CLOSURE → CLOSED
```

草稿阶段和票种特有阶段通过 `permit_phase_marker` 表达，例如临时用电“待拆除”、盲板抽堵“动作确认”、动土“回填恢复”。

## 3. 通用检查点

| 检查点 | 说明 |
| --- | --- |
| `SAVE` | 基础字段、时间范围和票种详情 |
| `SUBMIT` | 人员、资质、JSA/JHA、措施、交底、审批路由 |
| `SITE_PERMIT` | 现场签到、专项检查、环境、SIMOPS 和在线签字 |
| `RESUME` | 票证有效性、变化项、环境和专项复核 |
| `MONITOR` | 超时、环境变化、巡检频次和异常 |
| `ACCEPTANCE` | 清场、人员工具、设施恢复和专项验收 |
| `CLOSE` | 最终关闭、归档快照和报表事件 |

## 4. 共用数据

| 表 | 用途 |
| --- | --- |
| `work_permit` | 主票、状态、区域、装置、人员、时间 |
| `work_permit_worker` | 作业人员和角色 |
| `permit_risk_analysis` | JSA/JHA |
| `permit_safety_measure` | 通用和专项措施 |
| `permit_disclosure` / `permit_disclosure_sign` | 交底和签字 |
| `permit_phase_marker` | 子阶段 |
| `permit_special_check` | 可配置专项检查项 |
| `permit_environment_check` | 天气、照度、环境数据快照 |
| `permit_isolation_record` | 隔离、挂牌、盲板关联 |
| `permit_site_confirm` | 签到、定位、许可签名 |
| `permit_monitor_record` | 监护、巡检和异常 |
| `permit_status_log` | 状态审计 |
| `permit_archive_snapshot` | 归档快照 |

复杂结构使用专项表，不强行塞入 JSON：受限空间出入、盲板台账、临电设施、动土地下设施、断路交通方案。

## 5. 票种差异矩阵

| 票种 | 编码 | 专项门槛 |
| --- | --- | --- |
| 动火 | `HOT_WORK` | 分级、气体检测、防火、消防器材 |
| 受限空间 | `CONFINED_SPACE` | 隔离、通风、检测、出入、救援 |
| 盲板抽堵 | `BLIND_PLATE` | 一盲板一票、挂牌、排空、状态一致 |
| 高处 | `HEIGHT_WORK` | 高度分级、A/B 类、防坠、天气、救援 |
| 吊装 | `LIFTING` | 吨位分级、方案、吊具、试吊、警戒 |
| 临时用电 | `TEMPORARY_ELECTRIC` | 电工、漏保、接地、巡检、拆除 |
| 动土 | `EXCAVATION` | 地下设施、会签、试挖、支护、恢复 |
| 断路 | `ROAD_BREAK` | 交通组织、绕行、应急通道、恢复 |

## 6. SIMOPS

SIMOPS 在 `SUBMIT`、`SITE_PERMIT`、`RESUME` 运行。命中结果为 `WARN/COORDINATE/BLOCK`，规则版本和协调记录进入归档快照。

优先种子规则：

- 动火 + 受限空间：`BLOCK`
- 动火 + 吊装：`COORDINATE`
- 动火 + 临时用电：`WARN`
- 受限空间 + 盲板抽堵：`COORDINATE`
- 动土 + 地下管线检修：`BLOCK`
- 断路 + 同区域其他作业：`WARN`

## 7. 实施顺序

| 批次 | 范围 |
| --- | --- |
| `S0` | 通用交底、子阶段、专项检查、环境检查、隔离、待关闭 |
| `S1` | 受限空间专项补齐 |
| `S2` | 高处、吊装、临时用电 |
| `S3` | 盲板抽堵、动土、断路 |
| `S4` | 移动端、SIMOPS、通知、报表、监管映射、灰度上线 |

## 8. 上线底线

- 关键许可和恢复必须在线校验，弱网仅允许草稿和普通记录暂存。
- 外部数据只读接入，保留来源和采集时间，不得反向影响 OT 控制逻辑。
- 人工复核、规则变更、强制暂停和终止必须审计。
- 归档后只读，补正产生新版本，不覆盖原始证据。
