# 断路作业 · 流程与现场许可产品设计

## 1. 页面清单

| 页面 | 功能 |
| --- | --- |
| 列表 | 道路、断路范围、时段、绕行、应急通道、状态 |
| 创建编辑 | 影响评估、交通方案、绕行图、通知范围、责任单位 |
| 许可向导 | 围挡 → 路障 → 标志 → 照明 → 绕行验证 → 应急通道 → 通知 → 签名 |
| 作业巡检 | 通行、应急通道、围挡和标志状态 |
| 恢复验收 | 清场、道路、标识、正常通行 |

## 2. 字段与校验

| 分组 | 字段 |
| --- | --- |
| 断路 | `roadId`、范围、开始结束时间、施工内容、责任单位 |
| 交通 | 影响区域、绕行路线、应急通道、交通组织方案 |
| 通知 | 消防、应急、生产、物流和相关作业负责人 |
| 布控 | 围挡、路障、标志、警示灯、夜间照明 |

## 3. 状态节点

```text
申请 → 交通影响评估 → 交底签字 → 审批中 → 待断路
→ 断路中 ⇄ 暂停中 → 道路恢复 → 待验收 → 待关闭 → 关闭
```

## 4. 移动端与通知

- 移动端地图展示断路范围、绕行和应急通道。
- 应急通道占用、围挡损坏、标志缺失可快速上报并暂停。
- 许可前通知消防、应急和相关区域负责人，保留送达结果。

## 5. 误操作防范与验收

- 未提供绕行方案和应急通道不得许可。
- 范围、时段和路线变化触发重新复核。
- 道路恢复、清场和正常通行未验收不得关闭。
- 同区域其他作业收到断路影响提示。
