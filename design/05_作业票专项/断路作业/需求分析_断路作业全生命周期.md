# 断路作业 · 全生命周期需求分析

> **依据**：`GB 30871-2022` 第 12 章、平台 M06 危险工作票闭环  
> **编码**：`ROAD_BREAK`

## 1. 结论

断路专项控制的不只是施工区域，还包括交通组织、绕行路线、消防和应急通道。未经影响评估和现场布控，不得断路。

## 2. 主流程

```text
申请 → 断路范围与交通影响评估 → 绕行及应急通道方案 → 交底签字
→ 审批 → 待作业：围挡、路障、标志、照明、绕行验证、通知确认
→ 断路中：巡检、交通异常暂停 ⇄ 恢复复核
→ 道路恢复、清场、通行验收 → 关闭归档
```

## 3. 关键规则

- 明确断路区域、时间、影响范围、施工内容和责任单位。
- 制定交通组织和绕行方案，保证消防、救护和应急车辆通行。
- 作业区设置路障、交通标志、警示灯和围挡；夜间保证可见。
- 断路影响区域内其他作业时，通知相关负责人并执行 SIMOPS 扫描。
- 临时变更断路范围、时间或绕行路线时重新审批或复核。
- 完工后清理现场，恢复道路、标志和正常通行。

## 4. 异常与联动

| 异常 | 行为 |
| --- | --- |
| 未提供绕行方案或应急通道不可用 | 阻断许可 |
| 路障、标志、照明或围挡缺失 | 阻断许可 |
| 应急通道被占用 | 暂停并立即处置 |
| 断路范围或时间变化 | 暂停，更新方案并复核 |
| 与区域内其他票冲突 | SIMOPS 提示、通知或协调 |
| 道路恢复未验收 | 阻断关闭 |

## 5. 数据与证据

| 数据 | 证据 |
| --- | --- |
| 断路详情 | 道路、范围、时段、原因、责任单位 |
| 交通方案 | 绕行图、应急通道、通知范围、审批意见 |
| 现场布控 | 路障、标志、围挡、照明照片和位置 |
| 巡检 | 通行状态、异常、应急通道占用情况 |
| 恢复 | 道路、标识、清场、通行验收 |

## 6. 验收标准

- 绕行方案和应急通道未确认时无法许可。
- 路障、交通标志、照明和围挡可逐项确认并留证。
- 范围、时段或路线变更可触发暂停复核。
- 断路可对同区域其他票产生 SIMOPS 提示。
- 道路恢复验收通过后方可关闭。
