## 核心结论

1. 平台不应只做“电子台账 + 审批流”，而应围绕风险闭环建设：风险辨识、作业许可、实时监测、报警联动、处置复盘、绩效改进。
2. 石油化工场景的关键差异化在“作业票与实时风险联动”：把重大危险源、人员定位、承包商资质、气体检测、视频 AI、DCS/SIS/可燃有毒气体报警数据纳入许可条件和动态风险评估。
3. 国内项目必须对齐 GB 30871-2022、应急管理部危化企业/化工园区安全风险智能化管控平台建设指南、重大危险源监测预警和双重预防机制要求。
4. 国际 PSM/EHS 平台强调 PHA/HAZOP、MOC、Control of Work、Barrier Management 和统一风险视图；国内平台更强调监管报送、特殊作业过程留痕、重大危险源在线监测、人员定位、封闭化管理和视频智能分析。
5. 推荐采用“平台底座 + 业务域模块 + 物联边缘网关 + 风险规则引擎 + 数据治理”的架构，先落地高风险场景，再扩展完整 PSM 十四要素和 EHS 一体化。

## 建议的 MVP 范围

第一期建议覆盖：

- 组织、人员、承包商、资质证照、培训准入。
- 动火、受限空间、高处、吊装、临时用电、盲板抽堵、动土、断路等特殊作业票。
- 重大危险源档案、风险分级、监测点位、实时指标、报警闭环。
- 报警中心、处置流程、通知升级、值班交接。
- 移动端现场确认、二维码/NFC 签到、电子签名、照片/视频留痕。
- 大屏态势、统计报表、审计追溯、监管数据接口预留。
