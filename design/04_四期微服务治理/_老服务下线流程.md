# 老服务下线流程

> 日期：2026-05-31 | 依据：执行计划步骤 8.1

---

## 下线前置条件（每个老服务逐一确认）

```
□ 网关 100% 流量已切到目标服务（灰度配置中 useXxxService=true，老服务路由已移除）
□ 监控连续 7 天无异常（错误率、P99 延迟）
□ 无外部系统直接调用老服务地址（检查 Nacos 注册中心调用方）
□ XXL-Job 定时任务已切换到目标服务
□ 消息队列消费者已切换到目标服务
□ 老服务日志最近 3 天无生产请求
□ 回滚方案已演练（至少一次切回老服务演练）
```

## 单服务下线步骤（模板）

```bash
# Step 1: 网关路由确认（流量 0% → 老服务）
# 确认灰度配置 useXxxService=true，移除老服务路由

# Step 2: 保留只读部署 2 天
# 进程运行但不接收网关流量，观察是否还有直接调用

# Step 3: 停进程
docker stop psm-xxx-service   # 或 kubectl scale deploy psm-xxx-service --replicas=0

# Step 4: 注销 Nacos
# 从 Nacos 控制台删除 psm-xxx-service 注册实例

# Step 5: 删除部署配置
# 移除 K8s YAML 或 docker-compose 中的服务定义

# Step 6: 代码模块归档（保留为兼容壳模块）
# 将 services/psm-xxx-service 目录标记为 DEPRECATED
# 或删除所有业务代码，仅保留一个空 README
```
