## 2. 不合并的数据库（保留独立）

| psm_config_rule | 平台支撑域 |
| psm_file | 文件服务，对象存储路径独立 |
| psm_notification | 横切通知能力 |
| psm_audit | 审计数据量大，独立扩展 |
| psm_integration | 外部集成域 |

## 3. 治理规则

1. **禁止**公共模块配置 DataSource（Data source 只在业务服务中配置）
2. **禁止** Mapper XML 中出现跨库 JOIN
3. **禁止** `@Transactional` 注解跨多个数据源
4. **要求**每个目标域服务的多数据源配置使用 `@Primary` + `@Qualifier` 明确主从

## 4. 定时任务盘点

| 任务类型 | 原调度方 | 目标调度方 | 风险等级 |
|---|---|---|---|
| 巡检计划生成 | psm-inspection-service | psm-risk-control-service | 中 |
| 报警告警升级 | psm-alarm-service | psm-realtime-perception-service | 高 |
| 作业票到期检查 | psm-work-permit-service | psm-operation-control-service | 中 |
| 承包商资质过期 | psm-contractor-service | psm-operation-control-service | 低 |
| 治理指标计算 | psm-governance-service | psm-incident-governance-service | 中 |
| 报表预聚合 | psm-report-service | psm-incident-governance-service | 低 |
| Token/Session 清理 | psm-auth-service | psm-identity-service | 低 |

## 5. 定时任务切换规则

1. 新老服务并行期间，同一逻辑任务只在一侧启用
2. 切换顺序：低频 → 中频 → 高频 → 实时
3. 切换后观察至少 2 个完整周期无异常
4. XXL-Job 参数中增加 `targetService=xxx` 标识
