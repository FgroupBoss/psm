=== 目标 9 域映射 ===
1. 接入与体验层: gateway (保留) + mobile-bff (保留瘦身)
2. 身份与组织域: psm-identity-service <- auth + iam
3. 平台支撑域: psm-platform-support-service <- master-data + config-rule + file + notification + audit
4. 实时感知域: psm-realtime-perception-service <- alarm + location + video
5. 作业与承包商域: psm-operation-control-service <- work-permit + contractor
6. 风险防控域: psm-risk-control-service <- dual-prevention + major-hazard + inspection
7. 流程安全域: psm-process-safety-service <- moc + pha + pssr + barrier
8. 事件治理域: psm-incident-governance-service <- incident + governance + report
9. 外部集成域: psm-integration-service (保留)
