> **签收**：2026-05-27 · **批次**：第 2 迭代 1～3、6 批次  
> **所属迭代**：第 2 迭代 · 准入与风险对象  
> **落地设计**：[03_承包商准入/落地设计.md](../../03_承包商准入/落地设计.md) · 服务 `psm-contractor-service`

## 1. 目标与边界

**Must**：单位档案、资质、准入审核、停权、黑名单、人员档案、证书、培训、违章、作业资格校验。

**Won't**：门禁自动开闸、承包商绩效评分完整模型、外部 LMS 深度集成。

## 2. 功能闭环

```text
录入承包商单位
 -> 上传资质和合同材料
 -> 准入审核
 -> 录入人员、证书、培训
 -> 作业票选人实时校验
 -> 作业过程产生违章或停权
 -> 复审、恢复或黑名单
 -> 资格校验结果持续影响作业
```

## 3. 状态机

```text
待提交 -> 待审核 -> 已准入 -> 待复审 -> 已准入
待审核 -> 已退回
已准入 -> 已停权
已准入/已停权 -> 黑名单
```

| 接口 | 用途 |

## 5. 核心 API

`/api/contractors/companies` · `/api/contractors/companies/{id}` · `/api/contractors/companies/{id}/approve` · `/api/contractors/companies/{id}/suspend` · `/api/contractors/companies/{id}/blacklist` · `/api/contractors/workers` · `/api/contractors/workers/{id}/certificates` · `/api/contractors/workers/{id}/trainings` · `/api/contractors/workers/{id}/violations` · `/api/contractors/workers/eligibility-check`

## 6. 数据表

`contractor_company`、`contractor_qualification`、`contractor_worker`、`worker_certificate`、`worker_training_record`、`contractor_violation`、`contractor_blacklist`、`contractor_audit_record`

## 7. 规则阻断点

| 校验项 | 检查点 | 处理 |
| --- | --- | --- |
| 单位未准入 | 作业票选择承包商、提交、许可 | 阻断 |
| 单位核心资质过期 | 提交、许可 | 阻断或预警 |
| 人员未准入 | 添加作业人员 | 阻断 |
| 人员培训失效 | 添加作业人员、提交、许可 | 阻断 |
| 特种作业证过期 | 对应作业类型 | 阻断 |
| 人员黑名单 | 任意作业 | 阻断并提示原因 |
