## 1. 目标与边界

**Must**：租户、登录、SSO 预留、组织用户、角色菜单、按钮权限、数据权限、区域设备点位、登录日志、操作日志、关键变更审计。

**Won't**：集团级商业计费、复杂组织多账套、跨租户共享业务数据、完整 IAM 产品化能力。

## 2. 功能闭环

```text
租户/企业初始化
 -> 身份源或本地账号配置
 -> 组织、岗位、用户维护
 -> 角色、菜单、按钮、数据范围授权
 -> 区域、装置、设备、点位维护
 -> 业务模块引用主数据和权限
 -> 关键操作写审计
 -> 审计查询和问题追溯
```

## 3. 依赖与输出

| 能力 | 用法 |
| --- | --- |
| 登录鉴权 | Web、移动端、网关统一身份入口 |
| IAM 权限 | 菜单、按钮、接口和数据范围控制 |
| 主数据 | 作业票、报警、危险源、承包商统一引用区域、设备、点位、人员 |
| 审计 | 全模块关键操作追溯 |

## 4. 核心 API

`/api/auth/login` · `/api/auth/refresh` · `/api/auth/me` · `/api/iam/menus/tree` · `/api/iam/users` · `/api/iam/roles/{id}/permissions` · `/api/iam/roles/{id}/data-scopes` · `/api/master-data/areas` · `/api/master-data/equipment` · `/api/master-data/monitor-points` · `/api/audit/change-logs`

## 5. 数据对象

`sys_tenant`、`sys_org`、`sys_user`、`sys_post`、`sys_role`、`sys_role_permission`、`sys_menu`、`sys_data_scope`、`base_area`、`base_unit`、`base_equipment`、`monitor_point`、`operation_log`、`audit_change_log`、`login_log`

## 6. 状态与规则

| 对象 | 状态 | 规则 |
| --- | --- | --- |
| 用户 | 正常、禁用、锁定、离职 | 非正常状态不可登录，不可参与新流程 |
| 区域 | 启用、停用 | 停用区域不可新建作业、危险源或报警映射 |
| 设备 | 运行、停用、检修 | 停用设备不可被新作业引用 |
| 点位 | 在线、离线、停用 | 停用点位不参与新报警映射 |
| 角色 | 启用、停用 | 停用角色不再授予权限 |
