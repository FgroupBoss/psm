## 1. 目标与边界

**Must**：字典、作业票模板、安全措施模板、审批流基础配置、规则评估、通知模板、附件策略、配置版本和审计。

**Won't**：复杂低代码表单设计器、图形化规则编排、跨租户规则市场、外部通知通道全量实现。

## 2. 功能闭环

```text
配置草稿创建
 -> 字段校验和版本生成
 -> 发布生效
 -> 业务模块按版本引用
 -> 规则评估返回通过/警告/阻断
 -> 配置变更生成新版本
 -> 审计查询和版本回放
```

## 3. 依赖与输出

| 能力 | 用法 |
| --- | --- |
| `WORK_PERMIT_TYPE`、`ALARM_LEVEL` 等字典 | Web/移动端枚举渲染和后端校验 |
| 表单模板 | 动火、受限空间等作业票字段和必填规则 |
| 审批流配置 | 作业票提交后按作业类型、风险等级、区域选人 |
| 规则评估 | 作业票提交、许可、延期、报警接入、承包商选人 |
| 通知模板 | 待办、超时、报警升级、证书到期提醒 |

## 4. 核心 API

`/api/config/dictionaries` · `/api/config/forms` · `/api/config/forms/{id}/publish` · `/api/config/workflows` · `/api/config/workflows/{id}/publish` · `/api/config/rules` · `/api/rules/evaluate` · `/api/config/notifications/templates` · `/api/config/attachments/policies`

## 5. 规则结果

| 字段 | 说明 |
| --- | --- |
| `passed` | 总体是否通过 |
| `level` | `PASS`、`WARN`、`BLOCK` |
| `ruleCode` | 命中规则编码 |
| `message` | 面向用户的提示 |
| `evidence` | 命中依据，如证书、报警、检测值 |
| `suggestion` | 建议处理动作 |

## 6. 必配规则

| 规则 | 检查点 | 结果 |
| --- | --- | --- |
| 作业区域停用 | 作业票提交 | BLOCK |
| 承包商未准入 | 选人、提交、许可 | BLOCK |
| 人员证书过期 | 选人、提交、许可 | BLOCK |
| 培训失效 | 选人、提交、许可 | BLOCK |
| 气体检测不合格 | 许可 | BLOCK |
| 气体检测超有效期 | 许可 | BLOCK |
| 监护人未签到 | 许可 | BLOCK |
| 区域高等级报警 | 许可 | BLOCK/WARN |
| 作业超时 | 作业中 | WARN/BLOCK |
