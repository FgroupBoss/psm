# 报表大屏与上线验收落地设计

## 1. 模块目标

提供一期试点验收所需的统计报表、大屏态势、数据追溯、测试验收和上线切换方案。

## 2. 报表范围

| 报表 | 指标 |
| --- | --- |
| 作业票统计 | 总数、类型、状态、区域、风险等级、超时、暂停、延期 |
| 报警统计 | 等级、区域、来源、确认时长、处置时长、高频报警、误报率 |
| 重大危险源统计 | 数量、等级、在线率、报警状态、责任人覆盖率 |
| 承包商统计 | 准入数量、证书过期、培训合格率、违章次数 |
| 审计统计 | 关键操作次数、配置变更、权限变更、异常登录 |

## 3. 大屏范围

大屏一期只展示可追溯指标，不做无数据闭环的装饰性内容。

| 区域 | 内容 |
| --- | --- |
| 风险态势 | 重大危险源数量、等级、当前报警 |
| 作业态势 | 今日作业、进行中、待许可、超时、暂停 |
| 报警态势 | 新报警、未确认、处置中、超时、关闭率 |
| 承包商态势 | 在场人员、证书过期预警、黑名单 |
| 数据时间 | 明确展示刷新时间和数据来源 |

## 4. 数据口径

| 指标 | 口径 |
| --- | --- |
| 特殊作业系统办理率 | 系统内作业票数量 / 试点区域实际作业数量 |
| 现场许可留痕率 | 有签到、检测、措施确认、签名的作业票 / 需现场许可作业票 |
| 承包商资质校验覆盖率 | 执行人员校验的承包商作业票 / 涉及承包商作业票 |
| 重大危险源档案完整率 | 必填档案完整危险源 / 试点危险源总数 |
| 报警闭环率 | 已关闭报警 / 应处置报警 |
| 关键操作审计覆盖率 | 有审计记录的关键操作 / 关键操作总数 |

## 5. 接口设计

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/reports/work-permits/summary` | GET | 作业票统计 |
| `/reports/alarms/summary` | GET | 报警统计 |
| `/reports/major-hazards/summary` | GET | 重大危险源统计 |
| `/reports/contractors/summary` | GET | 承包商统计 |
| `/dashboard/overview` | GET | 大屏总览 |
| `/reports/export` | POST | 报表导出 |

## 6. 验收测试用例

| 场景 | 验收点 |
| --- | --- |
| 动火作业正常闭环 | 创建、审批、气体检测、许可、监护、验收、归档 |
| 受限空间闭环 | 人员、气体检测、措施确认、监护记录完整 |
| 证书过期拦截 | 承包商人员证书过期时禁止加入作业 |
| 培训失效拦截 | 培训失效人员不能参与作业 |
| 气体检测不合格 | 禁止现场许可 |
| 区域报警联动 | 高等级报警未关闭时阻断或升级审批 |
| 报警处置闭环 | 确认、派发、处置、升级、关闭 |
| 危险源聚合视图 | 档案、点位、报警、作业、责任人可查看 |
| 移动端现场许可 | 签到、措施确认、检测、拍照、签名 |
| 权限隔离 | 不同区域用户只能访问授权数据 |
| 审计追溯 | 关键操作可追溯到人、时间、终端和内容 |

## 7. 上线准备清单

| 类别 | 内容 |
| --- | --- |
| 主数据 | 组织、用户、区域、装置、设备、点位、承包商、人员 |
| 模板 | 八大作业票模板、安全措施模板、验收项 |
| 流程 | 审批流、加签转办规则、超时规则 |
| 规则 | 资质、培训、证书、气体检测、区域报警、延期 |
| 接口 | HR、OA、GDS/DCS/实时库、门禁或人员系统 |
| 权限 | 角色、菜单、按钮、数据范围、移动端动作 |
| 运维 | 部署、备份、监控、日志、告警、应急回退 |
| 培训 | 管理员、审批人、许可人、监护人、值班员、承包商管理员 |

## 8. 上线步骤

1. 主数据清洗和导入。
2. 作业票模板、审批流和规则配置。
3. 承包商和人员证书导入。
4. 重大危险源和点位绑定。
5. 报警接入和规则调试。
6. 关键用户培训。
7. 试运行 2-4 周。
8. 问题修复和规则优化。
9. 正式上线。
10. 推广到其他区域。

## 9. 验收标准

- 一期范围内所有模块能在试点区域完成端到端闭环。
- 关键流程有完整审计记录。
- 报表指标与明细数据一致。
- 大屏展示刷新时间和数据来源。
- 系统完成部署、备份、监控和培训。
- 试运行问题关闭后正式上线。
