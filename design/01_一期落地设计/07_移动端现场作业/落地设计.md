# 移动端现场作业落地设计

## 1. 模块目标

支撑现场人员在移动端完成作业许可和监护关键动作，解决现场真实性、及时性和证据留痕问题。

## 2. 功能范围

| 子模块 | 一期范围 |
| --- | --- |
| 登录待办 | 登录、待办列表、消息提醒 |
| 作业票详情 | 基本信息、风险、措施、审批、附件 |
| 现场签到 | 二维码/NFC/定位签到 |
| 气体检测 | 检测数据录入、有效期、结论 |
| 措施确认 | 逐项确认、拍照证明 |
| 电子签名 | 许可、验收、关键确认签名 |
| 监护检查 | 检查记录、拍照、异常上报 |
| 作业控制 | 暂停、恢复、延期申请、终止建议 |
| 报警处置 | 报警查看、处置反馈、附件上传 |
| 弱网草稿 | 非许可动作草稿保存和重试 |

## 3. 现场动作约束

- 许可开工必须在线校验，不允许离线直接开工。
- 需要现场真实性的动作必须记录定位或扫码结果。
- 附件上传失败时保留本地待上传记录，并支持重试。
- 所有关键动作记录人员、时间、终端、网络状态。
- 弱网草稿同步后需再次执行服务端规则校验。

## 4. 页面设计

| 页面 | 关键能力 |
| --- | --- |
| 待办列表 | 按角色展示待许可、待监护、待验收、报警待处理 |
| 作业票详情 | 查看作业信息、人员、风险、措施、审批 |
| 现场许可 | 签到、气体检测、措施确认、签名、开工 |
| 监护记录 | 巡检项、照片、异常、暂停建议 |
| 完工验收 | 清场确认、设备恢复、人员撤离、签名 |
| 报警反馈 | 查看报警详情、填写处置过程、上传照片 |
| 草稿箱 | 待同步草稿、失败原因、重试 |

## 5. 接口设计

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/mobile/tasks` | GET | 移动端待办 |
| `/mobile/work-permits/{id}` | GET | 作业票详情 |
| `/mobile/work-permits/{id}/check-in` | POST | 现场签到 |
| `/mobile/work-permits/{id}/gas-tests` | POST | 气体检测录入 |
| `/mobile/work-permits/{id}/measures/confirm` | POST | 措施确认 |
| `/mobile/work-permits/{id}/site-permit` | POST | 许可开工 |
| `/mobile/work-permits/{id}/monitor-records` | POST | 监护记录 |
| `/mobile/work-permits/{id}/acceptance` | POST | 完工验收 |
| `/mobile/alarms/{id}/feedback` | POST | 报警处置反馈 |
| `/mobile/files/upload` | POST | 附件上传 |

## 6. 离线与重试策略

| 动作 | 弱网策略 |
| --- | --- |
| 查看详情 | 可缓存最近详情，明确显示数据时间 |
| 监护记录 | 可保存草稿，联网后同步 |
| 拍照附件 | 本地排队上传，失败可重试 |
| 气体检测 | 可暂存，但许可开工前必须在线提交并校验 |
| 现场许可 | 必须在线 |
| 暂停作业 | 优先在线提交，失败时提示联系值班人员 |

## 7. 安全与审计

- 移动端 Token 过期必须重新认证。
- 关键动作记录设备标识、IP、定位或扫码结果。
- 电子签名记录签名图片、签名人、签名时间和业务节点。
- 附件记录业务归属、上传人、上传时间和文件哈希。

## 8. 验收标准

- 手机端可完成现场签到、气体检测、措施确认、拍照、签名和许可开工。
- 许可开工时服务端重新校验资质、培训、气体检测和区域报警。
- 附件上传失败有重试机制和明确提示。
- 监护异常可触发作业暂停或上报。
- 所有关键动作可在 Web 端时间线查看。
