# 07 实施路线与招标选型

## 1. 分期路线

### 一期：高风险作业与重大危险源闭环（3-6 个月）

目标：快速替代纸质作业票，打通重大危险源和报警闭环。

范围：

- 基础主数据：组织、人员、区域、装置、设备、承包商。
- 八大特殊作业票、审批流、移动端现场确认、电子签名。
- 承包商准入、人员证书、培训有效期校验。
- 重大危险源档案、监测点位、实时数据接入。
- 报警中心、处置闭环、通知升级。
- 作业态势和重大危险源大屏。

验收：

- 80% 以上特殊作业通过系统办理。
- 动火/受限空间等高风险作业实现气体检测和现场确认留痕。
- 重大危险源关键点位在线率达到项目约定值。
- 报警确认、处置、关闭全流程可追溯。

### 二期：双重预防、巡检和智能联动（4-8 个月）

范围：

- 风险分级管控、隐患排查治理。
- 巡检路线、检查表、NFC/二维码。
- 人员定位、电子围栏、门禁、车辆接入。
- 视频 AI 事件接入和特殊作业过程监护。
- SIMOPS 交叉作业冲突识别。
- 园区/监管平台接口。

验收：

- 风险清单和隐患闭环覆盖主要装置和区域。
- 人员定位和作业票区域联动可用。
- 视频 AI 事件能进入报警中心并闭环。

### 三期：完整 PSM 与集团治理（6-12 个月）

范围：

- PHA/HAZOP、LOPA、Bowtie。
- MOC、PSSR、事故调查、根因分析。
- 屏障管理、机械完整性、设备可靠性集成。
- 集团多基地模板、指标对标、审计。
- 数据仓库、风险模型、AI 辅助分析。

验收：

- 关键 PSM 要素形成跨模块闭环。
- 集团能统一查看各基地风险、报警、作业和整改绩效。
- 形成可复用行业模板和实施方法论。

## 3. 关键里程碑

1. 现状调研：制度、票证、组织、设备、点位、接口、网络边界。
2. 蓝图设计：业务流程、系统架构、数据标准、集成清单。
3. 原型评审：作业票、报警中心、重大危险源、移动端。
4. 开发配置：模块开发、流程配置、规则配置、接口开发。
5. 联调测试：工业数据、门禁定位、视频、OA/HR/EAM。
6. 试点上线：选择一个装置/区域试运行。
7. 全厂推广：培训、数据迁移、运行支持。
8. 复盘优化：指标分析、规则调优、模板沉淀。

## 5. 招标关键条款建议

- 必须提供 GB 30871-2022 八大特殊作业票模板，并支持企业制度差异化配置。
- 必须支持移动端现场确认、电子签名、定位、照片/视频附件和二维码/NFC。
- 必须支持人员资质、承包商准入、培训有效期与作业票许可联动。
- 必须支持重大危险源档案、监测点位、实时趋势、报警分级和处置闭环。
- 必须支持 DCS/SIS/GDS/火灾报警/人员定位/视频平台中至少若干类接口接入。
- 必须提供完整审计日志，覆盖审批、许可、关闭、报警处置、阈值和规则变更。
- 必须提供接口文档、数据字典、部署架构、安全方案、备份恢复方案。
- 必须支持私有化部署和企业网络安全边界要求。
- 供应商需提供石油化工或危化企业同类案例。

## 6. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 现场人员抵触，觉得系统增加负担 | 移动端少填、模板复用、扫码带入、先试点优化 |
| 工业数据接入复杂 | 先接关键点位，建立点位字典和边缘网关标准 |
| 业务制度不统一 | 集团模板 + 企业差异化参数，避免硬编码 |
| 报警过多导致疲劳 | 去重、关联、抑制、分级、TOP 问题治理 |
| 监管口径变化 | 接口适配层和数据映射配置化 |
| 只建大屏不落流程 | 以作业票、报警、隐患闭环作为验收核心 |
| OT 安全风险 | 只读采集、隔离区、最小权限、网络白名单 |

## 7. 近期行动清单

1. 选择 1 个典型厂区和 1 个高风险装置作为调研对象。
2. 收集现行作业票模板、审批制度、承包商准入制度、重大危险源台账和报警分级制度。
3. 梳理工业数据接口：DCS/SIS/GDS/FAS/实时库/视频/定位/门禁。
4. 明确一期必须上线的作业类型和监管上报要求。
5. 建立产品原型并邀请安全、生产、设备、承包商、值班人员评审。
