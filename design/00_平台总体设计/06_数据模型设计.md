# 06 数据模型设计

## 1. 数据域划分

| 数据域 | 主要实体 |
| --- | --- |
| 组织权限域 | 企业、厂区、部门、岗位、用户、角色、权限、数据范围 |
| 基础对象域 | 区域、装置、设备、介质、SDS、监测点位、风险单元 |
| 作业许可域 | 作业票、作业包、风险分析、安全措施、审批、气体检测、现场确认、监护、验收 |
| 重大危险源域 | 危险源、分级、包保责任、储罐/装置、屏障、监测指标、预案 |
| 报警事件域 | 报警、报警规则、报警处置、升级、通知、复盘 |
| 承包商域 | 承包商单位、合同、资质、人员、证书、培训、考试、违章、绩效 |
| 双重预防域 | 风险清单、管控措施、检查表、隐患、整改、复查 |
| 应急域 | 预案、资源、队伍、演练、应急事件 |
| 审计域 | 操作日志、电子签名、版本快照、接口调用 |

```text
承包商 1:N 承包商人员

隐患 N:1 风险单元
隐患 N:1 整改行动项
```

## 4. 权限模型

权限由四层组合：

1. 功能权限：菜单、按钮、接口。
2. 数据权限：集团、企业、厂区、装置、区域、班组。
3. 角色权限：安全员、审批人、监护人、承包商管理员、值班员等。
4. 场景权限：只有当前作业票的相关人员可现场确认；只有值班人员可确认报警；只有授权管理员可修改阈值。

## 5. 指标体系

### 5.1 作业票指标

- 作业票总数、按类型分布、按风险等级分布。
- 审批平均时长、超时审批数。
- 作业延期率、暂停率、强制终止率。
- 气体检测不合格次数。
- 交叉作业冲突次数。

### 5.2 重大危险源指标

- 点位在线率、报警次数、报警持续时长。
- 一级/二级报警处置及时率。
- 安全屏障失效次数和失效时长。
- 巡检完成率、隐患逾期率。

### 5.3 承包商指标

- 准入通过率、证书过期率、培训合格率。
- 违章次数、严重违章次数、整改及时率。
- 高风险作业参与次数和异常率。

### 5.4 报警指标

- 报警总量、重复报警率、误报率。
- 平均确认时间 MTTA。
- 平均处置时间 MTTR。
- 超时未处置报警数。
- 高频报警 TOP10。

## 6. 数据治理

- 主数据统一编码：组织、区域、装置、设备、点位、人员、承包商。
- 点位字典维护原始点号和业务对象映射。
- 附件和电子签名保留策略按企业制度配置。
- 关键表保留版本快照，支持审计回放。
- 身份证、手机号、健康信息等敏感数据必须脱敏展示、加密存储。
