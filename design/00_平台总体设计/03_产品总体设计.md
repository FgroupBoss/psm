# 03 产品总体设计

## 1. 产品定位

建设一套面向石油化工企业的企业级 PSM 安全管理平台，核心目标是：

- 管住高风险作业：危险工作票全流程数字化和现场过程管控。
- 管住重大风险源：重大危险源档案、实时监测、报警和处置闭环。
- 管住外来风险：承包商、人员、车辆、资质、培训和作业绩效。
- 管住异常事件：报警、隐患、事件、应急、整改和复盘闭环。
- 支撑集团治理：统一标准、统一模板、统一指标、统一审计、统一监管接口。

## 4. 核心业务闭环

### 4.1 作业许可闭环

申请作业 -> 自动校验基础条件 -> JSA/JHA 风险辨识 -> 安全措施确认 -> 多级审批 -> 现场许可 -> 作业中监护 -> 异常暂停/恢复 -> 完工验收 -> 归档与复盘。

关键控制点：

- 未培训、证书过期、承包商未准入、区域有高等级报警、气体检测过期时禁止许可。
- 同一区域存在动火、排放、吊装、受限空间等冲突作业时触发 SIMOPS 风险提示。
- 作业中报警、人员离岗、视频识别违章、气体超限时自动暂停或要求复核。

### 4.2 重大危险源闭环

危险源建档 -> 分级和责任绑定 -> 点位接入 -> 阈值规则 -> 实时监测 -> 报警分级 -> 处置预案 -> 整改/维修 -> 复盘评估。

关键控制点：

- 每个危险源必须绑定责任部门、包保责任人、监测点位、巡检计划、应急预案和安全屏障。
- 监测数据异常要能关联到设备、区域、作业票、人员、视频和历史趋势。

### 4.3 报警处置闭环

报警产生 -> 规则归并 -> 分级派发 -> 值班确认 -> 现场核实 -> 预案处置 -> 升级通知 -> 关闭 -> 复盘分析。

关键控制点：

- 报警不能只推送消息，必须绑定处置责任、时限、证据和关闭条件。
- 重复报警、闪断报警、关联报警要归并，避免报警疲劳。

### 4.4 承包商准入闭环

单位准入 -> 合同/资质审核 -> 人员录入 -> 培训考试 -> 证书校验 -> 门禁授权 -> 作业表现 -> 绩效评价 -> 续准入/清退。

关键控制点：

- 承包商人员必须和作业票、培训、证书、门禁、定位、违章记录联动。
- 高风险作业人员的特种作业证、健康条件、培训有效期必须自动校验。

## 5. 端侧设计

| 端 | 适用场景 |
| --- | --- |
| Web 管理端 | 配置、审批、台账、报表、系统管理 |
| 移动 App/小程序 | 现场申请、确认、拍照、签名、扫码、监护、隐患上报 |
| 中控大屏 | 重大危险源、报警态势、作业态势、人员车辆、应急资源 |
| 边缘网关 | 工业数据采集、协议转换、缓存、断点续传、数据脱敏 |
| 开放 API | ERP、EAM、HR、OA、监管平台和第三方算法接入 |

## 6. 产品原则

- 现场优先：移动端必须少填、可扫码、可复用模板、支持弱网。
- 配置优先：票证、流程、风险矩阵、审批规则、报警规则可配置。
- 证据优先：关键节点有定位、时间、人员、照片/视频、签名和审计记录。
- 闭环优先：所有风险、报警、隐患、事件、作业异常都要可追踪到责任和整改。
- 集成优先：不是替代 DCS/SIS，而是在安全管理侧汇聚数据并形成决策闭环。
