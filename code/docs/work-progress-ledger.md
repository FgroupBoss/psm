# 工作进度记录台账

## 目的

本台账用于记录每次工作完成后的项目状态、完成内容、验证结果和下一步计划，避免后续工作丢失上下文。

## 记录规则

- 每次完成一次明确工作后，在“工作记录”中追加一条记录。
- 记录应包含日期、范围、当前状态、完成内容、验证结果、遗留问题和下一步。
- 状态统一使用：`未开始`、`进行中`、`待验证`、`已完成`、`阻塞`。
- 只记录与当前任务相关的进展，不记录无关探索过程。
- 若修改了代码但未完成验证，状态应标记为 `待验证`，并写清楚未验证原因。
