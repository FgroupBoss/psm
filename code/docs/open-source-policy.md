# 开源与使用政策

本仓库采用 **个人学习使用许可证**，完整法律文本见仓库根目录 [LICENSE](../../LICENSE)。

## 一句话说明

| 场景 | 是否允许 |
| --- | --- |
| 个人学习、阅读源码、本地调试 | ✅ 允许 |
| 个人非商用实验、写学习笔记/教程（注明出处） | ✅ 允许 |
| 企业内生产/运营环境部署 | ❌ 须商用授权 |
| 对外提供产品、SaaS、交付项目 | ❌ 须商用授权 |
| 出售、出租、再许可本仓库内容 | ❌ 须商用授权 |

## 「个人开发者」与「商用」

- **个人开发者**：以自然人身份、出于学习或研究目的使用，不代表公司或组织开展业务。
- **商用**：以营利或商业利益为目的的使用，包括组织内部生产使用、作为商业服务组成部分等。
